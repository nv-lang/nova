  `value_recv_by_pointer` (R3: `mut @`/`consume @` — указатель; R5: `ro @` — копия до 24 Б, иначе
  указатель), `row_recv_by_pointer`. Размер — поля с выравниванием C; размер, который Карина не
  считает, даёт «указатель» (для `ro` неотличимо от копии).
- check: отказ VALUE_METHOD_MSG снят (с ним `recv_type_name` — единственный вызывающий); приёмник,
  идущий указателем, обязан быть МЕСТОМ (`x`, `@`, `x.f`, `@f`); временное (`mk().m()`) — отказ по
  имени (уже оракула: он проливает во временное).
- emit: сигнатура `NovaValue_X*` где указатель; в теле `@f` — `self.f` при копии, `self->f` при
  указателе, `@` — `(*self)` за указателем; на месте вызова `(&recv)`.
- Фикстура `value_recv/pos_1`: 16 Б `ro` копией, 32 Б `ro` указателем, `mut` указателем (локал и
  поле кучевой записи). **Клетки 17–24 Б в фикстуру не положены**, как велено.
- Три метода `CalleeRef` (40 Б) в sem/channel.nv идут указателем.

## №1576

Литеральный дефолт handed-функции нёс id своего дерева; эмиттер читает тип литерала по id в
канале КОМПИЛИРУЕМОГО файла. Воспроизведено модульным тестом: `bump(n int, by int = 3)` из файла,
открытого `fn kN() -> u8 => 7`, при одном из 16 сдвигов печатал `3` типом чужого узла. Теперь
`resolve_const_defaults` пересобирает литерал-дефолт без идентичности (`handed_literal`).
