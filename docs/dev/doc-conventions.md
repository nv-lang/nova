# Конвенция документации Nova

> Нормативная конвенция (управление — [conventions-governance.md](conventions-governance.md)).
> Структурная карта зон — [docs/README.md](../README.md); этот файл — правила
> ведения: язык, нормативность, переводы, публикация. Сайт-сторона —
> [site-conventions.md](site-conventions.md).

## Зоны и их контракты {#zones}

| Зона | Язык | Нормативность | На сайт |
|---|---|---|---|
| `spec/*.md` | **русский — норматив** | нормативна для компилятора | да (синк) |
| `spec/*.en.md` | английский | **informative-перевод** | да (план 241) |
| `spec/decisions/` | русский | нормативна (D-блоки) | да (RU-only) |
| `docs/guide/` | en = основной, ru-пара | информативна | да (whitelist) |

| `docs/plans/` | русский | процесс | нет |

## Языковая политика {#language}

- **`docs/guide/`**: английский файл — основной (`имя.md`), русское зеркало —
  `имя.ru.md`. Файл, синкаемый на сайт, ОБЯЗАН иметь ru-пару
  (site-conventions #en-ru-sync); правка одной стороны пары не сдаётся.
- **`spec/`**: русский текст (`имя.md`) — единственный норматив; это
  зафиксировано и НЕ переворачивается под схему guide (на `spec/*.md` как на
  русский норматив завязаны агенты, брифы и ссылки D-блоков). Английский
  перевод — `имя.en.md` рядом, informative, с обязательной шапкой:
  «Informative translation; the Russian text is normative.»
- **`spec/decisions/`**: только русский до стабилизации языка (объём ~64k
  строк, перевод нецелесообразен); на сайте — пометка для en-читателя.
- Док-комментарии в `.nv` (`///`, `//!`) и тексты диагностик/линта — ТОЛЬКО
  английский (nv-coding-style §25). Отчёты агентов — по-русски.

**Русский текст — с минимумом английских слов (слово владельца 2026-08-03).**
В ru-доке англицизмы сводятся к минимуму: не «роутер/хендлер/консюмить/капчурить»,
а «маршрутизатор/обработчик/потреблять/захватывать». Английскими остаются ТОЛЬКО:
имена из кода (типы, методы, ключевые слова, файлы, команды, коды ошибок E_*/W_*),
устоявшиеся имена собственные (GitHub, Rust) и термины из GLOSSARY, у которых
глоссарий явно фиксирует английскую форму. Enforcement: вычитка при приёмке
(машинный словарь калек — кандидат в страж 242 позже, warning-уровнем).

## Переводы и дрейф {#translation-drift}

- Frontmatter каждого `*.en.md`-перевода обязан нести ревизию источника:
  `source_rev: <короткий хеш коммита ru-файла>` и `source_date: <ISO-дата>`
  на момент перевода.
- Синк сайта сравнивает `source_date` с текущей датой ru-источника: русский
  новее → на en-странице автоматический баннер «The Russian original has
  been updated since this translation». Дрейф не скрывается — это
  документный аналог site-conventions #honest-dates.
- Перевод не меняет код-примеры: они переносятся байт-в-байт и обязаны
  компилироваться (site-conventions #compilable-examples).
- Догон дрейфа — периодической волной; баннер честно закрывает промежутки.

## Публикация {#publishing}

Сайт тянет контент ТОЛЬКО синком (`www/site/scripts/sync-decisions.mjs`) из
`docs/guide/` (whitelist), `spec/` и `spec/decisions/`. Правка страницы сайта
= правка источника в nova; сгенерированный контент в www руками не правится.
`docs/dev/` не цитировать и не линковать с публичных страниц.

enforcement: частично машинное — синк тянет только перечисленные зоны,
`npm run build`/check-links падают на битых источниках; языковая политика и
ru-пары — глазами в приёмке (site-conventions #acceptance).
