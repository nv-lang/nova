## C. Идентичность и слой sem (перед Э2-б, иначе переписывать)

C1 три несогласованных списка форм (`is_expr_kind`/`type_of`/`emit_expr`) и пять `if`-цепочек по NodeKind вместо `match` — язык не судит полноту (П13.5 нарушен собственным кодом) · C2 нет типизированных индексов (type-id/field-row/variant-row/def-row — все `int`, `row_off` адресует два разных вектора) · C3 `Prims` по ПОЗИЦИИ списка builtins (П13.6 обойдён на уровень) · C4 `fn_rets []int` без сигнатур (параметры повторно резолвятся в эмиттере — П1) · C5 `mangle` — функция от строки: неинъективен (`_`-разделитель), не знает перегрузок (`Nova_str_method_contains` vs `…__nova_char`), `c_fn` без модуля · C6 int-сентинелы `-1`/коды 0/1/2 вместо `Option`/сумм (класс №652 в другой одежде) · C7 `type_of` пересчитывается на каждом сайте — O(n·глубина), нет канала `resolved_types` (Э4) · C8 `type_of(MatchExpr)` по первому арму · C9 метод по имени, ресивер игнорируется (`p.contains(...)` на записи → ошибка линковки у пользователя) · C10 локалы/поля/параметры идут в C вербатим мимо двери мэнглинга (C-ключевые слова, макросы rt) · C11 дублирование понижения: строковый литерал ×2, `return` ×3 с разными умениями, `checked_add` ×2 — **трипвайр «MIR пора» из §9 уже сработал** · C12 у примитива два C-написания (`nova_str` значение / `Nova_str` владелец методов), второе угадывается склейкой.

## Вердикт агента 274

**Что уже хорошо** (сходятся все трое): дисциплина «правило со стражем», lossless-дерево, sem вне бэкенда, дверь мэнглинга до того как понадобилась, builtins-лист, машинная оболочка, откат demo вопреки монотонности, цена итерации 40 → 1.7 с.

**Главный риск** (тоже сходятся): **не паника, а тихое** — принятие не-языка (A1–A3, A8) и мискомпиляция в принятом подмножестве (A4–A7), которые дифф-гейт по своему контракту не видит, при том что сам гейт novac не строит (D1) и фаззер не гоняет (D2). Храповик 11/5 не опровергает ни одного из этих классов.

**Порядок исполнения — три волны, каждая ≤ день:**
1. **Механизмы доверия** (D1, D2, D3, D8, D9-частично, D6): гейт строит novac и краснит «судить нечего»; фаззер в гейте с rc; порог паники по спеке; страж суммы леджера + нормализация; страж свежести оболочки. Без этого всё остальное — на памяти сессии.
2. **Тихие мискомпиляции и не-язык** (A1–A8, A11, A12): Pratt-приоритеты; терминаторы в atom + take без assert; строка не через `\n`; пространство вариантов от суммы; `+=` через Bin; Scope-откат; префикс пользовательских типов; walk_in → match с арностью; временные по счётчику; println положительно. Плюс тесты на `code/lo/hi` и свойство «листья == токены» (D23) — иначе правки не доказаны.
3. **Перед Э2-б** (C1–C6, C9, C10, A9): match вместо if-цепочек; типизированные индексы; Prims по имени; FnDef с параметрами; mangle от сущности с перегрузкой и модулем; Option вместо -1; ресивер в ключе метода; локалы через дверь; дубли имён — диагностика. И D11 (`reserialize` как CLI + корпус) — параллельно, дёшево.

Э2-б (дженерики/mono) **не начинается**, пока волны 1–2 не закрыты: строить mono на плоском пространстве имён и на парсере без приоритетов — значит переписывать.
