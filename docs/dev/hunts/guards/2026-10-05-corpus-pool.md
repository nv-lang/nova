## Что обошёл и почему

- Перевод строки внутри имени фикстуры (Linux): на Windows такое имя не создать.
- Две фикстуры с одинаковым текстом под разными именами: носителя нет (дублей по
  sha256 среди 186 нет); зазор закрыт этой веткой — имя файла вошло в ключ бинаря.
- Грязный подмодуль: `git diff HEAD` даёт `-dirty` без содержимого правки — по
  чтению, без пробы.
- Гонка `cp`/`mv` при публикации бинаря и отказ `mv` на Windows из-за открытого
  хэндла — нужен живой оракул.
- CRLF в строке `// NOVAC_TWIN` — код близнеца от 2026-10-03, вне цели.
- `wait -n` в `gate-novac.sh` и шаг prune в `nova-gate.yml` — вне цели.
