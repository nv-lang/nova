# A — `check-ratchet-moves.sh`: правило про СЛИЯНИЕ, замер по НЕЗАКОММИЧЕННОМУ диффу

Класс: К4 (страж отвечает на соседний вопрос, а читается как ответ на заданный).
Семья: «страж судит рабочую копию, вердикт — о публикуемом объекте» (реестр №1118).

## 1. Вердикт дословно

Шапка, `scripts/guards/check-ratchet-moves.sh:1-2`:

> сдвинул храповик, напиши почему **ТЕМ ЖЕ СЛИЯНИЕМ** (274 §10.4)

Зелёные строки (строки 66 и 116):

> `check-ratchet-moves ok: сдвигов храповиков в диффе нет`
> `check-ratchet-moves ok: файлов с сдвигом храповика: N, сдвигов без причины: 0`

Текст отказа (строка 110) повторяет предмет: «причина обязана приехать
**тем же слиянием**».

## 2. Что читает физически

`scripts/guards/check-ratchet-moves.sh:59-63`:

```
git -C "$GITDIR" diff --cached -- 'scripts/guards/*.baseline' > "$TMP/d"
if [ ! -s "$TMP/d" ]; then
    git -C "$GITDIR" diff -- 'scripts/guards/*.baseline' > "$TMP/d"
fi
```

То есть индекс, а если он пуст — рабочая копия. **Коммит не читается никогда.**
Вердикт не называет, какой из двух объектов прочитан.

## 3. Расхождение

`A-ratchet-moves-committed-shift/cmd.sh` — одноразовая репа, четыре состояния
(`output.txt`):

| состояние | что в коммите | вердикт стража |
|---|---|---|
| 1. чисто | ничего | `ok: сдвигов храповиков в диффе нет` |
| 2. сдвиг в индексе, причины нет | сдвиг поедет | `FAIL` — верно |
| 3. **тот же сдвиг УЖЕ закоммичен, причины нет нигде** | **сдвиг уехал** | `ok: сдвигов храповиков в диффе нет` |
| 4. сдвиг только в рабочей копии, в коммит не поедет | **ничего** | `ok: файлов с сдвигом храповика: 1` |

Состояние 3 — неоправданный сдвиг храповика лежит В СЛИЯНИИ, страж зелен.
Состояние 4 — слияние не несёт сдвига вовсе, страж записывает сдвиг в его актив.

## 4. Почему это не теоретический край

`scripts/gate.sh:595` зовёт стража как `check-ratchet-moves.sh "$ROOT"` (второй
аргумент опущен → `GITDIR=ROOT` = настоящее дерево), ярус `loop`.
`scripts/tools/push-after-gate.sh:55-60` ОТКАЗЫВАЕТСЯ запускать гейт на грязном
дереве (`DIRTY=$(git diff --name-only HEAD | wc -l)`). Значит в санкционированном
порядке работы страж всегда встречает состояние 3: всё уже закоммичено, оба диффа
пусты, «сдвигов в диффе нет» печатается по построению.

## 5. Воспроизведение

```sh
bash docs/dev/hunts/guards/probes/2026-09-16-worktree-vs-published/A-ratchet-moves-committed-shift/cmd.sh
```

(из корня репы; путь к стражу берётся `git rev-parse --show-toplevel`,
абсолютных путей внутри нет). Рабочее дерево не трогается: проба заводит
собственную репу в `mktemp -d` и удаляет её за собой.
