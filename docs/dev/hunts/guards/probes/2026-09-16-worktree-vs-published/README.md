# Охота 2026-09-16, трек `guards`: «страж мерит рабочую копию, вердикт — о публикуемом объекте»

Клетка: семья стражей, у которых предмет суждения — коммит / индекс / то, что
увидит клон или CI, а физический вход — рабочая копия (или наоборот).
Класс К4 в переводе на стражей: страж отвечает на СОСЕДНИЙ вопрос, а его строка
читается как ответ на заданный.

Дом класса: реестр `docs/plans/221.1-bug-sweep.md`, строка **№1118**.

Проверено 14 стражей из 203 файлов `scripts/guards/check-*`; шесть находок ниже.
Ни одна проба не правит рабочее дерево: каждая заводит собственную репу в
`mktemp -d` и удаляет её за собой; проба E — только чтение настоящего дерева.
