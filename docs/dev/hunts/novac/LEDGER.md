# Леджер охот трека novac

Карта прошедших охот: по строке на свёрнутый отчёт. Отчёт сворачивается сюда,
когда его находки заведены в реестр (`docs/plans/221.1-bug-sweep.md`) с меткой
`НАЙДЕНО ОХОТНИКОМ <дата> (novac)`; файл отчёта и его пробы при этом удаляются
из дерева (история git хранит полный текст). Формат строки и правила свёртки —
дом `scripts/guards/check-hunter-fold.sh` (шапка); здесь формат не повторяется,
чтобы копии не разошлись.

Открытые отчёты лежат рядом в этом каталоге; их пробы — в `probes/<stem>/`.
