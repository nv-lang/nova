# Охота: lex × К2 (2026-08-30)

Второй прогон охотника плана 278 Ф.4. Модель агента: **opus** (defect-hunter),
~50 проб (escape, сырые управляющие байты, комментарии, числа во всех формах,
границы токенов, юникод/BOM, интерполяция, свип на паники). Находки сверены
окном запуском из каталога каждой пробы.

Оракул: `nova-cli/target/release/nova.exe`. novac:
`nova-p274/novac/target/novac.exe`, `NOVA_STD_PATH=…/std/src`.

## Находки

НАХОДКА | К2 | lex | num_2pow64 | novac rc=0 принял тихо / oracle rc=1 «number too large to fit in target type» | целый литерал 2^64 (18446744073709551616) сверх потолка u64; novac пропускает программу, которую эталон отвергает
НАХОДКА | К2 | lex | num_huge | novac rc=0 принял тихо / oracle rc=1 «number too large» | тот же корень, второй свидетель: 37 девяток; величина десятичного литерала не проверяется НИГДЕ

Один корень: величина десятичного целого литерала не проверяется по всей цепочке
novac — лексер `lex.nv:378-411` делает IntLit из любого прогона цифр без границы;
`check/type_of.nv:157` типизирует IntLit как int без range-чека; `emit_c.nv:597-600`
печатает текст литерала + «LL» дословно, из-за чего 2^64 переполняет signed 64-бит
`long long` в эмитированном C — тихий miscompile, а не только пропущенный отказ.
Два свидетеля, один фикс (range-чек величины). Адреса сверены окном по дереву.

## Что обошёл и почему

- Escape в строках: novac валидирует строже оракула (`check/strings.nv`) — опасного
  направления нет; `\x \u \u{} \0` — отставание подмножества, не находка.
- Сырые CR/TAB/NUL в строке, BOM, кириллица в идентификаторе, doc/хвостовые
  комментарии, блочные `/* */` (нет ни у кого) — выровнено.
- Числовые формы `1_000, 1u8, 0x1F, 0b101, 1e9`: novac корректно отвергает,
  исторического misread нет; переполнение float оба принимают (оракул чекает
  величину только INT-литералов).
- Границы токенов, интерполяция: расхождения только «оракул принял, novac отверг
  подмножеством» либо оба отвергли — не находки.
- Паники: свип по пунктуации и вырожденным входам — ни одной; свой мега-CU не
  гонял.

## Противоречия

Источник против источника — нет. Не-дефект для прозрачности: невалидный UTF-8 —
novac rc=2 (документированная «дверь»), оракул rc=1; оба отвергают, механизм
разный, дверь novac санкционирована его контрактом.
