# Охота: check × К1 (2026-08-30)

Третий прогон охотника плана 278 Ф.4. Модель агента: **opus** (defect-hunter).
Материал — живые законные программы оракула (`spec_tests/conformance/standalone`
210 файлов, `examples` 62) плюс прицельные within-subset пробы. Находки сверены
окном из каталога каждой пробы; развилка find2 разрешена окном по спеке.

Оракул: `nova-cli/target/release/nova.exe`. novac:
`nova-p274/novac/target/novac.exe`, `NOVA_STD_PATH=…/std/src`. Находка второго
рода = novac молча (rc0) принимает то, что оракул честно отвергает (не «оба
ложно принимают» из леджера №652 — там оба rc0).

## Находки

НАХОДКА | К1 | check | find1_dup_type | novac rc0 принял тихо / oracle rc1 «duplicate top-level name Pt» | два `type Pt {...}` одного имени с конфликтующими телами; novac резолвит против одного и не замечает коллизии — резолв-дыра
НАХОДКА | К1 | check | find2_empty_record | novac rc0 принял тихо / oracle rc1 (отвергает) | `Pt { }` при обязательном поле `n` — novac принимает конструкцию БЕЗ обязательного поля. Спека (`02-types.md:152,1677`: «construction всегда требует все обязательные поля») отвергает такую форму, значит неправ novac, а не оракул. Механизм отказа у оракула другой (E_STMT_SEP_MISSING — читает `Pt {}` как выражение + блок), но ВЕРДИКТ оракула по спеке верный

Развилка, которую охотник честно оставил окну («законен ли пустой литерал?»),
разрешена по спеке: пустой/частичный литерал записи с пропущенным обязательным
полем незаконен (`02-types.md:152, 514, 1677`), и оракул подтверждён пробой —
даже zero-field `type U {}` он не читает как литерал (E_STMT_SEP_MISSING). Сторона
выбрана не мной, а нормой.

## Что обошёл и почему

- `E_NOVAC_ICE` на межмодульном вызове из std (`import std.unicode`) — уже
  зарегистрировано `[LEGACY-#700-user-error-as-ice until:E2b3]` (novac-divergences.md),
  известный незакрытый этап, не новое расхождение.
- Тип-несоундность, где ОБА принимают (`fn f() -> int => "str"`, неизвестное
  поле, частичная запись) — задокументированный совпад №652 (novac-divergences.md:147).
- Честные `E_NOVAC_SUBSET` (интерполяция, протокол-операторы, многополе через
  запятую, локальный тип, индекс, ctor-в-аргументе, перегрузка) — незакрытый этап.
- Не-standalone conformance (1912) и `std/src` (311) целиком не прогонял —
  ~0.9с/файл не влезало в бюджет; шёл прицельными батареями. Честный пробел.

## Противоречия

неправ). Иных противоречий, где выбор не окна, не встретил.
