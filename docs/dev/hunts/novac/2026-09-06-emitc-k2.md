## 2. Что обошёл и почему

- **Остальные формы без носителя среди эмитируемых.** Перепись p02 покрывает только формы, которые
  перенесла волна M2b-1; систематический вопрос «для каждой ветки принтера — есть ли эмитируемый файл»
  записан в план 274.8 §3 как задача до M2b-2 (порча литерала → пересборка → корпус → число файлов,
  ~2 часа машины частями) — не сегодня, машина в очереди из трёх окон.
- **Отступы принтера `match`** (8 пробелов у биндеров арма против 4 у всех прочих строк тел) — не
  дефект поведения, а препятствие побайтовой приёмке среза (г); записано в план 274.8 §2а как микросрез
  (г0), охотой не считаю.
- **Доступ к payload варианта всегда `->`** (`emit_match.nv:191`: `_novac_scr_tN->payload.V._i`), тогда
  как тест тега выбирает `.`/`->` по размещению суммы (A4). Для суммы-значения это был бы невалидный C —
  но есть ли в подмножестве сумма-значение с payload, до которой доходит `match` с биндерами, я не
  проверил: без пробы это подозрение, не находка. Кандидат на пробу следующей охоты по той же клетке.
