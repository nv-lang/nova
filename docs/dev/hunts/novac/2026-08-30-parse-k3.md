# Охота: parse × К3 (2026-08-30)

Первый прогон охотника плана 278 Ф.4. Модель агента: **opus** (defect-hunter).
Цель назначена окном; находки сверены окном запуском из каталога каждой пробы
(`nova check` тянет папку как модуль — из чужого каталога novac отвечал rc=2
«дверь», из своего — реальным вердиктом; сверка это поймала).

Оракул: `nova-cli/target/release/nova.exe`. novac:
`nova-p274/novac/target/novac.exe`, `NOVA_STD_PATH=…/std/src`. Коды novac:
0 принял / 1 отверг диагностикой / 2 дверь; 127 (STATUS_STACK_OVERFLOW) — паника.
novac реализует ПОДМНОЖЕСТВО, поэтому «оракул принял, novac отверг подмножеством»
НЕ находка; находка — паника либо тихий приём того, что оракул отвергает.

## Находки

НАХОДКА | К3 | parse | parens513 | novac rc=0 принял тихо / oracle rc=1 E_NESTING_TOO_DEEP | у оракула предел вложенности 512 (№800), у novac счётчика глубины нет — глубина 513 проходит молча
НАХОДКА | К3 | parse | parens2500 | novac rc=127 stack overflow / oracle rc=1 E_NESTING_TOO_DEEP | тот же корень на большей глубине даёт КРАХ рекурсивного спуска вместо диагностики; порог novac ~1800 принимает / ~2000 падает
НАХОДКА | К3 | parse | brace_only_fn | novac rc=0 принял тихо / oracle rc=1 unexpected EOF | функция с незакрытым телом `fn main() {` без `}` принимается: `@push_if(RBrace)` при отсутствии `}` молчит, Err-узел не сажается (для отсутствующего тела `if` — сажается: разошедшаяся форма одного правила)

Первые две — один корень (нет стража глубины в `@expr`/`@block` рекурсивного
спуска novac), два наблюдаемых поведения; третья — отдельный корень (опциональная
`}` в `@block`).

## Что обошёл и почему

- Statement-level путь к краху (вложенные блоки/`if`): novac упирается в
  subset-стену раньше рекурсии (`{` в позиции утверждения читается как
  record-constructor, E_NOVAC_SUBSET) — до краха там не дойти этим путём.
- Незакрытые `(`/`"`, trailing `+)`, одиночная `)`: оба отвергают, разница только
  в тексте диагностики — по «оракул не донор» не находка.
- Вырожденные (пустой файл, пустое тело, унарные цепочки): расхождения нет.
- Строковая интерполяция, match-вложенность, приоритеты вне `+ - * /`: не дошёл,
  честный пробел (бюджет ушёл на два подтверждённых корня).

## Противоречия

Источник против источника — не встретил. Для триажа (выбор не охотника):
архитектура novac заявляет инвариант «recovery never panics or hangs / the
parser refuses it instead of running out of stack» (`novac/src/parse/parse.nv`
заголовок), а находка parens2500 (rc=127) прямо ему противоречит.
