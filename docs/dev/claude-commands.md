# Слэш-команды проекта: где живут и что про них измерено

**Кому:** окну, которое заводит или правит команду в `.claude/commands/`. Здесь только
то, что проверено запуском; правила работы самих команд — в их файлах.

## Где живут и почему в репе

`.claude/commands/*.md` — **отслеживаются** (исключение в `.gitignore` рядом с
проводкой хуков). Довод тот же, что у хуков: команда есть механизм, а механизм обязан
ехать вместе с деревом, иначе свежий клон, другая машина или другой аккаунт получают
репозиторий без него. Личная копия в `~/.claude/commands/` даёт вторую истину — она
молча расходится с проектной, и два окна получают разные правила из команды с одним
именем.

Шапку каждой команды судит `scripts/guards/check-claude-commands-frontmatter.py`
(в `gate.sh`, ярус `loop`): шапка обязана парситься и нести непустой `description`.
Повод — 2026-08-23: из четырёх новых команд ДВЕ несли двоеточие внутри значения
`description`, YAML читал остаток строки как вложенное отображение, и команда
работала наполовину, молча. Значения в шапке берутся в двойные кавычки.

## `@путь` в теле команды разворачивается — измерено 2026-08-23

Ссылка вида `@docs/dev/recheck-common.md` в теле команды **втягивает содержимое файла**
в ввод до первого действия агента: харнесс сам делает `Read` названного файла. Проверено
канареечной пробой — уникальное слово в файле под `.gitignore`, команда с прямым
запретом читать: слово приехало, а `Read` в логе стоит ДО первого слова агента, то есть
вызов не его.

Два следствия, важные для следующего замера:

* критерий «импорт работает, если не было вызовов инструмента» **негоден**: механизм и
  есть вызов, просто харнессовый. Судить надо по тому, приехал ли текст без решения
  агента его читать;
* `allowed-tools: ""` в шапке команды развёртывание **не** ограничивает.

Поэтому общие части подключаются через `@` (`/next` тянет `flow` и `delegate`, оба
`*-recheck` — `docs/dev/recheck-common.md`), а фраза «не приехало — прочитай сам»
оставлена дешёвым поясом, а не основным механизмом.

## Прочее, проверенное на себе

* **Новая команда появляется в меню только после перезапуска панели** — список
  собирается при старте сессии. Правка ТЕЛА уже известной команды перезапуска не
  требует.
* **Настройки папки перебивают пользовательские, а не дополняют их:** блок `[nova]` в
  `.vscode/settings.json` worktree отменил одноимённый блок из `%APPDATA%\Code\User`.
  Правило общее для настроек VS Code, но найдено здесь — на выключении семантической
  подсветки для `.nv`.
* **Имя команды — латиница, нижний регистр, дефисы.** Тело и аргументы могут быть
  по-русски: `$ARGUMENTS` принимает весь остаток сообщения, включая переносы строк.
