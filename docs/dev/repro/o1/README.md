# Репро класса О-1 — готовые фикстуры для волны 196

**Класс.** Решение принимает один слой, до следующего оно не доезжает. Общий
признак: `nova check` проходит, а собранная программа либо не компилируется,
либо отвечает неверно. Экземпляры собраны окном 274 за 2026-08-17; каждый
проверен на бинаре той же даты и лежит здесь отдельной папкой (папка = один
модуль Nova, поэтому каталог на случай).

**Как гонять.** Из корня дерева:

    nova check docs/dev/repro/o1/<случай>/t.nv
    nova build docs/dev/repro/o1/<случай>/t.nv -o /tmp/probe.exe && /tmp/probe.exe

| папка | что показывает | ожидание после фикса |
|---|---|---|
| `716_nova_text_in_c` | в `t.c` попадают идентификаторы `found`, `Option`, `nv_int` — текст Nova напечатан в C дословно | собирается, печатает 10 |
| `716b_option_of_record` | `[INTERNAL-PANIC] E_CODEGEN_TYPE_UNKNOWN` на методе, тип возврата которого чекер знает | собирается, печатает 7 |
| `677_never_in_tail` | `never` лоуэрится как `nova_int`; на `-> str` C отвергает, на `-> int`/`-> bool` собирается и РАБОТАЕТ | собирается, печатает `zero` |
| `676_var_index_method` | метод на элементе по ПЕРЕМЕННОМУ индексу: приёмником считается `Vec` (`E_RECV_METHOD_MISMATCH`) | собирается, печатает 7 |
| `o1g_const_in_pattern` | именованная `const` как ОБРАЗЕЦ: `check` ok, C — доступ к тегу у байта | собирается, печатает 2 |
| `o1v_tail_if_unreached` | `check` принимает; сборка падает ТОЛЬКО если функция вызвана | вердикт не зависит от достижимости |
| `o1b_self_initializer` | имя видно в собственном инициализаторе и читается как ноль: печатает 100 вместо 107 | печатает 107 либо форма отвергается спекой явно |

## Состояние на 2026-08-26 — все восемь перегнаны заново

Перепроверено интегратором на `0b9a4cdd0` (бинарь того же дня, после слияния 410
коммитов ветки 274). Столбец — что происходит СЕЙЧАС, а не что было 17-го:
восемь запусков стоят дешевле, чем одно решение по устаревшей карте. `nova check` чист у ВСЕХ
восьми — это и есть подпись класса.

| папка | сейчас |
|---|---|
| `676_var_index_method` | ЖИВА — сборка падает `E_RECV_METHOD_MISMATCH` |
| `676b_var_index_silent` | ЖИВА и ТИХА — собирается, печатает 1 (длина вектора) вместо 3 |
| `677_never_in_tail` | **ИСПРАВЛЕНА** — собирается, печатает `zero`, то есть ожидание сверху |
| `716_nova_text_in_c` | ЖИВА — сборка падает, 7 ошибок C |
| `716b_option_of_record` | ЖИВА — сборка падает |
| `o1b_self_initializer` | ЖИВА и ТИХА — собирается, печатает 100 вместо 107 |
| `o1g_const_in_pattern` | ЖИВА — сборка падает, 4 ошибки C |
| `o1v_tail_if_unreached` | ЖИВА — сборка падает (функция вызвана) |

**Что из этого следует.** Семь из восьми живы спустя девять дней и четыреста десять
коммитов — то есть пакет не устарел, и брать его в работу можно как есть. Две тихие
(`676b`, `o1b`) важнее шести громких: громкую сборку находят за минуты, неверное число —
никогда. А `677` уже ЗАКРЫТ в реестре (2026-08-19), и его репро теперь служит не
задачей, а ПРОВЕРКОЙ НА РЕГРЕСС — и это независимое подтверждение его закрытия,
которого требует оговорка «фикс носителя приёмкой не считается».

**Зачем пакет.** Координатор просил складывать репро, а не обходить экземпляры
маркерами: каждый станет фикстурой волны. Семь случаев — это семь разных
дверей одного корня, и фикстура на каждую дешевле, чем одна на «класс вообще».
