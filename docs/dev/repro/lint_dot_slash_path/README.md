# `nova lint ./путь` молча не находит файлов

Замер 2026-08-18, из корня дерева, один и тот же каталог:

```
$ nova lint novac/src
lint: 27 file(s), 0 finding(s)

$ nova lint ./novac/src
no .nv files to lint            # код возврата 0

$ nova lint ./novac
no .nv files to lint            # код возврата 0

$ nova lint .//novac/src
no .nv files to lint            # код возврата 0
```

Достаточно ведущего `./`, чтобы линт перестал видеть файлы. Отказа нет,
код возврата ноль.

**Почему это важнее, чем выглядит.** `nova lint ./src` в скрипте или в CI
печатает «нет замечаний» и не проверяет НИЧЕГО. Тихий ноль вместо работы —
тот же класс, что и молчаливо пустой прогон тестов: зелёное там, где
проверка не состоялась.

**Как нашлось.** `check-novac-lint.sh`, вызванный с относительным корнем
(`bash scripts/guards/check-novac-lint.sh .` из `d:/Sources/nv-lang/nova-p274`),
собрал аргумент `./novac/src` и получил «no .nv files to lint». Страж не
поверил непонятому выводу и покраснел — он повёл себя правильно, но
сообщение звучало как «сломан раннер», и искать пошли не там.
