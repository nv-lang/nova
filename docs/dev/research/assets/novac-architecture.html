Архитектура novac: компилятор Nova, написанный на Nova

novac architecture: the Nova compiler written in Nova

Один конвейер из тринадцати модулей, один писатель семантической модели, один владелец порядка проходов — и нынешний компилятор рядом не как образец, а как неподвижная точка поведения: тот же stdout, тот же код возврата, байт в байт.

One pipeline of thirteen modules, one writer of the semantic model, one owner of the pass order — and the current compiler beside it not as a model to copy but as a fixed point of behaviour: same stdout, same exit code, byte for byte.

Три решения, которые держат форму

Three decisions that hold the shape

Один писатель. Семантическую модель sem пишет только check; mono и emit_c читают канал и ничего не выводят сами — поэтому эмиттеру не нужно ребро к чекеру.

One writer. Only check writes the semantic model sem; mono and emit_c read the channel and infer nothing themselves — which is why the emitter needs no edge to the checker.

Один владелец порядка. pipeline — единственный, кто зовёт фазы; снаружи — compile(files, cfg), внутри — ни обхода файловой системы, ни резолва пакетов: это дело драйвера на Rust, который остаётся как есть.

One owner of order. pipeline alone calls the phases; outside — compile(files, cfg), inside — no file-system walk and no package resolution: that is the Rust driver's job, and it stays as it is.

Одна дверь для имён. C-имена печатает только sem/mangle, и мэнглинг односторонний: из имени ничего не читают обратно; страж сверяет напечатанные имена с оболочкой после факта, Ctx.interop — до.

One door for names. Only sem/mangle prints C names, and mangling is one-way: nothing is ever read back out of a name; a guard checks the printed names against the shell after the fact, Ctx.interop before it.

Как это судится

How it is judged

Корпус. 61 файл примеров прогоняется обоими компиляторами: совпал ли вердикт проверки (11) и собрался ли файл байт в байт с тем же поведением (5). Цифры — храповик: вниз только с записанной причиной.

The corpus. 61 example files run through both compilers: did the check verdict match (11), did the file build byte-identical with the same behaviour (5). The numbers are a ratchet: down only with a written reason.

Стражи. 76 проверок только для novac: размер файла, полнота ветвлений, документированность, одностороннее мэнглинг, отсутствие аллокаций в дверях поиска, свежесть живой строки плана — каждая с самотестом, который умеет краснеть.

Guards. 76 checks for novac alone: file size, complete branching, documentation, one-way mangling, no allocation in lookup doors, freshness of the plan's live line — each with a selftest that knows how to go red.

Отказ по имени. Всё вне подмножества компилятор отвергает диагностикой, которая называет форму и причину; молчаливое принятие не-языка — худший вид расхождения, и его ищут отдельно.

Refusal by name. Everything outside the subset is refused with a diagnostic that names the form and the reason; silently accepting non-language is the worst kind of divergence, and it is hunted separately.
