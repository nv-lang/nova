## Три двери (чартер)
1. walk: флаг позиции значения with-биндинга. Геометрия парсера: `with`, name, `=`,
   handler, (`,`, name, `=`, handler)*, body Block => handler на at % 4 == 3.
2. типизация: сигнатура из ЕДИНСТВЕННОЙ операции эффекта (EffectDef), тело — handler-method
   по D61; переиспользовать параметры/захваты/scope closure-light; двухоп — отказ по D31
   (обязателен handler-литерал); обе формы лямбды (выражение и блок) — D22 п.6.
3. эмиссия: vtable NovaVtable_<E> (fn+ctx), НЕ NovaClosBase; образец emit_handler.nv.

## ИЗМЕРЕНО 2026-11-19 (важно)
walk-only дверь (добавить позицию, типизацию не трогать) НЕБЕЗОПАСНА: литерал в слоте
проходит walk, типизация его молча не типизирует (в main нет ClosureLit-арма в @type_expr),
и check-чистая программа дойдёт до emit как untyped -> ICE. Проба p2 после walk-only:
первая диагностика ушла на дверь хвоста тела ("fn declares a return type but its body ends
without a value"), но чистого пути нет — дверь без типизации оставляет дыру.
=> ВЫВОД: двери walk+типизация должны садиться ОДНИМ логическим куском (или walk-дверь
временно закрыта именованным отказом слотового уровня, но это не прогресс).
Э.11-опыт это подтверждает: там is_expr_kind + @type_expr-арм садились вместе.

## НАХОДКА 2026-11-19 (влияет на объём чартера)
`interrupt` НЕ существует в novac на уровне парсера/чекера:
- lex/lex.nv:380 — "KEYWORD-PARITY: interrupt -- debt (E2, the effects/consume horizon)";
- в reserved-словах (builtins.nv:775), но ключом не лексится;
- в parse/ и check/ нет ни узла Interrupt, ни арма.
Значит каноническое тело handler-лямбды из D31 (`|err| interrupt v`) Карина сегодня
распарсить/типизировать НЕ МОЖЕТ. Носители корпуса (L074/L078/L081), наоборот, пишут
БЛОЧНОЕ тело БЕЗ interrupt (`|_e| { timed_out.store(true) }`), и оракул его принимает.

Следствие для чартера: pos-фикстура «Fail-лямбда с interrupt» (пример D31) невозможна без
реализации interrupt = долг горизонта E2 (эффекты/consume), больше волны D31. Варианты:
(A) сузить волну до носителей: лямбда с единственной операцией, тело без interrupt (блок
    или выражение); `interrupt` остаётся отказом по имени (unknown name, E2-долг) —
    документированно; pos = Fail-лямбда блок-телом с захватом (p6) + выражение-форма;
    neg = двухоп (D31), interrupt-тело (E2-долг); смоуки байт-в-байт на p6.
(B) включить interrupt в волну — выход за чартер, нужен D-блок/этап E2 и решение интегратора.
