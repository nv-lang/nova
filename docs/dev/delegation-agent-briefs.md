## Агент-читатель: форма выдачи обязательна

Агенту, читающему спеку, конвенции или планы, задание даётся по форме. Полная форма с
причинами — в `.claude/agents/spec-reader.md` (грузится, только когда агент реально
запущен); здесь — то, что связывает тебя при составлении брифа:

- **строка на правило:** «требование одной фразой — файл, раздел → что это значит для
  ЭТОЙ задачи». Без «что это значит» строка бесполезна;
- **три раздела обязательны, даже пустые:** применимые правила · чего в документах нет
  · противоречия (оба места дословно, **выбор не агента**);
- **выдача агента — не основание для блокирующего решения.** Решают стражи и
  документы; «агент сказал» не закрывает строку реестра и не двигает базу;
- **факты о дереве, названные агентом, сверяет вызывающий — до использования.**

## Агент-охотник: цель назначаешь ты, вердикт — не его

Для охоты за дефектами по клетке (подсистема × класс К1–К7) есть отдельное
определение — `.claude/agents/defect-hunter.md` (план 278; модель opus, потому
что это разведка и суждение о формах). Что связывает тебя при постановке цели:

- **клетку называешь ты** — одну, а не список; живое подозрение окна — самая
  точная наводка. Трек тоже называешь ты, и треков ДВА: novac и guards (охота на
  сами стражи — слово владельца 2026-09-04), у каждого свои правила охоты и
  свой каталог `docs/dev/hunts/<трек>/`;
  трек `oracle` ЗАКРЫТ 2026-09-16 (владелец): охота ищет НОВЫЕ дефекты, а его
  названные чинит план 274.10 — это не охота;
- **находка приезжает файлом-пробой в своём пустом каталоге** — отчёт без
  файла и команды не принимается. Принимая отчёт, ты переносишь цитируемые
  пробы (и не меньше трёх) в `docs/dev/hunts/<трек>/probes/<имя-отчёта>/` —
  без проб в дереве отчёт не двигает часы долга (278 Ф.5/Ф.6);
- **его отчёт ничего не закрывает**: строку реестра заводишь ты, с меткой
  `НАЙДЕНО ОХОТНИКОМ <дата> (novac|oracle|guards)` — без метки и трека меру плана 278
  не посчитать грепом. Страж/фикстуру, которая удержит класс, пишет тот, кто
  ЧИНИТ дефект (для novac — окно 274), не охотник и не ты как регистратор.
