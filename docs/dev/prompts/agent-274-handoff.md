## Правила, выведенные из вопросов владельца 2026-08-22 (все с механизмом)

* **`?` для раннего возврата, не `?? return`** — D86 отвергает второе: `??`
  подставляет значение, ранний возврат это поток управления. `?` там, где у
  функции ЕСТЬ обёртка для проброса; явный `match` там, где её нет (функция
  отдаёт `()`), — так же говорит подсказка самого отказа;
* **завёрнутый индекс сравнивают завёрнутым**: `raw_X(a) == raw_X(b)` сравнивает
  два `int` и пропустит сравнение ДВУХ РАЗНЫХ пространств. Страж
  `check-novac-no-unwrap-compare.py`;
* **курсор с шагом один — это диапазон**: `for i in X..Y`. Страж
  `check-novac-cursor-is-range.py`. Законен `while`, если шаг не единица или
  условный;
* **`_` законен ТОЛЬКО как отказ** (`ice`/`@refuse`) — не как значение; компактная
  исчерпаемая форма это ИЛИ-паттерн `A(_) | B(_) => …`;
* **`if Some(x) = …`** выигрывает, когда второму случаю есть что сказать
  (значение или терминатор), и проигрывает, когда нечего: П31 всё равно требует
  `else` с причиной, и тогда форма длиннее плеча `match`.

## Дефекты ОРАКУЛА, найденные и эскалированные (канал 196)

Все четыре в `docs/dev/novac-divergences.md` с минимальными репро:

1. **ro-launder не снимает newtype до носителя**: `fn f(v int) -> int => v`
   компилируется, `fn f(r Row) -> Row => r` над `type Row int` —
   `E_READONLY_COERCE`. Бьёт по КАЖДОЙ волне заворачивания; обход — дверь
   `types.same_ty` под `[LEGACY-#TBD-newtype-ro-launder]`;
2. **эмиссия зависит от ПОРЯДКА объявлений**: newtype в плече суммы, объявленный
   ниже неё, эмитится боксированным `struct Nova_X*` и сталкивается со своим же
   `typedef nova_int Nova_X`. Изолировано на 12 строках. Обход — объявление в
   первом файле модуля под `[LEGACY-#TBD-newtype-order-in-sum-arm]`;
3. **перегрузка `main`**: `check` принимает, clang даёт `redefinition of
   'nova_fn_main_impl'` и `use of undeclared identifier`. Причина у оракула та же,
   что была у novac: точка входа определялась СРАВНЕНИЕМ ИМЕНИ. У novac починено
   (`is_entry_fn` — три факта о строке);
4. **разбор записи по НЕСУЩЕСТВУЮЩИМ полям** проходит `check` и падает в clang.

следующего: **ставя стража в ярус loop, замерь его** — loop это цикл правок
`.nv`, и он обязан оставаться дешёвым; всё, что меняется вместе со стражами,
судится в push, потому что правящий стража гоняет push.
