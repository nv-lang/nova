## Что сделано этой сессией и чем доказано

**№809 — закрывающая скобка была необязательной в шестнадцати местах.** Охотник
нашёл носитель (`fn main() {` без `}` → код 0, ни одной диагностики), перепись
нашла остальные пятнадцать. Дверь `@push_closer` (`novac/src/parse/expect.nv` —
файл выделен тем же слиянием, `parse.nv` перевалил 1000 строк) сажает Err-лист.

**Правило, когда ей говорить, стоило ЧЕТЫРЁХ отвергнутых формулировок**, и
каждую отверг ПРОГОН, не чтение: флаг «синтаксис назван один раз на файл»
схлопывал две раздельные причины; «Err среди прямых детей» смотрел на уровень
выше поломки; без условия конца файла ловилась рассинхронизация курсора; признак
нулевой ширины не срабатывал из-за порядка обхода. Живое правило: **пара —
причина, только если файл КОНЧИЛСЯ и конструкция при этом цела.** Сверено с
оракулом поштучно на пяти файлах.

**№812 — поля конструкции записи не сверялись с объявлением.** Причина была не
«нет механизма»: `field_range_of` уже жил в `sem`, чекер в эту дверь не заходил.

**Обе обратные пробы сняты:** со снятой посадкой Err падает ровно тест #809, со
снятым вызовом правила — ровно тест #812.
