## Что построено (устройство, а не история)

- **Каркас:** `novac/src/{source,lex,tree,parse,check,names,builtins,sem,emit_c,diag,pipeline,main}`.
  Зелёное дерево lossless (`reserialize(lex(src)) == src`), Err-узлы вместо падений,
  диагностика §7-JSON через serde. Архитектура и таблица рёбер —
  `docs/dev/novac-architecture.md` (§2 карта, §3 рёбра — вход стража deps);
  конвенция — `docs/dev/novac-compiler-conventions.md` (П1–П14; каждое правило со
  стражем; П15–П19 — заводятся волнами 274.3).
- **sem** — семантический слой (rustc_middle-модель): реестр типов `Ctx.types`
  (value-записи `TypeDef`, id = индекс), `DefTable`/`FieldTable`/`Scope` (таблица имён
  + строки одной записью), `Prims` (CommonTypes), `type_of`. **`sem/mangle`** —
  единственная дверь C-имён, держится диффом с оракулом (`check-novac-mangle-fixed-point.sh`).
- **builtins** — лист-модуль, единственное место строковых имён языка (universe
  примитивы с ABI-именами, `ENTRY_FN`/`PRINT_FN`, `[LEGACY-SUBSET Э2-б]` str-метод-таблица);
  страж `check-novac-no-name-hardcode.sh`. Инстансы дженериков и C-имена неприм. типов там
  ЗАПРЕЩЕНЫ (вердикт владельца).
- **emit_c** — только C-рендер по формам оракула (записи — GC-указатели, суммы —
  tag+union+maker, match — if-цепочка). Оболочка `shell.tpl.c` генерится **машиной** из
  зонтичного probe (`novac/probe/shell_probe.nv` → `scripts/tools/novac-regen-shell.sh`).
- **Подмножество взято (байт-в-байт с оракулом):** hello, arithmetic, strings, records,
  match_demo. **demo.nv откачен** (был взят захардкоженным `[]int` — К7; вернётся через
  `mono`, Э2-б). Храповик 11/5.
- **CLI:** `novac check f1 f2 …` (батч, exit = худший), `novac emit f` (C на stdout).
- **Цикл — секунды (274.2, П14):** смоук `novac-e1-smoke.sh` 1.7 с тёплый (кэш эталона +
  argv оракула через `NOVA_CLANG` + PCH + lld), фаззер батчем 16 с, дифф-раннер 50–68 с;
  бюджеты — храповик в обе стороны.

## Приёмка волны — что гонять перед каждым коммитом (порядок и цена)

```sh
ORACLE=d:/Sources/nv-lang/nova/nova-cli/target/release/nova.exe   # оракул главного дерева
taskkill //F //IM novac.exe >/dev/null 2>&1; "$ORACLE" build novac/src/main.nv -o novac/target/novac.exe   # ~6-14 с
for f in hello arithmetic strings records match_demo; do sh scripts/tools/novac-e1-smoke.sh examples/basics/$f.nv | tail -1; done   # 5 × 1.7 с
for t in novac/src/*/*_test.nv; do timeout 200 "$ORACLE" test "$t" | grep -E "^PASS:|^FAIL" | tail -1; done   # первый прогон после сборки может ударить в кэш — перегнать
sh scripts/tools/novac-fuzz-mutations.sh 40 | tail -1                     # 16 с, паник 0
timeout 200 "$ORACLE" lint $(find novac/src -name '*.nv' ! -name '*_test.nv') | tail -1
for g in scripts/guards/check-novac-*.sh; do NOVAC_CORPUS=0 sh $g >/dev/null 2>&1 || echo "КРАСНЫЙ: $g"; done   # 21 страж
sh scripts/guards/check-novac-differential.sh | tail -2                     # храповик корпуса, ~50-70 с
```
Плюс: строка в `docs/dev/novac-time-ledger.md` (страж time-ledger; **сумма долей за дату ≤ 1.0** —
страж F4 волны 1), живая строка §9 — тем же коммитом; `git add` по именам; `shell.tpl.c` —
`git add -f` (`.gitignore *.c`); в сообщении коммита — `274.3/F<N>` при закрытии находки.

## Инварианты, за которые кусают стражи (21 + lib)

deps (рёбра только из §3) · no-naked-panic (только `ice()`; **схема ждёт спеки — см. К-I**) ·
no-string-keys · resolve-discipline (без тихих int-дефолтов и линейных сканов имён) ·
no-name-hardcode (П5) · mangle-fixed-point · type-field-docs (П13: `///` у типа/функции, у поля
— trailing или над полем; строгость по пину ≥ 9a69411b3 — уже строгий) · file-size (≤1000) ·
differential (фикстуры + храповик корпуса в обе стороны + бюджет цены) · iteration-cost (П14) ·
diag-schema · no-cascade · no-panic · legacy-workarounds · time-ledger · и др.
Общая библиотека `scripts/guards/lib/novac.sh`: `novac_require_bin` (при существующем
`novac/src/main.nv` без бинаря — КРАСНЫЙ, не «судить нечего»), `novac_is_panic_rc`
(паника = exit ≠ 0 и ≠ 1).

Правила процесса: спека до кода; изменение языка — амендмент D-блока в том же слиянии
(бриф интегратору, как D104 rev-2 — образец в журнале: точки в оракуле по живому коду,
решение владельца, порядок, запреты); маркеры самоистекающие; блокер не ждать — делать то,
что не требует сборки, и писать в реестр; страж, который «не краснеет никогда», мёртв —
самотест на подложке обязателен.

## Ловушки, на которые уже наступали (не повторять)

- **Python-скрипты правок через heredoc съедают `\n`/`\1`/`\r`/`\\`** в не-raw строках —
  писать `r'''…'''`, а heredoc самого bash — квотированный `<<'EOF'`; после серии правок
  перечитать файл; лучше — Edit-инструмент.
- **Многострочные `=>`/`&&`/`||` с оператором на строке-продолжении** оракул не парсит —
  однострочник или вложенный `if`.
- **`vk[j].kind_of()` с переменным индексом** мискомпилируется ([LEGACY-#TBD-var-index-method]) —
  биндинг-хоп `ro pj = vk[j]`.
- **`ice() -> never` в хвосте str-функции** мискомпилируется ([LEGACY-#TBD-never-in-tail]) —
  строка-пацификатор `""` после (маркер обязателен на КАЖДОМ носителе).
- **char-литералы с сырыми управляющими байтами** принимаются молча — спецбайты только
  hex-константами `B_*`.
- **`nova build` в пакете examples/ платит dep-lock (12 с) и vcvars (7 с)** — смоук собирает
  эталон вне пакета и линкует прямым clang; не возвращать оракул в горячий путь.
- **`assert` внутри `spawn` под Supervisor убивает процесс** (не ловится) — см. К-I.
- **`mut`-захват в хендлере эффекта вокруг spawn** запрещён D441 — только `ro`/`#share`/`consume`.
- Первый прогон теста после сборки может ударить в недособранный кэш — перегнать.
- Страж, что грепает собственное написание правила, не видит его поломки — самотест на подложке.
- Хук `guard-git.py`: git только с `-C <дерево>`; `git add -A/./-u` запрещены.
- Бинарь `novac.exe` иногда занят предыдущим процессом — `taskkill //F //IM novac.exe` перед сборкой.
