## Что построено (устройство, а не история)

- **Каркас:** `novac/src/{source,lex,tree,parse,check,names,builtins,sem,emit_c,diag,pipeline,main}`.
  Зелёное дерево lossless (`reserialize(parse(lex(src))) == src`), Err-узлы вместо
  падений, диагностика §7-JSON через serde. Архитектура и таблица рёбер —
  `docs/dev/novac-architecture.md` (§2 карта, §3 рёбра — вход стража deps);
  конвенция — `docs/dev/novac-compiler-conventions.md` (П1–П14; каждое правило со
  стражем).
- **sem** — семантический слой (rustc_middle-модель): реестр типов `Ctx.types`
  (value-записи `TypeDef`, id = индекс), `DefTable`/`FieldTable`/`Scope` (таблица имён
  + строки одной записью), `Prims` (CommonTypes: seed возвращает фактические id, никаких
  хардкод-индексов), `type_of`. **`sem/mangle`** — единственная дверь C-имён
  (`c_type/c_struct/c_tag/c_maker/c_method/c_fn`), держится диффом с оракулом
  (`check-novac-mangle-fixed-point.sh`).
- **builtins** — лист-модуль, единственное место строковых имён языка (universe
  примитивы с ABI-именами, `ENTRY_FN`/`PRINT_FN`, `[LEGACY-SUBSET Э2-б]` str-метод-таблица);
  страж `check-novac-no-name-hardcode.sh`. Инстансы дженериков и C-имена
  неприм. типов там ЗАПРЕЩЕНЫ (вердикт владельца 2026-08-15).
- **emit_c** — только C-рендер по оракульским формам (фикс-пойнт: записи — GC-указатели,
  суммы — tag+union+maker, match — if-цепочка). Оболочка `shell.tpl.c` генерится
  **машиной** из зонтичного probe (`novac/probe/shell_probe.nv` →
  `scripts/tools/novac-regen-shell.sh`); probe растёт той же волной, что подмножество.
- **Подмножество взято (байт-в-байт с оракулом):** hello, arithmetic, strings, records,
  match_demo. **demo.nv откачен** (был взят захардкоженным `[]int` — К7; возвращается
  через `mono`, Э2-б). Храповик 11/5.
- **Цикл — секунды (274.2, П14):** смоук `novac-e1-smoke.sh` 1.7 с тёплый (кэш эталона
  + argv оракула через `NOVA_CLANG` + PCH + lld), фаззер батчем 16 с, дифф-раннер 50–68 с;
  `novac check f1 f2 …` — батч одним процессом.

## Инварианты, за которые кусают стражи (20 штук, `scripts/guards/check-novac-*.sh`)

deps (рёбра только из §3) · no-naked-panic (только `ice()`; **схема меняется — см.
очередь**) · no-string-keys · resolve-discipline (без тихих int-дефолтов и линейных
сканов имён) · no-name-hardcode (П5) · mangle-fixed-point · type-field-docs (П13: `///`
у типа/функции, у поля — trailing или над полем; строгость по пину ≥ 9a69411b3) ·
file-size (≤1000) · differential (фикстуры + храповик корпуса в обе стороны + бюджет
цены) · iteration-cost (П14, в обе стороны) · diag-schema · no-cascade · legacy-workarounds
· time-ledger (коммит в novac/** без строки в леджере — красный) · и др. Прогон всех:
`for g in scripts/guards/check-novac-*.sh; do NOVAC_CORPUS=0 sh $g; done`.

Правила процесса: спека до кода; изменение языка — амендмент D-блока в том же
слиянии (бриф интегратору, как D104 rev-2); маркеры самоистекающие (`EXPECT_*`); блокер не
ждать — делать то, что не требует сборки, и писать в реестр; в конце сессии — строка в
`docs/dev/novac-time-ledger.md`; `git add` только по именам; force-add нужен для
`shell.tpl.c` (`.gitignore *.c`).

   П12 переписать, страж no-naked-panic меняет знак (красный — `ice(`).
2. **Э2-б каркас:** ридер сигнатур std (str-методы из деклараций → builtins худеет),
   `TkApp` в реестре + `mono` (инстансы `[]T`, `Option[T]`) → demo.nv возвращается.
3. **274.2 хвосты:** фаззер ≤10 с (генератор мутаций одним процессом), дифф-раннер
   ≤30 с (батч novac + кэш вердиктов оракула), бюджеты в базу.
4. Реестр 221.1: номера для `[LEGACY-#TBD-*]` (char-literal-permissive,

## Ловушки, на которые уже наступали (не повторять)

- **Python-скрипты правок через heredoc съедают `\n`/`\1`/`\r`** в не-raw строках —
  писать `r'''…'''` или править Edit-ом; после серии правок перечитать файл.
- **Многострочные `=>`/`&&`/`||` с оператором на строке-продолжении** оракул не
  парсит — однострочник или вложенный `if`.
- **`vk[j].kind_of()` с переменным индексом** мискомпилируется ([LEGACY-#TBD-var-index-method]) —
  биндинг-хоп `ro pj = vk[j]`.
- **`ice() -> never` в хвосте str-функции** мискомпилируется ([LEGACY-#TBD-never-in-tail]) —
  строка-пацификатор `""` после.
- **char-литералы с сырыми управляющими байтами** принимаются молча — спецбайты только
  hex-константами `B_*`.
- Первый прогон теста после сборки может ударить в недособранный кэш — перегнать.
- Страж, который «не краснеет никогда», мёртв: самотест на подложке обязателен
  (mangle-fixed-point первой версии грепал собственное написание правила и не видел
  его поломки).
- Хук `guard-git.py`: git только с `-C <дерево>`.
