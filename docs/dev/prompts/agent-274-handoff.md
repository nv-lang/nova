Владелец — Головин Евгений (соло-автор). Отчёты ему — по-русски, коротко, простыми

## Что построено (устройство, а не история)

- **Каркас:** `novac/src/{source,lex,tree,parse,check,names,builtins,sem,types,mono,emit_c,diag,pipeline,main}`.
  Зелёное дерево lossless (`reserialize(lex(src)) == src` — с 2026-08-19 инвариант, а не
  команда), Err-узлы вместо падений, диагностика §7-JSON через serde. Архитектура и
  таблица рёбер — `docs/dev/novac-architecture.md` (§2 карта, §3 рёбра — вход стража
  deps); конвенции — `docs/dev/novac-compiler-conventions.md` (П1–П34; каждое правило со
  стражем), гейт и стражи вынесены в свой документ конвенций.
- **sem** — семантический слой (rustc_middle-модель): реестр деклараций
  (`DefTable`/`FieldTable`/`FnTable`/`Scope`, строки — value-записи, id = индекс),
  `Prims` (CommonTypes), `type_of`, канал чекера (`CheckOut`: `resolved_callees`,
  `subst_args`, одна дверь на запись — страж channel-one-writer).
- **types** — интернер терминов (`Interner.intern(kind, head_id, args)`, корзины по
  `(kind, head_id)`, аргументы в общем пуле): `TkPrim/TkRecord/TkSum/TkApp/TkParam/TkInfer`.
  Параметр типа — НАСТОЯЩИЙ тип (донор rustc `TyKind::Param`), поэтому `-> T` больше не -1.
- **sem/mangle** — единственная дверь C-имён, держится диффом с оракулом
  (`check-novac-mangle-fixed-point.sh`). Имя выводится ЕДИНООБРАЗНО для любой вызываемой
  сущности: **методов как отдельного вида нет — ресивер это параметр ноль** (план 273);
  параметры и тип возврата входят в имя; `c_callable(ctx, row, subst)`, `type_tag`
  подставляет `TkParam` → `subst[i]`. `foreign` как понятие снято 2026-08-20: внешняя
  функция — это `extern "C" fn` / `extern "nova" fn`, и это ФОРМА языка, которую парсер
  читает.
- **builtins** — лист-модуль, единственное место строковых имён языка. Хардкод сигнатур
  std снят: novac **читает** объявления (`--std`), таблицы `builtin_method_ret` нет.
- **mono** — множество достижимого от `main` по каналу; эмиттер спрашивает и не решает.
  Функция без пути из `main` в C не попадает.
- **emit_c** — только C-рендер по формам оракула. Оболочка `shell.tpl.c` генерится
  **машиной** из зонтичного probe (`novac/probe/shell_probe.nv` →
  `scripts/tools/novac-regen-shell.sh`, свежесть судит страж).
- **Подмножество взято (байт-в-байт с оракулом): hello, arithmetic, records,
  match_demo — четыре, не пять.** `strings` откачен ОБЪЯВЛЕННЫМ откатом 2026-08-20
  (храповик 11/5 → 10/4): novac читает сигнатуру метода, тела не компилирует, и говорит
  это отказом по имени вместо тихой мискомпиляции. `demo.nv` откачен раньше (К7, вернётся
  через `mono`). **Красный смоук `strings` — ожидаемое состояние, не поломка**; сверяй с
  `novac-corpus.baseline`, а не с этой строкой.
- **CLI:** `novac check f1 f2 …` (батч, exit = худший), `novac emit f` (C на stdout).
- **Цена цикла (П14, 274.2 + перенос стражей на python):** тир правки ~9 с, полный гейт
  584 с, из них 238 с — мутационная проверка САМИХ стражей. Бюджеты — храповик в обе
  стороны; в `novac-iteration-cost.baseline` живёт `cal-ms` — машинная калибровка (150 мс
  на тихой машине против 3300 мс под полным гейтом), при переезде на другую машину её
  перезаписывают СОЗНАТЕЛЬНО, а не «чинят» пороги.

## Приёмка волны — что гонять перед каждым коммитом

Гейт сам знает порядок и цену, поэтому руками собирать прогон больше не надо:

```sh
NOVAC_TIER=loop bash scripts/gate-novac.sh    # ~80с: правила по novac/src + сборка + модульные тесты
NOVAC_TIER=push bash scripts/gate-novac.sh    # умолчание: плюс поведение — дифф, паники, батч, фаззер
NOVAC_TIER=full bash scripts/gate-novac.sh    # CI: плюс мутационный самотест стражей и замер цены
```
Швы `NOVAC_CORPUS=0` / `NOVAC_COST=0` / `NOVAC_PROVE=0` — для дешёвой выборки в окне;
прогон с любым установленным швом НЕ печатает `final` («зелено на выборке» и «зелено» —
разные утверждения, №645). Код возврата **2** — не твоя вина: бинарь оракула разошёлся с
заголовками рантайма (пересобраться/дождаться слияния), гейт различает это машиной.

Порядок внутри гейта НОРМАТИВЕН (класс F1): `novac-build` идёт ДО бинарь-зависимых
стражей — иначе они честно скажут «судить нечего» и выйдут нулём, и гейт станет зелёным
НИ О ЧЁМ (наступали: сутки блокера std serde прошли зелёными).

Руками — только когда нужен один шаг:

```sh
ORACLE=d:/Sources/nv-lang/nova/nova-cli/target/release/nova.exe
taskkill //F //IM novac.exe >/dev/null 2>&1; "$ORACLE" build novac/src/main.nv -o novac/target/novac.exe   # ~8с
sh scripts/tools/novac-e1-smoke.sh examples/basics/hello.nv | tail -1                                     # 1.7с/файл
```
Плюс к коммиту: строка в `docs/dev/novac-time-ledger.md` (страж time-ledger; **сумма
долей за дату ≤ 1.0**), живая строка §9 — тем же коммитом; `git add` по именам;
`shell.tpl.c` — `git add -f` (`.gitignore *.c`); в сообщении — `274.3/F<N>` при закрытии
находки и строка `Donor:`.

## Инварианты, за которые кусают стражи (62 стража `check-novac-*`, 64 самотеста)

Почти все переписаны с sh на python (замер: страж — ОДИН процесс, а не процесс на файл;
`temp-edges` 3.82 с → 0.28 с). Правило переноса — в конвенциях гейта: НОВЫЙ текстовый
страж идёт в общий python-раннер (маргинальная цена нуль), ЖИВОЙ shell-страж рядом с
общим процессом не трогают (замер: перенос не менял ничего и один страж замедлил),
ПОВЕДЕНЧЕСКИЙ судится тиром и бюджетом.

Ключевые: deps (рёбра только из §3) · no-naked-panic (только `ice()`) · no-string-keys ·
resolve-discipline · no-name-hardcode (П5) · mangle-fixed-point · mangling-one-way ·
channel-one-writer · type-field-docs (П13: `///` у типа/функции, у поля — trailing или
над полем) · file-size (≤1000) · differential (фикстуры + храповик корпуса в обе стороны
+ бюджет цены) · iteration-cost · diag-schema · no-cascade · no-crutch (**слово «crutch»
гейт отказывает: у костыля нет конца — механизм это правило с именем**) · no-silent-skip ·
legacy-workarounds (`#TBD` виден и стареет от первого появления) · time-ledger ·
guard-registry (мета-страж §10.3а↔guards↔gate↔selftest) · selftest-proves-red
(мутационная проверка: страж, который не краснеет на сломанном правиле, мёртв).
Библиотека `scripts/guards/lib/novac.sh`: `novac_require_bin` (есть `main.nv`, нет
бинаря — КРАСНЫЙ, не «судить нечего»), `novac_is_panic_rc` (одно определение паники),
`novac_find_oracle`.

Правила процесса: спека до кода; изменение языка — амендмент D-блока в том же слиянии
(бриф интегратору, образец D104 rev-2); маркеры самоистекающие; блокер не ждать — делать
то, что не требует сборки, и писать в реестр; храповик умеет ЗАКОННЫЙ откат — механизм
есть, объявленный откат пишется строкой `RATCHET-DOWN` с причиной и датой.

## Очередь — где ты остановился

**1. Э2-б2 ЗАКРЫТ приёмкой (2026-08-21).** `fn dbl[T](x T) -> T => x + x` при вызовах
`dbl[int](21)` и `dbl[f64](1.5)` даёт ДВЕ C-функции из одного тела, поведение
байт-в-байт с оракулом; фикстура — `novac/fixtures/generic_call/pos_1.nv`, форма
`generic_call` внесена в реестр форм. Устройство: `pipeline.instances_of` обходит
`Reach.instances()`, зовёт `check_instance` на элемент, собирает `emit_c.Instantiation`
(декларация + строка + подстановка + КОНКРЕТНЫЕ типы + свой канал); эмиттер пишет по
функции на элемент одной дверью `@emit_callable` плюс прототипы наверху. Конкретные типы
переписывает mono через `sem.subst_type` — эмиттер не подставляет ничего.
**Чего Э2-б2 не даёт (названо, отказы по имени):** вывода нет (turbofish обязателен);
композиции подстановок нет (`inner[T](x)` внутри `outer[T]` отказан своим сообщением);
дженерик-методов нет. **Оракул на этих формах СЛАБЕЕ:** `dbl[int, f64](21)` принимает и
компилирует, `dbl[Zork](21)` принимает и падает в clang — класс О-1в, в реестре
расхождений, у интегратора.

**2. Э2-б3 — `#coerce` в подборе перегрузки.** `FnTable.fits` сравнивает id типов ТОЧНО,
`#coerce` не учитывает вовсе (D429: `str → ro []u8`, `StringBuilder → str`,
`WriteBuffer → []u8`). Сегодня не видно только потому, что типы аргументов на call-site
`UNKNOWN_TYPE` и различается одна арность: первый же типизированный аргумент превратит
законный вызов в «no such method», и причина будет названа неверно.

**3. Newtype-индексы реестров** (37 сигнатур: `row`, `type_id`, `ty_id`, `vrow`, слот
параметра) — приняты, отложены датировано: подмножество не читает `type X int`. Порядок:
сперва форма и конструктор `X(n)` в подмножестве, потом заворачивать, начиная с пары
`fn row` / `ty_id` — тех двух, что уже путались (держатся ассертом локстепа, не типом).

**4. Остаток 274.3** — 33 отметки из 71 находки. Порядок раздела §9.1а: сорок четыре
находки ВНЕ слоя типов идут параллельно и не ждут ничего; двадцать семь внутри слоя — 
после Э2-б1, и часть исчезнет сама, потому что описывала форму, которой больше нет.
Волны (2) и (3) считаются идущими, пока не пройдена **поштучная** переаттестация списка:
закрывать их «по ощущению» — ровно то, против чего заведён §9.1а.

**5. К-I panic-схема** — ЖДЁТ спеки: `assert` в ребёнке под Supervisor не ловится
(`panic`/`throw` — ловятся); сужение `err any → str` — формы нет. До ответа `ice()`
остаётся.

**6. Открытое у интегратора:** номера для `[LEGACY-#TBD-*]`; `[]int` ≡ `Vec[int]`
(замер 2026-08-21, класс О-1в — `check` оракула принимает две перегрузки, кодоген даёт
два определения с ОДНИМ именем `nova_fn_4main1f`; реестр расхождений).

## Ловушки, на которые уже наступали (не повторять)

**Инструмент и хуки:**
- **Хук `guard-shell-nonascii.py`: в командной строке только ASCII.** Русский `grep`-шаблон
  отказан (cp1251 против UTF-8). Ищи через инструмент Grep или python-скриптом.
- **Хук изоляции worktree отказывает СЛОЖНЫМ командам** («too complex to verify»): цепочки
  с `for`/`&&`/подстановками, пути вне дерева. Разбивай на плоские команды из корня дерева.
- **Хук `guard-git.py`:** git только с `-C <дерево>`; `git add -A/./-u` запрещены.
- **Python-скрипты правок через heredoc съедают `\n`/`\1`/`\r`/`\\`** в не-raw строках —
  писать `r'''…'''`, а heredoc bash — квотированный `<<'EOF'`; после серии правок
  перечитать файл; **лучше — Edit-инструмент.** Замер 2026-08-21: вставка функции
  скриптом съела ///-док у СОСЕДА, и это увидел только страж type-field-docs.
- **Пробы держать по ОДНОЙ на каталог:** `nova check`/`build` судит пакет целиком, и два
  файла с `fn main` в одной папке дают «duplicate definition `main`» о чужой пробе.
  Каталоги `probes-*/` и `scratch*/` в `.gitignore` (реестр №695).
- **C оракула для сверки мэнглинга** берётся так: `TEMP=<каталог> TMPDIR=<каталог>
  nova build … --keep-artifacts`, потом искать `.c` ПО СОДЕРЖИМОМУ (не по времени —
  параллельные окна пишут в общий кэш).
- Бинарь `novac.exe` иногда занят предыдущим процессом — `taskkill //F //IM novac.exe`.

**Язык и оракул:**
- **Многострочные `=>`/`&&`/`||` с оператором на строке-продолжении** оракул не парсит —
  однострочник или вложенный `if`.
- **`vk[j].kind_of()` с переменным индексом** мискомпилируется ([LEGACY-#676]) —
  биндинг-хоп `ro pj = vk[j]`; у формы есть ТИХАЯ половина (замер 2026-08-18).
- **`ice() -> never` в хвосте str-функции** мискомпилируется ([LEGACY-#677]) — строка-
  пацификатор `""` после (маркер обязателен на КАЖДОМ носителе).
- **char-литералы с сырыми управляющими байтами** принимаются молча ([LEGACY-#675]) —
  спецбайты только hex-константами `B_*`.
- **`nova lint ./path`** (ведущий `./`) молча не находит файлов и выходит нулём.
- **`assert` внутри `spawn` под Supervisor убивает процесс** (не ловится) — К-I.
- **`mut`-захват в хендлере эффекта вокруг spawn** запрещён D441 — только
  `ro`/`#share`/`consume`.
- **`nova build` в пакете examples/ платит dep-lock (12 с) и vcvars (7 с)** — смоук
  собирает эталон вне пакета и линкует прямым clang; не возвращать оракул в горячий путь.
- Первый прогон теста после сборки может ударить в недособранный кэш — перегнать.

**Метод:**
- Страж, который грепает собственное написание правила, не видит его поломки — самотест
  на подложке обязателен, и мутационная проверка судит это машиной.
- «Дверь есть» ≠ «дверь позвана»: `record_subst` числился сделанным, пока не выяснилось,
  что вызовов нет ни одного. Проверять читателя, а не наличие функции.
- Замер вместо обещания: и в плане, и здесь. Строка «почти готово» — запрещённая форма.
