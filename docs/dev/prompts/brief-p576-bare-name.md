### Носитель 1 — №576, ВОСПРОИЗВЕДЁН интегратором (начни с него)

ФАКТ. Три строки вне корпуса, без зависимостей:

    type Colour enum Red | Green | Blue(int)
    fn Colour @to_str() -> str => "blue7"
    ro c = Blue(7)
    print(c.to_str())

`nova build` падает ошибкой СИ: `passing 'int' to parameter of incompatible
type 'nova_str'` на `nova_print_str(Nova_Colour_method_to_str(c))`. То есть
рукописный метод ВЫЗЫВАЕТСЯ, но объявлен в C с возвратом `int` вместо
`nova_str`.

ФАКТ. Носитель — не печать: у суммы имя `to_str` занято встроенным путём
(печать по тегу), и это имя решает раньше, чем объявление пользователя.

ГИПОТЕЗА, независимо не подтверждена: точка расхождения — там, где эмиттер
берёт сигнатуру встроенного `to_str` вместо сигнатуры найденного
пользовательского метода. Если не подтвердится — ОСТАНОВИСЬ и доложи, не чини
по неверному диагнозу.

### Носитель 2 — №536, точка НАЗВАНА предыдущим окном

`f1_check_call`, ветка `Member{obj: Ident(prefix)}` в
`compiler-codegen/src/types/mod.rs` (~строка 15380): кандидаты берутся из
плоской CU-широкой `self.sig.fn_decls.get(name)` по ГОЛОМУ имени, а `prefix`
идёт ТОЛЬКО в гейт-проверку `imported_modules.contains` и НЕ фильтрует
кандидатов по модулю. Значит `a.f(x)` может выбрать одноимённую `f` из модуля
`b`, если та лучше подходит по арности — при явно написанном модуле.

ЧЕСТНО: носитель не предъявлен, приоритет по ЦЕНЕ ОТКАЗА (молча вызвана не та
функция). Первое действие — предъяви носитель фикстурой: два модуля, в каждом
`fn f`, разная арность, вызов `a.f(x)`; покажи, какая выбрана.

### Носитель 3 — №534, репро в чужом пакете

`nova-polaris/src/rt/handle_connection_smoke.nv`: локальная `fn routes() ->
Router`, вызванная ВНУТРИ тела `spawn`, даёт `CC-FAIL: use of undeclared
identifier 'routes'` — анализ захвата добавляет в контекст файбера поле
`routes` (это ВЫЗОВ, не переменная) с ЧУЖИМ типом `[]RouteInfo`, взятым по
голому имени у одноимённого ПАРАМЕТРА в модуле `polaris.openapi`.

Этот носитель бери ПОСЛЕДНИМ: он в соседнем репозитории
`d:/Sources/nv-lang/nova-polaris`, и если первые два закрыты правильно, он
может отвалиться сам. Проверь — и скажи прямо, отвалился или нет.
