## Вещи, которые стоили времени — не наступай снова

1. **Оболочка исполняет обратные апострофы и съедает слова.** Сообщения коммитов пишутся
   ФАЙЛОМ всегда, без исключения для однострочных: исключение «если коротко» и есть тот
   триггер, на котором правило не срабатывало трижды.
2. **Не-ASCII в командной строке блокируется хуком** — скрипт писать файлом.
   И в сообщении коммита кириллица запрещена: цитату чужого текста ставить строкой с `>`.
3. **Код возврата после конвейера принадлежит ПОСЛЕДНЕЙ команде** (реестр №1104).
   `nova test … | tail; echo "EXIT=$?"` напечатал `EXIT=0` при упавшем тесте;
   `grep … | head && echo НАШЁЛ` объявил конфликтные маркеры там, где их нет. Знака у
   ошибки НЕТ — бывает и ложное зелёное, и ложное красное. Судить по строке `PASS:`/`FAIL:`
   либо по `${PIPESTATUS[0]}`; голый `$?` после `|` не писать вовсе.
4. **УТВЕРЖДЕНИЕ ОБ ОТСУТСТВИИ нельзя доказать поиском по ОДНОМУ написанию предмета.**
   Интегратор объявил «правила о порядке полей в спеке нет», искав русские слова в абзаце,
   который говорит `required`/`optional` по-английски — и абзац говорил ПРЯМО ОБРАТНОЕ.
   Я повторил ту же ошибку в тот же день: сказал «следа нет» про фикс-массив, имея 371
   попадание грепа и просмотрев тридцать строк. След был, в строке реестра №1096.
5. **Своя мерка врёт МОЛЧА и правдоподобно.** Одна и та же дала 97, 112 и только потом 141:
   `)` внутри комментария обрубал тело объявления; имя типа искалось глобально; якорь
   `^type` НЕ ВИДЕЛ `export type`. **Число, ВЫРОСШЕЕ после починки мерки, — сигнал искать
   следующую слепую зону, а не докладывать.**
6. **Свойство, выведенное из двух носителей, названо по ВЫБОРКЕ, а не по механизму.**
   Так у №1104 появилось ложное «ошибка односторонняя», снятое через час контрпримером.
7. **Время в отчёте и в метках берётся КОМАНДОЙ `date`** — включая метки `echo` внутри
