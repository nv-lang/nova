Установлено 2026-08-09 по десяти срывам подряд. Окна падают с
`Agent stalled: no progress for 600s (stream watchdog did not recover)` не по
задаче, а по нагрузке: при пяти-шести одновременно работающих окнах отдельные
вызовы инструментов растягиваются дольше сторожевого порога.

Усугубляет **любая тяжёлая команда интегратора параллельно**: полный
`nova test`, `cargo build --release`, пятиминутный прогон opencode. В тот же
момент валились по два-три окна разом.

**Why:** каждый срыв теряет незакоммиченное и стоит сообщения на возобновление,
а работа окна к тому моменту уже оплачена лимитами. Десять срывов за сутки — это
десять потерянных кусков работы и десять лишних ходов.

**How to apply:**
* держать **не более четырёх** окон одновременно; пятое ставить в очередь, а не
  запускать;
* пока окна работают, **не запускать у себя** полный `nova test`, `cargo build`
  и долгие сторонние прогоны — только греп, чтение и правку файлов;
* в брифе окна требовать **чекпоинт-коммит перед каждым долгим замером** и
  дробление серий (не «200 прогонов одной командой», а по 25–50 с коммитом
  счёта каждой части);
* возобновлять упавшее окно **сообщением**, а не новым запуском: оно продолжает
  со своей ветки и не перечитывает контекст заново.
