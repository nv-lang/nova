Nova — соло-проект (Евгений [[user-identity]] пишет язык один). В **публичных/
outward-facing текстах** (GitHub-комментарии/issues, доки, сайт, релиз-ноты)
использовать **единственное число от первого лица**: «я», «буду», «закрываю»,
«сделал». НЕ royal-we: «мы», «будем», «наша команда».

**Why:** «будем рады деталям» в комментарии к issue #3 — user поправил: «почему
множественное число, я пишу язык в соло пока». Royal-we создаёт ложное впечатление
команды.

**How to apply:** перед публикацией любого outward-facing текста — проверить voice,
заменить «мы/будем/нам» → «я/буду/мне». Внутренние логи/планы — не критично.
