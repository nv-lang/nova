Владелец 2026-08-06 («ДА» на вопрос, распространяется ли правило на мои сессии):
**номера маркеров в `docs/plans/221.1-bug-sweep.md` выдаёт ТОЛЬКО интегратор; окна и
сессии пишут `№TBD`.**

enforcement: немашинное — самопроверка при регистрации маркера.

**Why:** правило пришло от параллельной сессии после реальной коллизии — две сессии
независимо взяли «следующий свободный номер» (`grep … | sort -n | tail -1`) и заняли
один и тот же; чужие №365/№366 пришлось переименовывать в №372/№373/№374 уже после
вливания, с правкой ссылок.

**How to apply:**
- В `backlog-followups.md` — текст маркера с пометкой `№TBD` вместо номера.
- В `221.1-bug-sweep.md` — строку ВСЁ РАВНО добавлять (иначе красный
  `check-bug-number-sync`: страж грепает ИМЕНА `[M-…]` в 221.1, не номера), но в
  колонке номера писать `№TBD`.
- Уже присвоенные ранее номера (мои №364/№371/№378) не перенумеровывать — на них
  ссылаются влитые тексты; правило применяется к НОВЫМ.
