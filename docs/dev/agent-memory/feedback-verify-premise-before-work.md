Первым действием по любой строке реестра — **проверить премису запуском**:
собрать носитель, прогнать названную фикстуру, грепнуть код. Не поверить
описанию, даже своему и даже недельной давности.

enforcement: гейт — `scripts/guards/check-fixed-but-open.sh` (строка не
остаётся `OPEN`, когда её правка слита; база `fixed-but-open.baseline`) плюс
`check-registry-single-verdict` (вердикт без статуса, база
`verdict-no-status.baseline`, храповик 20). Половина «доказать, что фикстура
умеет падать» — НЕМАШИННОЕ: обратное применение коммита требует пересборки и
суждения, машина этого не решит; держится дисциплиной и записью замера в
строке реестра.

**Why:** 2026-08-19 за одну смену ДЕСЯТЬ строк оказались устаревшими. Восемь
были починены и приколоты фикстурами, но статус остался `OPEN`, потому что
коммит-правка обновлял ДРУГИЕ строки того же файла (класс №731). Ещё две
(№471 «модуль std/net не собирается», №498 «декремент до проверки»)
описывали код, которого уже нет. Пятая часть открытых блокеров тега была
фикцией учёта. Проверка премисы стоит минуты и экономит окно.

**How to apply:**

1. **Закрывать по ЗАМЕРУ, а не по доверию.** Прежде чем снять статус, докажи,
   что фикстура УМЕЕТ ПАДАТЬ: `git diff <fix> <fix>^ -- <src> | git apply`,
   пересобрать тот же бинарь, увидеть красное, восстановить. Половинчатый
   выключатель обманывает: у №711 отключение только эмиссионной ветки не
   изменило выпущенный C ни на байт, и фикстура выглядела пустой — правка
   оказалась двухполовинной. Снимай правку ЦЕЛИКОМ.

2. **Зелёный тест, не умеющий падать, хуже отсутствующего** — он читается как
   покрытие (класс F1, №645). Тем же приёмом отбракована собственная фикстура
   `d25_never_tail_all_returns_pos.nv`: проходила и с правкой, и без.

3. **Перед заведением новой строки — ГРЕП по симптому и по имени фикстуры.**
   №732 завёл дубликатом к №445, которая держала ту же работу с 2026-08-08.
   Реестр в 700 строк в голове не помещается.

4. **Два сканера, считающие одно число по-разному, — находка, а не шум.**
   55 блокеров против 35 обнажили десять строк с вердиктом и БЕЗ статуса.
