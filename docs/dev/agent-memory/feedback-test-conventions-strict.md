**ВСЕ конвенционные доки нормативны; изменения и отклонения — ТОЛЬКО по согласованию с владельцем.** Мета-правило в одном governance-файле: `docs/conventions-governance.md` (на него баннером ссылаются все 7 конвенций: compiler/test/nv-coding-style/perf/bench/lsp/project-philosophy). Нашёл ошибку/противоречие в конвенции — НЕ править молча: вынести владельцу (что не так + варианты + рекомендация), получить решение, потом править; коммит правки конвенции упоминает согласование.

**Тесты — по `docs/test-conventions.md`; читать ДОК НАПРЯМУЮ** (не копировать паттерн соседних фикстур — они могут быть неконформны). Конкретные правила НЕ дублирую в памяти (меняются — источник правды сам док). Общее:
- классификация теста — по **маркеру** `EXPECT_*`; группировка TU — по равенству `module`-деклараций (раннер НЕ читает суффикс `_neg`/имя `neg/`). Правя конвенцию, сверяться с `test_runner.rs`, чтобы не разойтись с инструментом.
- полнота для overload/arg-проверок: multi-param, разная арность, частичный матч — НЕ только single-param.
- detect172/ (ветка 172.1) — дом своих pos/neg по тем же конвенциям.

**История (2026-06-20):** я (а) скопировал неконформный паттерн соседних фикстур вместо чтения дока; (б) нашёл 2 внутренних противоречия (test-блок rule↔пример; `_neg` rule↔пример) — вынес владельцу, согласовали **смягчение** (test-блок допустим — не исполняется; `_neg` необязателен внутри `neg/`, обязателен вне), проверил совместимость с раннером, внёс правку + завёл `conventions-governance.md` + баннеры.

**Why:** конвенции — единый источник правды процесса; самовольная правка/отклонение форкает (агенты следуют разным версиям, фикстуры дрейфуют).

**How to apply:** (1) читать `test-conventions.md` (+ `conventions-governance.md`) перед тестами; (2) сомнение/противоречие в любой конвенции → к владельцу, не самовольно; (3) правка конвенции — только после согласования, со сверкой с инструментом.
