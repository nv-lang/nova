они — память проекта. И повторно (2026-07-18) — simplifications.md

**Как применять:** обновлять по ходу; коммит после каждой большой
задачи; несколько задач → несколько коммитов (см.
[[feedback-commit-per-task]]). `nova-private` — свой `git commit`,
`git add` только по именам (см. [[feedback_git_add_specific]]).

памяти невидимыми, без строки в индексе):**
