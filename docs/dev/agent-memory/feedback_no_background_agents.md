**Default:** делать работу самому через Bash / Read / Edit / Write —
каждое действие видно пользователю в реальном времени.

**Запрещено без явного подтверждения:**
- Любой `Agent` tool call — **ни background, ни foreground**
- Background = `run_in_background: true` (явно невидимо, нужен monitor)
- Foreground = без флага (один большой tool result в конце; для
  пользователя всё ещё «чёрная коробка» делающая что-то долго)

**Why:** Пользователь хочет видеть **что именно** я делаю, шаг за шагом,
а не получать конечный отчёт. Agent tool скрывает промежуточные действия
(внутри отдельный transcript, недоступный для просмотра без overflow
context). Делегирование агенту = потеря transparency, даже если
foreground.

**How to apply:**
- По умолчанию делать всю работу самому через прямые tool calls
  (Bash/Read/Edit/Write/Grep/Glob).
- Если объём задачи большой (multi-day) — **обсудить с пользователем**
  стратегию: разбить на foreground steps в основном диалоге, или
  делегировать агенту (нужно явное «можно агента»).
- Когда пользователь говорит «я ушел» или «делай сам» — это **не**
  разрешение на агента. Это значит «работай в основном диалоге без
  моего участия, но видимо».
- Исключение: пользователь явно сказал «запусти агента» / «можно
  background» — тогда OK.
- При сомнении — спросить, не запускать.
