Репозитории пакетов (`nova-polaris`, `nova-http`, `nova-tls`, `nova-socks`,
`nova-compress`, `nova-bignum`, …) — целиком моя земля: слияние, пуш **и
проставление тега**. Отдельного слова владельца не требуется. Тег **в самой
`nova`** — по-прежнему только владелец.

**Why:** пакет тянется по `version = "0.1"`, резолвер выбирает свежайший
подходящий **тег** — правка, лежащая в `main` пакета, невидима ни одному
потребителю, и сборка на чистом дереве остаётся красной. 2026-08-16 я
остановился спросить разрешения на тег `nova-compress`, и этим держал D461;
владелец: «мы же договаривались, что тег на модули ты ставишь сам!».

**How to apply:** тегай сам, без вопроса. Ритуал: тесты пакета зелёные →
поднять `version` в `nova.toml` → коммит `release: vX.Y.Z -- …` → `git tag -a`
→ пуш ветки и тега во все **три** зеркала → сверить `git ls-remote` (объект
обязан совпасть) → у потребителя `nova update` → коммит лока. Правило теперь
живёт и в дереве (`AGENTS.md`, раздел Git) — там его читает каждое окно, а не
только эта сессия: владелец отдельно указал, что обещание «поправлю память»
проблему не решает. См. [[project-three-remote-mirrors]],
[[feedback-no-external-memory-for-project-state]].
