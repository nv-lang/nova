Урок Plan 214 (2026-07-18): после ревью-3/4/5 я трижды заявлял «дозрел / до дна / готов без
известных дыр» — и каждый раз следующий проход (мой, владельца, независимого агента) находил
РЕАЛЬНЫЕ дыры (эффект-свобода, саморекурсия, видимость; generic/protocol/композиция;
R6-перепромис, линт-предикат). Владелец прямо указал: «в прошлые разы ты тоже был уверен».

**Why:** у документного ревью убывающая, но НЕ нулевая отдача; заявление «готово» после него —
некалиброванная уверенность, которую владелец уже ловил (также «я думал, ты нашёл» — гипотеза,
прозвучавшая как находка). Лучшие находки приходят из эмпирики (ветка-разведка, код-факт
ревьюера), не из N-го прохода глазами.

**How to apply:**
- Формулировка итога ревью: «проход N новых дыр не нашёл», НИКОГДА «дыр нет / готов».
- Гипотезы явно метить гипотезами («если бы X — то Y»), не подавать тоном находки.
- После 2-3 чистых/малоурожайных проходов рекомендовать переход к реализации как к более
  дешёвому источнику следующих находок (smoke-гейт + checkpoint-notes → находки исполнителя =
  штатный выход фазы), а не обещать законченность документа.
- Связано: [[feedback-zero-tolerance-bugs]], [[feedback-rustc-as-reference]] (эмпирика/эталон
  выше рассуждения).
