Владелец МНОГОКРАТНО (7+ раз к 2026-07-06) просил «говори по русски» — в том числе когда ответы уже были формально на русском. Вывод: раздражает не язык каркаса, а ПЛОТНОСТЬ англицизмов в русском тексте (merge, DONE, agent running, worktree, keystone, reconcile, verify и т.п.).

**Why:** прямая повторная просьба владельца; «по-русски» = читабельный русский текст, а не русская грамматика с английской лексикой.

**How to apply:**
- Весь текст ответов и статусы туду-листа — по-русски: «слияние» (не merge), «готово» (не DONE), «агент работает» (не running), «рабочая копия» (не worktree), «проверка» (не verify), «сверка с эталоном» (не reconcile).
- Английское оставлять ТОЛЬКО для буквальных имён: файлы/пути, коды ошибок (E_...), названия команд (`git merge`, `cargo build`), имена D-блоков/маркеров, идентификаторы кода.
- Следить с ПЕРВОГО ответа сессии (легко сбиться после чтения англоязычного кода).
- Публичные тексты (README/AGENTS) — по-английски, как раньше. См. [[feedback-solo-author-singular-voice]].
