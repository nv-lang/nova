Владелец (2026-07-06): «sum-type у нас теперь делается через type Type enum ..., а ты используешь старый синтаксис через type Type | ...».

**Правило (D406, 2026-07-01, spec/decisions/02-types.md):** сумма = `type X enum A | B | C` (однострочно — без `|` перед первым вариантом; многострочно — `|` у КАЖДОГО, включая первый). Маркер `enum` обязателен.

**Ловушка:** парсер ПОКА принимает старый leading-`|` без диагностики → старый вид тихо проскакивает в новый код (7 файлов std проскочили — исправлены; ретракция = `[M-d406-retract-leading-pipe]`, после миграции корпуса тестов).

**How to apply:** в каждом задании агенту, где возможны суммы, — писать только `type X enum ...`; проверять поставки грепом `^(export )?type \w+(\[.*\])? \|`.
