Владелец (2026-08-01): «мне кажется ты редко гоняешь линт, что нехорошо».

enforcement: немашинное — ритуал интегратора (в гейт nova-репы линт как
blocking-шаг не входит, счёт находок плавает по волнам); кандидат на
машинный храповик: baseline-файл счёта находок per-репо (задача при
закрытии линт-свипов).

**Why:** линт — единственный автомат, который видит стиль-дрейф новых волн
(ручной max, to_str в интерполяции, hand-rolled JSON находил владелец
глазами — линт бы часть поймал раньше).

**How to apply:** в приёмку КАЖДОЙ волны с .nv-правками включать
`nova lint <затронутая зона>` и фиксировать счёт в отчёте волны; при пуше
пакетной репы — `nova lint src` всей репы, дельту к прошлому счёту — в
коммит-сообщение или отчёт владельцу. Счета на 2026-08-01: nova 328 (свип
идёт), polaris 178, http 86, bigint 7. Связано: [[feedback-update-logs]].
