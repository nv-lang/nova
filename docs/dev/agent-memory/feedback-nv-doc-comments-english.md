Владелец (2026-07-31, повторно — «мы кажется договаривались»): вся дока в
.nv-файлах — на английском. Конвенция записана в docs/nv-coding-style.md:25
(doc-comments публичного std `///`/`//!` — английский). Также: сообщения линта
(summary/тексты правил lints.rs) — на английском.

**Why:** публичная поверхность (nova doc, hover, вывод линта) — для внешнего
читателя; русский там — витринный провал.

**How to apply:** в КАЖДЫЙ бриф пакетных/std-окон: «`///`/`//!`-доки и
пользовательские сообщения — АНГЛИЙСКИЙ; отчёт и внутренние обсуждения —
русский». НЕ писать «комментарии в коде — русский» (моя системная ошибка
2026-07-30/31, породила ~750 русских /// в bigint/polaris-волнах; в std их
2945 исторических). Внутренние `//` — не дока, язык свободный. Перевод-волны:
батчами с гейтом канона (std FAIL: 26), сравнение — только тексты, код не
трогать.

enforcement: планируется страж check-doc-comment-language.sh (греп кириллицы в
///-строках std/src + пакетных src, gate.sh шаг; завести в 231.2 при вкате
перевод-волны std) — до него немашинное: строка в каждом брифе.
