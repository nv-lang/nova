На любой вопрос владельца — короткий ответ простыми словами. Не разворачивать в
эссе, не перечислять всё, что знаю по теме, не пересказывать историю решения,
если не спросили.

**Why:** указание владельца 2026-08-19, после серии длинных ответов с таблицами
и разделами на вопрос вида «что такое X». Длинный ответ на короткий вопрос
заставляет искать ответ внутри ответа.

**How to apply:** сначала одна фраза по существу, дальше — только то, без чего
она непонятна. Таблицы и разделы — когда просят СВОДКУ или сравнение, а не
когда спрашивают «что это». Отчёт о сделанной работе — тоже коротко, детали по
запросу. Связано с [[feedback-respond-in-russian]].

enforcement: немашинное — длину и простоту ответа не проверить скриптом; судит
владелец следующим замечанием.
