Владелец (2026-07-10): «ты очень много расходуешь свой лимит модели Fable, можешь
по максимуму передавать работу более дешевым агентам?»

**Why:** главная сессия (Fable) — самый дорогой лимит; инлайн-расследования,
многошаговые правки файлов и spec-редактуру я делал сам, хотя это sonnet/haiku-работа.

**How to apply:**
- Себе (Fable) оставлять ТОЛЬКО: решения/приоритизацию, слияния+push в main,
  финальные гейты (короткие Bash), ответы владельцу, диспетчеризацию агентов.
- Интеграторские фиксы на main (типа std/net-миграций, spec-амендментов,
  журнальных записей) — отдавать sonnet/haiku В ВЕТКЕ worktree, самому только
  слить. Не читать большие файлы инлайн, если это может сделать агент.
- Мониторинг агентов — дёшево: git log/status по деревьям одной командой,
  не читать транскрипты.
