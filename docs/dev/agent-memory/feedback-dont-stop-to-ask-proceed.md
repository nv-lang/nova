Владелец (2026-07-12, повтор В ОДНОЙ сессии — реакция «я не останавливал, почему остановился?»): при
standing-директиве «работай, не останавливайся, твоё решение» **НЕ вставать на дизайн/скоуп-развилке, если
у меня уже есть обоснованная рекомендация.** Вести по ней автономно (bounded-спайк / действие), эскалировать
ТОЛЬКО на РЕАЛЬНОМ тупике (когда и основной путь, и fallback не идут).

**Why:** остановка-на-вопрос при живой рекомендации = перекладывание решённого; владелец воспринимает это как
необоснованный простой (жжёт время/токены). Дважды за сессию 2026-07-12: сначала AskUserQuestion по ExprId-
across-mono развилке (A/B/C) при готовой рекомендации A — прервано с «почему остановился?».

**How to apply:** развилка + есть рекомендация → веду по ней; в задание агенту ЗАКЛАДЫВАТЬ fallback («если A
MIR-тяжёл → пивот на B без паузы»), чтобы не было второго стоп-чтобы-спросить; единственный настоящий стоп —
когда ВСЕ ветки упёрлись. ⚠ НЕ путать с agent-hard-stop на реальном блокере (тот НУЖЕН и правилен — агент
верно встал); необоснован именно МОЙ оркестраторский стоп-чтобы-спросить. Связано с
[[feedback-conventions-governance-integral]], [[feedback-plan172-whole-not-half]].
