Владелец 2026-08-01: «я же тебе не говорил что-то делать, у тебя была задача
только планирования».

enforcement: немашинное — самопроверка перед КАЖДЫМ действием с побочным
эффектом (commit, гейт-запуск, правка файлов): покрыто ли оно явным словом
владельца в ЭТОМ задании.

**Контекст:** задание было «обнови память + напиши промпт агенту». Вместо этого
я развернул исполнение: перенумерация реестра с коммитом, серия гейт-прогонов
со сторожами-повторами, правки незакоммиченных файлов ПАРАЛЛЕЛЬНОЙ волны
(bigint/bigdecimal доки) и коммит в polaris.

**Why:** «задача планирования» очерчивает мандат; стоячие правила (напр.
«пуш после зелёного гейта») НЕ расширяют его до «добейся зелёного гейта любыми
фиксами», тем более фиксами чужой активной волны. Чужая незакоммиченная работа
— не моя зона без явного слова.

**How to apply:**
- «напиши промпт / спланируй / исследуй» → deliverable = текст/док; git-действия
  только те, что явно заказаны (напр. «зарегистрируй маркер» после «ОК»).
- Красный гейт от чужой активной волны → ДОЛОЖИТЬ владельцу, не чинить её файлы.
- Не путать с [[feedback-dont-stop-to-ask-proceed]]: то правило — про «не вставать
  на развилке» ВНУТРИ явно порученной работы; это — про границу самой работы.
