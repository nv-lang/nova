# План 222.3 — модуль `polaris.extract`: типизированное извлечение из запроса

**Статус:** 📋 ДИЗАЙН, НЕ СОГЛАСОВАН. **Слой:** 2 (Polaris-ядро).
**Зависит:** 222.1 (Router — ✅ влит), [180.1](180.1-serde-parity-and-beyond.md) Ф.1 (serde
field-атрибуты — без `rename_all` любой реальный JSON-API мимо).
**Основа:** Axum `FromRequest` (форма) + **наш serde как ЕДИНЫЙ движок** (механизм).
**Родитель:** [222](222-http-framework.md) · **Карта:** [222.0](222.0-module-map.md).

## 1. Протокол

```nova
/// Извлечение значения из запроса. ВСЕГДА синхронно — тело уже буферизовано
/// (`ServerRequest.body []u8`), в отличие от Axum, где extractors async.
export type FromRequest protocol {
    .from_request(req ServerRequest) -> Result[Self, HttpError]
}
```

## 2. Встроенные extractor-типы (все — `value`-record с одним полем + property-аксессор)

```nova
export type Path[T]  value { priv data T }      // {name}-параметры пути
export type Query[T] value { priv data T }      // ?a=1&b=2
export type Json[T]  value { priv data T }      // тело как JSON
export type Bytes    value { priv data []u8 }   // сырое тело
export type Text     value { priv data str }    // тело как UTF-8
export type Headers  value { priv data HeaderMap }

// Доступ — property-метод по конвенции D117 (НЕ голое поле):
export fn Path[T]  @data() -> T => @data
export fn Query[T] @data() -> T => @data
export fn Json[T]  @data() -> T => @data
export fn Bytes    @data() -> []u8 => @data
export fn Text     @data() -> str => @data
export fn Headers  @data() -> HeaderMap => @data
```
**Синтаксис Nova не меняется:** Rust-паттерн `Json(input): Json<T>` невозможен и не нужен —
в теле `req.data()`.

## 3. Реализации `FromRequest`

```nova
#impl(FromRequest)
export fn Json[T Deserialize].from_request(req ServerRequest) -> Result[Json[T], HttpError] {
    match json_decode_body[T](req.body_bytes()) {   // существующий мост 178/180
        Ok(v)  => Ok(Json { data: v })
        Err(e) => Err(e)
    }
}

#impl(FromRequest)
export fn Path[T Deserialize].from_request(req ServerRequest) -> Result[Path[T], HttpError] {
    mut d = ParamsDeserializer.at(req.params())
    match T.deserialize(d) {
        Ok(v)  => Ok(Path { data: v })
        Err(e) => Err(HttpError.decode_error(e.to_str()))
    }
}
// Query[T] — зеркально через QueryDeserializer.at(req.query())
// Bytes/Text/Headers — тривиальные (без serde)
```

## 4. Источники-`Deserializer` (ключевой архитектурный кусок: 0 строк Rust)

Реальный API (сверено `std/src/encoding/serde/serde.nv:124-165`): навигация по имени
`@enter_field(key) -> Result[Self, DeError]` + чтение по ТИПУ `@deser_int()`/`@deser_str()`/…
Синтез компилятора генерит `d.enter_field("id")?.deser_int()?`.

```nova
/// Плоский источник над [](str, str) — path-параметры.
export type ParamsDeserializer value { priv pairs [](str, str), priv cur Option[str] }
export fn ParamsDeserializer.at(pairs [](str, str)) -> ParamsDeserializer

/// Тот же контракт над query-строкой (percent-decode + split '&'/'=').
export type QueryDeserializer value { priv pairs [](str, str), priv cur Option[str] }
export fn QueryDeserializer.at(query str) -> QueryDeserializer
```
Оба реализуют `Deserializer`: `@enter_field(key)` находит пару и ставит под-курсор;
`@deser_int()` парсит строковое значение текущего курсора (`str.to_int()`, ошибка → `DeError`);
`@deser_str()` отдаёт как есть; `@is_null()` — курсор пуст (для `Option`-полей).
**`T` синтезируется `#impl(Deserialize)` ОДИН раз и работает со всеми тремя источниками.**

## 5. Регистрация хендлеров с extractors (арность-перегрузки на `Router`)

```nova
export fn Router mut @get[R IntoResponse](path str, h fn() -> R) -> Result[(), HttpError]
export fn Router mut @get[T1 FromRequest, R IntoResponse](path str, h fn(T1) -> R) -> Result[(), HttpError]
export fn Router mut @get[T1 FromRequest, T2 FromRequest, R IntoResponse](path str, h fn(T1, T2) -> R) -> Result[(), HttpError]
// … до 4; @post/@put/@delete/@patch — то же семейство
```
Тело (остальные — механическая копия по арности):
```nova
=> @get(path, Handler.new(fn(req ServerRequest) -> ServerResponse {
       match T1.from_request(req) {
           Ok(v1) => h(v1).into_response(),
           Err(e) => e.into_response(),
       }
   }))
```
Существующая форма `@get(path, Handler)` ОСТАЁТСЯ (низкоуровневый эскейп-люк).

**ЛОВУШКА (протокол «стоп+отчёт», НЕ обход):** резолв generic-overload по арности+bound —
класс `[M-concrete-instance-arity-overload-mangle]` (стрелял на П21). Если споткнётся —
чекпоинт + отчёт интегратору.

## 6. State/DI — замыкания, НЕ `State<T>`

```nova
fn make_get_user(db Db) -> Handler =>
    Handler.new(fn(req ServerRequest) -> ServerResponse { /* db захвачен */ })
mux.get("/users/{id}", make_get_user(pool))!!
```
Компайл-тайм-проверено: забыл зависимость → ошибка компиляции (у Axum `State<T>` — рантайм-паника,
у FastAPI `Depends()` — рантайм-резолв).
