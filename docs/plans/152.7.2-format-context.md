## Объём

1. **Протокол `Fmt`** поверх `Write` (аксессоры спека: `@alternate() -> bool`,
   `@precision() -> Option[int]`) + второй ОПЦИОНАЛЬНЫЙ метод `@display_fmt(mut f Fmt)`;
   типы без него живут по-старому (`@display(mut w Write)` + пост-обработка у вызывающего) —
   БЕЗ повторной ломки сигнатур после D374.
2. **`#` (alternate) = канонический pretty-флаг**: `"${v:#}"`; первый потребитель —
   `JsonValue @display_fmt` (эквивалент `to_str_pretty`).
3. **Оси типу:** alternate, precision; width/fill/align остаются пост-обработкой
   у вызывающего; radix — встроенные числовые пути.
4. **Движок интерполяции — прямо-в-sink:** `${x}` лоуэрится в `@display(mut sb)`
   без промежуточной str; `str.from` уходит из интерполяционного пути
   (остаётся конверсией по 174.1-канону). Примитивы — через рантайм-хелперы
   152.7-B (`nova_fmt_int_body` и семейство); в т.ч. переделка тел вида
   `fn int @display(mut w Write) => w.write(str.from(@))` (вопрос владельца
   2026-07-13 об аллокации). Если путь примитивов глубоко вплетён —
   маркер `[M-d419-interp-direct-primitives]`, хвост отдельной короткой волной.
5. `E_FORMAT_SPEC_UNKNOWN` смягчается ТОЛЬКО для типов с `@display_fmt`;
   протухший `[M-91.14-format-dsl-extensions]` закрывается ссылкой на D419;
   Q-блок помечается RESOLVED.
