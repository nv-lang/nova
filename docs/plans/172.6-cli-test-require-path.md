# Plan 172.6 — `nova test` требует явный путь

## Цель

`nova test` без аргументов сейчас молча берёт корень репо (все `.nv` файлы в дереве).
Это опасно: случайный запуск из worktree запускает полный прогон вместо целевой папки.
Нужно: если `paths` пусто — ошибка с подсказкой.

## Изменение

**Файл:** `nova-cli/src/main.rs`

Два места с одинаковым паттерном:

```rust
// Строка ~1392 (run_test функция)
let resolved_paths: Vec<PathBuf> = if paths.is_empty() {
    owned_root = find_repo_root()?;
    vec![owned_root.clone()]   // ← убрать
} else {
    paths.iter().cloned().collect()
};

// Строка ~1488 (вторая функция с тестом)
let resolved_paths: Vec<PathBuf> = if paths.is_empty() {
    owned_root = find_repo_root()?;
    vec![owned_root.clone()]   // ← убрать
} else {
    paths.iter().cloned().collect()
};
```

Заменить оба блока на:

```rust
let resolved_paths: Vec<PathBuf> = if paths.is_empty() {
    return Err(usage_err("nova test requires at least one path\n  example: nova test spec_tests/conformance"));
} else {
    paths.iter().cloned().collect()
};
```

Также обновить doc-comment аргумента (строка ~415):

```rust
// было:
/// Paths to test (files or directories). Default: `<repo>/nova_tests/`.
// стало:
/// Paths to test (files or directories). Required.
```

И в описании команды (строка ~408) убрать строки про дефолт.
