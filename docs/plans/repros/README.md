# repros/ — доказательная база реестра дефектов

Минимальные воспроизводящие файлы (`.nv`), на которые ссылаются записи реестра
[221.1-bug-sweep.md](../221.1-bug-sweep.md) и [backlog-followups.md](../backlog-followups.md).

Правила:
- Файл попадает сюда В МОМЕНТ заведения №, если репро не выражается conformance-фикстурой
  (живой краш/вечный цикл/OOM — то, что нельзя держать в тест-прогоне).
- Имя: `nNNN-<короткий-слаг>/` (папка = изолированный модуль; folder-module не даст
  случайных импортов) либо одиночный `nNNN_<слаг>.nv`.
- После ЗАКРЫТИЯ № репро либо превращается в conformance-фикстуру (предпочтительно),
  либо удаляется ТОЙ ЖЕ волной с пометкой в записи реестра.
- Прогон руками: `nova-cli/target/release/nova.exe build|check <файл>` — эти файлы
  НЕ входят ни в какой автоматический тест-прогон.
- Сессионные черновики сюда НЕ кладутся (для них — нетрекаемый scratch, см. .gitignore).
