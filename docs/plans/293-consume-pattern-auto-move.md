# План 293 — consume-паттерн без маркера там, где выбора нет (вариант 1 исследования 16)

коммитом, что этот план), дальше Ф.1 — улика по факту №4. Слово владельца 2026-09-24

## Правило (вариант 1)

Биндинг payload-паттерна must-consume типа без маркера `consume` законен ТОГДА И
ТОЛЬКО ТОГДА, когда имя использовано ровно один раз и это использование — форсируемый
перенос: хвост арма, `return`, аргумент конструктора (`Ok(v)`, `Some(v)`, литерал
записи). Любое иное использование (вызов метода или функции, второе упоминание,
захват замыканием, view-использование) — по-прежнему `E_CONSUME_PATTERN_REQUIRED` с
тем же предложением «insert consume». Правило синтаксическое и потому работает и в
обобщённых телах (закрывает факт №3 исследования нормативно).

## Этапы и приёмка

### Ф.0. Амендмент D157 (спека до кода)

Амендмент к консум-волне А — она живёт в разделе D157 `spec/decisions/05-memory.md`
— и обзорная страница (`spec/syntax.md` / `.ru.md`); spec-queue для Карины +1. **Приёмка глазами, потому что** это текст
нормы: интегратор сверяет, что формулировка правила выше и список форм совпадают
дословно, и что июльское «вариант А» не отменено, а сужено.

### Ф.1. Факт №4 — только при воспроизведении

Факт №4 исследования (перегрузки по режиму: проверка выбирает consume-версию,
исполняется view-версия) интегратором НЕ воспроизведён на двух формах (кучевой
consume-тип и `consume value`). Исполнителю, заявившему факт, — положить пробу
файлом. **Воспроизвёлся** — строка реестра (молчаливая утечка ресурса, К1 по
политике владельца), фикс и фикстура ДО Ф.2; **не воспроизвёлся** — пункт
закрывается записью «не подтверждено, проба такая-то».

### Ф.2. Оракул — только если дёшево

**Машинные критерии.** (1) `spec_tests/conformance/` — позитивная фикстура на каждую
форму переноса (`Ok(s) => s`, `Ok(v) => Ok(v)`, `Some(v) => Some(v)`, `return v`,
литерал записи) без маркера — PASS, сборка и запуск, ресурс закрыт ровно один раз;
(2) негативная фикстура на каждую иную форму (`Ok(s) => s.close()`, два упоминания,
захват замыканием, вызов свободной функции) — `E_CONSUME_PATTERN_REQUIRED`
построчно (`nova:expect`); (3) обобщённое тело (`map_err`-форма) — правило
применяется, фикстура; (4) `nova test spec_tests std` не краснеет. **Проба в обе
стороны:** правило, забывшее «ровно один раз», — краснеет негативная «два
упоминания»; вернуть — зелено. **Дёшево** значит: одна проверка формы в чекере, без
правки резолвера и кодогена; иначе Ф.2 не делается и правило ждёт Ф.3.

### Ф.3. Карина — в волне consume

по тем же критериям.
