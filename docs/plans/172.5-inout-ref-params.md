## 1. Цель

Ввести `ref` как **режим передачи параметра** (Swift `inout` / C# `in`+`ref`), НЕ тип: безопасная in-place мутация caller-значения (`mut ref`) и zero-copy чтение больших стек-значений (`ro ref`, авто) — без сырых указателей, без лайфтаймов. Формализовать `@`-ресивер как частный случай (`mut @ ≡ mut ref @`, `-> @ ≡ ref @`). Полный нормативный дизайн — [D326](../../spec/decisions/02-types.md#d326) (R1-R12).

**Что закрывает (дыра `mut @`-only из Q29):** out-параметры, мутация не-ресивера, несколько mut-аргументов (`swap(mut ref a, mut ref b)`). **Для одиночной мутации канон остаётся `mut @`** — `mut ref` узкий инструмент, не «способ менять любой параметр».

## 2. Дизайн (из D326 — здесь только карта)

| Ось | Правило (D326) |
|---|---|
| Форма | `ro ref a T` (авто/невидимо — это 172.4) · `mut ref a T` (явный, единственный user-facing) |
| Call-site | `inc(ref x)` (короткий `ref`-маркер; `ro ref` маркера нет) |
| `@` ABI | `mut @` всегда by-ptr (любой размер); `ro @` size-discretionary |
| `-> @` | режим = режим ресивера (D181); цепочка гейтит (`c.peek().bump()` → `E_RECEIVER_BINDING_NOT_MUT`); consume `@ -> @` → `E_CONSUME_RECEIVER_RETURNS_AT` |
| `-> @` биндинг | heap/consume/builder → **алиас** (D131/D132); value-record → **копия** (D246 оракул) — НЕ blanket-copy |
| value-`@` escape | decay by-value при bind/return/store (R8) — не висячий ptr |
| Эксклюзивность | УЗКАЯ: same-call same-root prefix-overlap → `E_REF_ALIAS_OVERLAP`; **НЕ Rust/Swift-гарантия** (GC, D157/D246-P10) |
| Эскейп | `ref` не хранить/захватывать/возвращать (кроме `@`) — sync-call lifetime |
| FFI | граница берёт сырой `*`/`*mut`, никогда `ref` |
| Дженерики | `fn f[T](mut ref x T)` ок; `[T consume]`-bound несовместим; `mut ref`≠consume |

## 3. Фазы

- **Ф.0 — Спека (готово).** D326 + amend Q29 (✅ 2026-06-26). Acceptance-кейсы (§4) согласованы.
- **Ф.1 — Parser (✅ 2026-07-06).** `ro ref`/`mut ref` на параметре (`ParamRefMode`); call-site `ref <place>` (`ExprKind::RefArg`, только arg-позиция). Реджект `ref` в тип-позиции → `E_REF_NOT_A_TYPE` (локал/поле/возврат/коллекция — все через `parse_type`). Голый `ref` без `ro`/`mut` → `E_REF_MODE_REQUIRES_RO_OR_MUT`. `consume @ -> @` → `E_CONSUME_RECEIVER_RETURNS_AT` (реюз существующей проверки). `consume ref`/`const ref` конфликты. `ref` — глобальное keyword (0 идент-использований в кодовой базе → non-breaking).
- **Ф.2 — Checker (✅ 2026-07-06).** Place-overlap отношение `RefPlace` (per-pair prefix, НОВОЕ — рядом с consume place-анализом, не решёткой) → `E_REF_ALIAS_OVERLAP` на same-call same-root. Index-disjoint: только int-литералы (V1, без SMT); dynamic-индекс → консервативный overlap. Marker⟺mode (R4): `E_REF_MARKER_REQUIRED`/`E_REF_MARKER_NOT_ALLOWED` (в `BoundCtx.check_ref_arg_modes` через argbind). Addressability: `E_REF_ARG_NOT_ADDRESSABLE` (реюз `addr_of_chain_root`). Mut-place: `E_REF_ARG_NOT_MUT` (в main-pass `f1_expr` RefArg-арме, где живут `ro_binding_names`+`check_target_readonly`). Escape-ban (R10): `E_REF_ESCAPE_CAPTURE` — захват `mut ref`-параметра closure/spawn/parallel/supervised/detach. Borrow ≠ move (D131/D133 не трогаем — RefArg в consume-walk = обычный use, не consumed).
- **Ф.3 — Checker: `-> @` mode + chain-gating — ⏸ ОТЛОЖЕНО** (`[M-172.5-chain-gating-ro-at]`). parse-часть (`consume @ -> @`) сделана в Ф.1. Гейтинг `mut @` на `ro ref @`-цепочке (`c.peek().bump()` → `E_RECEIVER_BINDING_NOT_MUT`) требует моделирования режима `@`-возврата сквозь method-chain (глубокая связь с fluent-машинерией 172.4, вне soundness in-out `mut ref`). Сейчас такой вызов компилируется (value-record `-> @` = копия по R7b — мутация копии безвредна).
- **Ф.4 — Codegen / ABI (✅ 2026-07-06 для `mut ref`).** `mut ref` param → C-указатель `T*` (единый `params_c` для forward-decl+definition, R5); body-использования авто-разыменовываются (`ref_params` в эмиттере); call-site `ref x` → `&x`. Форвардинг `ref`-параметра работает (`&(*v)≡v`). Скаляр+record проверены. `ro ref` авто — это **172.4** (НЕ дублировано; explicit `ro ref` = обычная value-передача). Generic `fn f[T](mut ref x T)` codegen — отложен (`[M-172.5-generic-mut-ref-codegen]`). value-`@` escape-decay (R8) / FFI-pin (R11) — домен 172.4/174.
- **Ф.5 — Тесты (✅ 2026-07-06).** `nova_tests/inout_ref/`: pos (2) — `inc(mut ref)`, `swap(mut ref a, mut ref b)`, `f(mut ref x.a, mut ref x.b)` disjoint, `mut ref` record, `ro ref` read, nested-forward. neg (11) — `E_REF_ALIAS_OVERLAP` ×2 (same-var, field-prefix), `E_REF_MARKER_REQUIRED`, `E_REF_MARKER_NOT_ALLOWED`, `E_REF_ARG_NOT_ADDRESSABLE`, `E_REF_ARG_NOT_MUT`, `E_REF_NOT_A_TYPE` ×2 (local, return), `E_CONSUME_RECEIVER_RETURNS_AT`, `E_REF_MODE_REQUIRES_RO_OR_MUT`, `E_REF_ESCAPE_CAPTURE`. Все зелёные. (fluent `mut @ -> @`-цепочка acceptance — §4 работает; chain-gating neg — с Ф.3.)
- **Ф.6 — Закрытие (частично).** Регрессия: byte-identical C-emission на 580 файлах (2 стрида), delta 0; Rust clean. spec D326 амендмент + plan + backlog обновлены. Полный `nova test` — не гонялся (out-of-budget; регрессия покрыта byte-diff).

## 4. Acceptance-критерии

```nova
// (1) in-out: мутация caller-значения через не-ресивер-параметр
fn inc(mut ref a int) { a = a + 1 }
mut x = 5
inc(ref x)
assert(x == 6)

// (2) несколько mut-аргументов (mut @ не выражает)
fn swap(mut ref a int, mut ref b int) { ro t = a; a = b; b = t }
mut p = 1; mut q = 2
swap(ref p, ref q)
assert(p == 2 && q == 1)

// (3) разные поля — ок; одно место дважды — ошибка
fn f(mut ref m int, mut ref n int) { ... }
mut s = Pair{a: 0, b: 0}
f(ref s.a, ref s.b)        // OK
// f(ref s.a, ref s)       // E_REF_ALIAS_OVERLAP

// (4) fluent value-record (общий с 172.4) + chain-gating
type P value { x int }
fn P mut @inc() -> @ { @x += 1; @ }
ro p2 = P{x: 0}.inc().inc()   // value-record: биндинг = копия (R7b)
assert(p2.x == 2)
// c.peek().bump()             // E_RECEIVER_BINDING_NOT_MUT (peek ro, bump mut)
```
- **[M-177-ifexpr-value-materialize-codegen]-fixture** (fluent `-> @`-хвост в if-цепочке, base64 `decode_with`) — **должна и дальше компилиться** (R7/R8 не регрессят R3-фикс `836befcb`).
- **Без упрощений, как для прода** (обязательный критерий).

## 5. Риски / открытые

- **Эксклюзивность-скоуп (R9).** Узкая — не заявлять Rust/Swift-гарантию; явно оговорить «sound-под-GC везде ещё» (D157/D246-P10). Риск over-claim → ложная безопасность. Mitigation: фикстуры на «aliased-mut через указатель/heap НЕ ловится — by design».
- **`-> @` биндинг alias-vs-copy (R7).** Главная поправка дизайна: НЕ blanket-copy. Amend D132 (alias-гарантия load-bearing для consume-чекера). Риск: копия heap-builder'а раздвоит хэндлы → потеря use-after-consume.
- **value-record `-> @` mid-chain in-place** (`mut y = x.foo()` same-slot вместо copy при доказанном escape) — **отложено** (`[M-172.5-value-at-inplace-bind]`, перф-only, гейт на Q-value-abi-auto-placement). V1: всегда copy-on-bind для value-record + опц. lint `W_FLUENT_VALUE_RECORD_COPY`.
- **Index-disjoint i≠j** — V1 literal-only; SMT-прувер не вводим (нет в спеке).
