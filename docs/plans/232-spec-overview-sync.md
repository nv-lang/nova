## Ф.1в — Аудит статус-строк D-блоков (находка владельца 2026-07-26: D412 «Реализация в очереди» на сайте при факте ✅ 2026-07-09)

Третий класс дрейфа: «Статус:»-строки D-блоков не обновляются волнами-реализаторами.
Механика: греп decisions по «в очереди|не реализован|PARTIAL|в работе|pending|ожидает|

Правило впредь (dev-workflow-строка): волна, реализующая/закрывающая D-блок, обновляет
его Статус-строку ТЕМ ЖЕ слиянием (как амендменты). Прецедент-фикс: D412 (2026-07-26).
