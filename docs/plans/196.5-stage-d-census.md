## 1. Пре-существующие дефекты корпуса (НЕ регрессии этой сессии; замеру частично мешают)

Все воспроизводятся на чистой базе `f64c9fdec` без каких-либо правок:

1. **P67-LEGACY panic `method=deserialize` (Path-форма, терминал B12q)** — компиляция модуля
   `std/src/encoding/serde` (и зависимого `std/src/http/serdejson`) убивает процесс раннера:
   `[P67-LEGACY] Path call return type unknown for method=deserialize`. Следствие: серде-корпус
   ПОСЛЕ точки паники не измерен; `B11ai_serialize_contract` 0-hit НЕ доказателен (регион
   недостижим для замера, пока жив этот panic). Терминал `B12q_panic_path_p67` при этом
   ДОКАЗАННО живой (hit = сама паника).
2. **P67-LEGACY panic `.until` на `nova_str` (Member-форма, терминал B11al)** —
   `examples/real_world/orm_decorators.nv:65` (`rest.until(" WHERE ")`): метод `until` не знает
   ни чекер, ни legacy → терминальная паника. Терминал `B11al_panic_method_p67` доказанно живой.
3. **nova-tls `[D133-not-consumed]`** (`d:/Sources/nv-lang/nova-tls/src/stream.nv:44`) — все
   tls-зависимые цели (examples/tls/*, examples/flagship/aggregator/server*, свободные
   `std/src/http/*.nv`-файлы с транзитивной tls-зависимостью) падают CODEGEN-FAIL до эмита →
   их трафик не добавлен (компиляция обрывается в чекере, часть трафика всё же собрана до обрыва).
4. **CC-FAIL std/src/concurrency/retry_test** (`nova_str` vs `Nova_T*` в сгенерированном C) и
   **supervised_deadline_test** (`no member 'cancel' in Nova_WriteBuffer`) — codegen доехал до C
   (трасса собрана), C-компилятор упал. Пре-существующие.
5. **E7001 examples/real_world/orm_demo** — closure-arg return `U` для `.map()` на
   `Vec____uint64_t` не резолвится ни каналом, ни inference (честная диагностика вместо тихого
   nova_int). Пре-существующий.
6. **RUN-FAIL examples/net/echo_server** — bind порта 7777 (окружение), не компилятор.
