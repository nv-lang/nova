**Ветка:** `stage-d-census` (worktree `nova-p196`), база `f64c9fdec` (Stage-D волна-1, реестр 62→54).
**Задание:** замер БЕЗ правок поведения — трафик каждой из 54 оставшихся `icr_trace`-веток на

## 2. Сверка с каналом (probe на входе функции)

Замер (jobs=1, упорядоченные пары ENTRY→CNT): **conformance** — 4040 входов в `infer_call_ret_c`,
из них `ch2=true` (в `resolved_types` ЕСТЬ запись для этого call-id) — **24**, `subst=true`
(`node_substs`) — **0**; все 24 ch2-входа маршрутизируются в **B07**. **vec_iter+vec_lazy** — 338
входов, ch2=2 (оба B07), subst=0.

**Вывод:** «дублирующих канал» веток нет — легаси-трафик по построению = промах Channel-2
(диспетчер читает канал первым), и probe подтверждает: чекер для этих call-site'ов данных
не производит (эрейзд/generic caller-контекст, mono-клоны — диагноз RESUME-4/волны-1
подтверждён прямым замером). Исключение — 24 сайта B07 (0.8% его трафика), где запись в канале
ЕСТЬ, но верхнее чтение её пропустило (гейт closure_channel_miss / generic-stub fallthrough —
тот же феномен, что описан у `B11ah`); равенство значений на этих 24 не проверялось (пары
примеров достаточно для вывода «композиция возможна точечно, не оптом»).

## 5. Кандидаты волны-3 (сводка)

1. **Снос:** `B11ah_resolved_types_channel_late` — единственный нулевой-и-снимаемый (с разбором
   гейта верхнего чтения). Опционально вместе с ним: закрыть вопрос B11i прогоном
   nova_tests/concurrency (если 0 и там+структурный аргумент — снять вторым).
2. **Фиксы-в-новый-путь (§10), попутно осушающие терминалы:** (а) `deserialize` Path-return в
   чекер → гасит панику §1.1, разблокирует серде-замер B11ai; (б) `str.until` → prelude/чекер →
   гасит панику §1.2. Оба = пре-существующие user-visible баги (zero-tolerance вход).
3. **Точечная композиция (микро-трафик ≤ 12, §3.2):** B10a, B10c, B10d, B11m, B12c, B11ag, B11x
   (builtin-таблица), B10m — перенос декларированных возвратов (CAP-DECL-RET), после каждого —
   ре-замер ветки до 0 и снос. Дешёвые атомы, но это ПЕРЕНОС, не «снятие мёртвого».
4. **Ядро (B01/B06*/B07/B07r/B10j/B11a/B11d)** — НЕ волна-3: требует продюсера для
   erased/mono-клон call-site'ов (owner-gated развилка 196.2 «ExprId-coverage»); канал пуст на
   99.2% их трафика (§2), композиция Stage-C2-стиля применима только к 24 B07-сайтам.
