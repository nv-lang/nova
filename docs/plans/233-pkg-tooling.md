## 1. Прокси для скачивания пакетов (запрос: «задание прокси при описании в nova.toml»)

Индустрия-канон: прокси — свойство СРЕДЫ разработчика, не пакета (cargo: ~/.cargo/config.toml
[http].proxy, НЕ Cargo.toml; go: GOPROXY env) — в коммитимом nova.toml прокси создал бы
переносимость-ловушку (у каждого свой). ПРОЕКТ РЕШЕНИЯ (слоями, первый существующий выигрывает):
1) env `NOVA_PKG_PROXY` (плюс уважение стандартных `HTTPS_PROXY`/`HTTP_PROXY` — git-скачивание
   уже уважает их само; проверить, что наш git-вызов не стерилизует env);
2) `[net] proxy = "http://…"` в НЕкоммитимом `nova.local.toml` (機анизм replace уже там живёт);
3) глобальный пользовательский `~/.nova/config.toml` `[net] proxy` (новый файл-слой — минимально).
В коммитимом nova.toml — НЕ поддерживать (осознанно; при несогласии владельца — обсудить).
Реализация: nova-cli git-fetch путь + докстрока в 07-modules/D-план package tooling.

Проблема: расширение `.lock` абстрактно — редакторы не включают TOML-подсветку.
Варианты: (а) **nova-lock.toml** (вариант владельца; прецедент pnpm-lock.yaml — «инструмент-lock.формат») —

эффект, сортируется вплотную к nova.toml); (в) оставить nova.lock + files.association в нашем
VSCode-экстеншне и №103-волне — ноль ломки, но работает только с нашим плагином.
**РЕШЕНИЕ (итерация с владельцем 2026-07-26, «либо дефис, либо точка — подумай»): ТОЧЕЧНАЯ СХЕМА** — nova.toml / nova.lock.toml / nova.local.toml: главный файл всё равно с точкой (дефис дал бы смесь), «nova.» = единый префикс-семейство (glob nova.*, сортировка рядом), двойные расширения — повсеместный прецедент (*.d.ts, *.tar.gz), и миграция минимальна: nova.local.toml УЖЕ существует и не трогается — переименовывается только nova.lock → nova.lock.toml.

## 2а. Опция-унификация (вопрос владельцу, одна строка)

Владелец в утверждении написал «nova-local.toml» (дефис) — сейчас файл `nova.local.toml`
(точка). ИТОГ ИМЕНОВАНИЯ (исследование по запросу владельца, 2026-07-26): схема
nova.toml / nova.lock.toml / **nova.override.toml** (local→override: визуальная коллизия
lock/local снята; «override» точнее по содержимому — replace-пути/прокси = оверрайды
резолва; прецедент механики docker-compose.override.yml; «dev» отклонён — dev-файлы в
индустрии обычно коммитятся командой, наш — персональный). Некоммитимость закрепляется
МАШИНОЙ, не именем: .gitignore-запись во всех репах + pre-commit-блок на staged
nova.override.toml (231.2-класс). Миграция обоих имён (nova.lock, nova.local.toml) —
чтение старых с warning, запись новых, переименование по репам той же волной.
