# План 210 — `embed_dir(...)`: вшить папку в бинарь (расширение D412)

> **Статус: 📋 READY (вариант A принят владельцем 2026-07-15), НЕ ЗАПУЩЕН.**
> Источник дизайна: [research 2026-07-15 embed-dir](../research/2026-07-15-embed-dir-proposal.md)
> (§3 вариант A + cross-language survey). Маркер: `[M-embed-dir]` (backlog, APPROVED/queued).
> Родитель: [D412](../../spec/decisions/03-syntax.md#d412) (`embed("file")`, single-file).
> **Язык-меняющее** — D412-амендмент (или новый D-блок) едет В ТОМ ЖЕ слиянии, что код
> (правило lang-change-needs-spec). Приоритет P3 (удобство, не блокер: single-embed +
> самодостаточный html покрывают MVP флагмана 187).

## 0. Цель (одна фраза)

`embed_dir("dir")` — компайл-тайм интринсик: вшивает ВСЮ папку в бинарь и возвращает
иммутабельный `EmbeddedDir` (карта `путь→[]u8`, нулевая копия), чтобы «фронт целиком в
программе» собирался одной строкой (Go `//go:embed`+`embed.FS`-эргономика).

## 1. Дизайн (вариант A — зафиксирован)

```nova
ro assets = embed_dir("frontend")            // тип: EmbeddedDir
ro body = match assets.get("app.js") {       // Option[[]u8], нулевая копия
    Some(b) => b
    None    => not_found_bytes()
}
for p in assets.paths() { … }                // []str — перечисление вложенных путей
```

- **`EmbeddedDir`** (std-тип, nv-sourcing): `get(path str) -> Option[[]u8]` +
  `paths() -> []str` + `len() -> int`. Иммутабелен.
- **Нулевая копия**: каждый файл → свой `static const uint8_t nova_blob_<n>[]` в
  `.rodata` (как single-`embed`, D412 §«Материализация»); `get` возвращает `[]u8`-вид
  на блоб (`len==cap==N`), не GC-копию. Мутирующие методы отсекает чекер.
- **Ключ**: путь относительно embed-корня, POSIX-слэши, детерминированный порядок
  (сорт путей) для воспроизводимого `.c`.
- **Рекурсия**: по умолчанию весь поддеревья (glob-фильтр — future, не в этом плане).
- **Границы** (как D412): аргумент — только строковый литерал; `..` выше корня проекта —
  ошибка; папка не найдена — ошибка (E_EMBED_DIR_NOT_FOUND); пустая папка → пустой
  `EmbeddedDir`; символ-линки — НЕ следовать (safety).
- **Fingerprint пересборки**: все файлы папки — build-зависимости (add/rm/change →
  пересборка), как single-embed.
- **Content-Type — вне объёма** интринсика (он про байты). Опц. mime-хелпер в std/http —
  отдельно/позже.

## 2. Фазы

| Фаза | Что | Гейт |
|---|---|---|
| **Ф.0 — спека** | D412-амендмент (или новый D-блок) в [03-syntax.md](../../spec/decisions/03-syntax.md): `embed_dir` форма, EmbeddedDir-контракт, границы, детерминизм, коды ошибок (E_EMBED_DIR_NOT_FOUND, переиспользовать E_EMBED_OUTSIDE_PROJECT). | Спек-текст ревьюабелен; едет с Ф.2-слиянием |
| **Ф.1 — std-тип** | `EmbeddedDir` в std (nv): поля-таблица (пары путь→view), `get`/`paths`/`len`. Форма представления таблицы согласована с Ф.2-эмиссией (статические пары). | `nova check std` δ-нейтрально; юнит-тест типа (рядом с модулем) |

Ф.4-фикстуры |
| **Ф.3 — флагман-потребитель** | `examples/flagship/aggregator`: показать `embed_dir` (даже если фронт пока 1 файл — как демонстрация; либо разнести assets). Опционально — не блокер плана. | Пример собирается+обслуживает |
| **Ф.4 — тесты** | Фикстуры (в проект-примера/spec_tests по конвенции §116): pos — embed_dir 3-файловой папки → get каждого → байты совпадают, paths()==3, порядок детерминирован; neg — папка-не-найдена (E_EMBED_DIR_NOT_FOUND), `..` наружу (E_EMBED_OUTSIDE_PROJECT), не-литерал-аргумент; edge — пустая папка. | Точечно зелёные |

## 3. Гейты приёмки (весь план)

1. D412-амендмент в спеке В ТОМ ЖЕ слиянии, что код (Ф.0 ↔ Ф.2).
2. Точечные фикстуры Ф.4 зелёные; `nova check std` δ-нейтрально.
3. Нулевая копия проверена: `embed_dir` на большой папке НЕ раздувает heap
   (блобы в .rodata, `get` — view). Детерминизм: два билда → идентичный порядок в `.c`.
4. conformance один CU δ0 — **авторитетный полный гейт делает ОРКЕСТРАТОР** при вливании
   (исполнителю — CPU-дисциплина, мега-CU не гонять).
5. Маркер `[M-embed-dir]` снят из backlog + лог в simplifications.

## 4. Исполнители (карта моделей)

- **sonnet** — Ф.0 (спека) + Ф.2 (resolver+emit_c — компиляторное ядро) + Ф.1 (std-тип);
  worktree `nova-p210`, в main НЕ мёржить (гейт у оркестратора).
- **haiku** — Ф.4 механика фикстур по образцу single-embed-теста (`d412_embed_fixture`) —
  ТОЛЬКО в worktree, в main-репу не заходить.
- Правила: суб-агентов НЕ спавнить; ФОНОВЫХ прогонов не запускать (синхронно); CPU-
  дисциплина (мега-CU не гонять, точечная верификация; авторитетный гейт — оркестратор);
  чекпоинт прогресса в файл (rate-limit-устойчивость); греп конфликт-маркеров ОДНОЙ
  командой с коммитом; git add по именам; без Co-Authored-By; спек-амендмент в том же
  слиянии.

## 5. Вне объёма

- Glob-фильтр (`embed_dir("dir", "*.html")`) — future, отдельный заход при нужде.
- Content-Type/mime-роутинг — хелпер std/http, не интринсик.
- Сжатие вшитых ассетов (gzip-in-binary) — future (гейт nova-compress).
