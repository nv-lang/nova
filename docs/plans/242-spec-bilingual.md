**Статус:** 🆕 PLANNED (записан 2026-08-02 по обсуждению с владельцем; запуск — по слову владельца).
**Приоритет:** P3 (сайт/дока; не блокирует релизные хвосты).
**Дом плана:** nova (слово владельца 2026-08-02: спеки/доки живут в nova docs) — источник переводов здесь; сайт-фаза исполняется в www со ссылкой сюда.
**Конвенция:** [docs/dev/doc-conventions.md](../dev/doc-conventions.md) (создана этим же коммитом) — язык/нормативность/дрейф нормативны для плана.

## 0. Мотив

`/spec/syntax/` и остальные spec-страницы на en-сайте показывают русский текст
(спека ведётся только по-русски); сейчас там честная пометка «maintained in
Russian only» (волна 2026-08-02). Цель — настоящие en-страницы спеки без
потери нормативности русского текста и без тихого устаревания переводов.

## 1. Объём и что НЕ переводим

Переводим 6 читательских файлов `spec/` (~4.1k строк):
`syntax.md` (1792), `revolutionary.md` (945), `conversions.md` (481),
`effects.md` (413), `overview.md` (257), `paradigm.md` (181).
НЕ переводим: `open-questions.md` (8.7k, внутренний рабочий док) и
`spec/decisions/` (~64k строк D-блоков) — остаются RU-only с пометкой на
сайте, до стабилизации.

## 2. Фазы

- **Ф.1 — переводы (nova):** `spec/<имя>.en.md` рядом с русским нормативом
  (схему НЕ переворачивать — `spec/*.md` остаётся русским нормативом,
  см. doc-conventions #language). Каждый файл: шапка «Informative
  translation; the Russian text is normative.» + frontmatter `source_rev`/
  `source_date` (doc-conventions #translation-drift). Код-примеры
  байт-в-байт. Исполнитель — sonnet (нормативная терминология, не механика),
  по файлу на батч, чекпоинт-коммит после каждого; суб-агентов не спавнить;
  git add по именам; работать в своём worktree.
- **Ф.2 — сайт (www, по site-conventions #plans-home — короткий план-указатель
  `www/plans/07` на этот план):**
  - синк: `content/spec/{en,ru}/`; en берётся из `*.en.md`, ru — из `*.md`;
  - маршруты: `/spec/<slug>/` = en-перевод, при отсутствии — fallback на
    русский текст с нынешней пометкой (ни одна страница не 404-ится);
    новый `/ru/spec/<slug>/` = всегда русский; hreflang + переключатель
    RU/EN только у существующих пар; ru-шапка ведёт на `/ru/spec/…`;
  - drift-баннер: `source_date` перевода старше даты ru-источника → «The
    Russian original has been updated since this translation»;
  - decisions: без изменений (RU-only, пометка уже стоит).
  - приёмка — site-conventions #acceptance + клик пар и fallback-страниц.
- **Ф.3 — поддержание:** периодическая волна «догнать дрейф» (обновить
  `*.en.md` по амендментам, освежить `source_rev`); между волнами дрейф
  честно виден баннером. Триггер — по слову владельца или при заметном
  расхождении.

## 3. Приёмка

- Ф.1: 6 файлов `*.en.md` с корректным frontmatter; примеры кода не
  изменены (diff по код-блокам пуст); выборочная вычитка терминов
  интегратором/владельцем.
- Ф.2: гейты www зелёные; `/spec/syntax/` — английский текст; `/ru/spec/syntax/`
  — русский; fallback-страница без пары показывает русский + пометку;
  drift-баннер проверен искусственным устареванием даты.
- Отчёты по-русски: модель, хеши, вердикты дословно.
