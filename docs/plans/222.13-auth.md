# План 222.13 — модуль `polaris.auth`: JWT/Basic/Bearer + сессии

**Статус:** ✅ РЕАЛИЗОВАН ~97% (ревизия 2026-07-31): Bearer/Basic/JWT/CookieJar/сессии+пример. SessionStore = EFFECT (эволюция 222.20 Ф.3 §Q2, не protocol из текста плана). OAuth2 — вне V1 по плану.
222.12 Ф.1 (для CORS-совместимости preflight+credentials).
**Основа:** формы `axum-extra` (typed-header extractors, cookie-jar); **крипто НЕ изобретаем** —
`std/crypto/{jwt,hmac}.nv` УЖЕ СУЩЕСТВУЮТ (проверено 2026-07-23).
**Родитель:** [222](222-http-framework.md) · [222.0](222.0-module-map.md).

## 1. Ключевой факт

**Новых внешних зависимостей НЕ нужно.** `std/crypto/jwt.nv` даёт `Jwt.decode_hs256(secret, token)`,
`std/crypto/hmac.nv` — HMAC. Наша работа — **обёртки-extractors**, а не криптография.
Это прямо снимает главный риск («не писать свою крипту»).

## 2. Извлекатели авторизации

```nova
/// Сырой bearer-токен из `Authorization: Bearer <token>`.
export type Bearer value { priv token str }
export fn Bearer @token() -> str => @token
#impl(FromRequest)
export fn Bearer.from_request(req ServerRequest) -> Result[Bearer, HttpError]
// нет заголовка / не Bearer-схема → 401 с `WWW-Authenticate: Bearer`

/// Basic-авторизация (RFC 7617).
export type BasicAuth value { priv user str, priv pass str }
export fn BasicAuth @user() -> str => @user
export fn BasicAuth @pass() -> str => @pass
#impl(FromRequest)
export fn BasicAuth.from_request(req ServerRequest) -> Result[BasicAuth, HttpError]

/// Проверенный JWT с типизированными claims.
export type Jwt[T Deserialize] value { priv claims T }
export fn Jwt[T] @claims() -> T => @claims
```

## 3. Проблема секрета — и её решение БЕЗ Extension-магии

`Jwt[T]` не может быть чистым `FromRequest`: ему нужен **секрет**, а `from_request(req)` его не
получает. Axum решает через `State<T>`/Extension (рантайм-резолв, паника при отсутствии).
**Наше решение — фабрика-замыкание** (компайл-тайм-проверено, §222.3 §6):

```nova
/// Строит middleware, кладущий проверенные claims в параметры запроса,
/// ЛИБО хендлер-обёртку — форма выбирается на Ф.0 (см. §5.1).
export fn require_jwt[T Deserialize](secret str) -> Middleware
```
Забыл передать секрет → **ошибка компиляции**, а не 500 в проде.

## 4. Сессии

```nova
/// Абстракция хранилища (in-memory для V1; Redis/БД — пользовательские реализации).
export type SessionStore protocol {
    @load(id str) -> Result[Option[SessionData], HttpError]
    mut @save(id str, data SessionData, ttl Duration) -> Result[(), HttpError]
    mut @destroy(id str) -> Result[(), HttpError]
}

export type MemorySessionStore value { priv ... }   // + TTL-выселение
export type SessionData value { priv kv [](str, str) }
export fn SessionData @get(key str) -> Option[str]
export fn SessionData mut @set(key str, v str) -> @

/// Middleware: читает cookie сессии, кладёт данные в запрос, ставит Set-Cookie при изменении.
export fn session[S SessionStore](store S, cfg SessionConfig) -> Middleware

export type SessionConfig value { priv cookie_name str, priv ttl Duration,
                                  priv secure bool, priv http_only bool, priv same_site SameSite }
```
Cookie-механика — на существующем `cookie.nv` (10 экспортов).
**Дефолты безопасные:** `http_only=true`, `secure=true`, `same_site=Lax` (иначе — типовая дыра).

## 5. Открытые вопросы (Ф.0, не угадывать)

1. **Форма JWT-инъекции:** middleware, кладущий claims в `req.params()`-подобный канал, ИЛИ
   обёртка-хендлер, ИЛИ `Jwt[T]` как extractor + глобальный секрет через замыкание при
   регистрации. Решить пробой — от этого зависит вся эргономика.
2. **Хранение секрета** — не в коде: чтение из env (`std/os`), контракт «секрет не логируется»
   (проверить, что `Debug`-производные его не печатают).
3. **OAuth2** — V1 НЕ делаем (redirect-flow, PKCE, обновление токенов — самостоятельный объём);
   решить после реального запроса.

## 6. Фазы

- **Ф.0** ответы на §5 (пробы).
- **Ф.1** `Bearer`/`BasicAuth` (чистые парсеры заголовка + 401-семантика).
- **Ф.2** `Jwt[T]` поверх `std/crypto/jwt` в выбранной §5.1 форме.
- **Ф.3** сессии: `SessionStore`/`MemorySessionStore`/`session`-middleware + безопасные дефолты.
