# Репро №1140 — дверь языка, которую не считала ни одна мерка

Строка реестра: [221.1 №1140](../../221.1-bug-sweep.md). Волна, в которой найдено:
[274.7 В14](../../274.7-subset-to-spec.md).

## Что воспроизводится

Не падение и не неверный вывод — **молчаливая потеря отказа счётом**. Поэтому
воспроизведение здесь не «запусти и посмотри на ошибку», а **два числа, которые обязаны
двигаться навстречу**.

```sh
python scripts/guards/check-novac-subset-debt-dated.py .
```

В выводе есть пара: «ПО ДВЕРИ: отказов N» и «постоянных ошибок на своём коде M». Перевод
любого носителя с двери долга (`@refuse`) на дверь языка (`@reject`) обязан уменьшать N и
увеличивать M. До правки 2026-09-16 он уменьшал N и **не трогал** M: `LANG_DOORS` в
`scripts/guards/novac_subset_debt.py` знал `@reject_first_leaf_of` и не знал `@reject`.

Отказ, поданный через незнакомую дверь, выпадал из ОБЕИХ мерок.

## Пробы D405, на которых это вскрылось

Две половины в РАЗНЫХ каталогах намеренно: папка в Nova — один модуль, и два `main`
рядом столкнулись бы раньше предмета (так и вышло на третьем заходе).

- [`bad.nv.txt`](bad.nv.txt) — запрещённая форма `u8 + u16`;
- [`ok.nv.txt`](ok.nv.txt) — законный сосед `u16 + u16`, отличается ОДНИМ символом.

```sh
# каждую половину — в свой каталог, иначе столкнутся имена main
NOVA_STD_PATH="$PWD/std/src" ./novac/target/novac.exe check <каталог>/probe.nv
./nova-cli/target/release/nova build <каталог>/probe.nv
```

Ожидаемое после починки: оракул отвергает запрещённое кодом `E_MIXED_WIDTH_ARITH` (D405) и
собирает законное; novac отвергает запрещённое кодом **`E_NOVAC_LANG`** и молчит на законном.

## Чего эта проба НЕ доказывает

Что других таких списков нет. Дописан ОДИН перечень дверей; сколько ещё мер держат
рукописные списки ИМЁН вместо вопроса о свойстве — не измерено. Фикс носителя приёмкой не
считается.

## Цена угадывания формы пробы

Три редакции покраснели, **ни разу не дойдя до проверяемого правила**: объявленный
локальный тип (E2-b3), вызов внутри слота интерполяции, отсутствующая строка `module`.
Четвёртая скопировала форму у `examples/basics/arithmetic.nv` — файла из базы объёма
эмиссии, то есть заведомо читаемого Кариной, — и сработала сразу.
