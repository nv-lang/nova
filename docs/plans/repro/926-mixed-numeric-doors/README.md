# Пробы к №TBD — D405 закрывает арифметику разных ширин, но не сравнение, не int/float и не унарный минус на unsigned

Заведено исследовательским окном (owner-research) 2026-09-04 по вопросу владельца «чем плохо
автоматическое расширение числа при операциях над разными типами, делать ли нам, например
`-u8 → i16`?». Ответ спеки уже есть — D405 (2026-06-30): смешанная арифметика целых — ошибка,
расширение только явным `as`; D54: неявных числовых конверсий нет нигде. Проверено, где D405
держит, а где буква D54 не исполняется. Исследование: `docs/dev/research/2026-09-04-numeric-widening.md`.

## Как запускать


## Замер 2026-09-04 (owner-research, `nova-cli/target/release/nova.exe`)

| проба | выражение | `nova check` | `nova build` → stdout | что не так |
|---|---|---|---|---|
| `ctrl_arith` | `u8 + i16` — КОНТРОЛЬ | `E_MIXED_WIDTH_ARITH` (D405) | — | держит |
| `cmp_signedness` | `u32(4294967295) == i32(-1)`, `u32 < i32` | `ok` | built → `true false` | **сравнение вне списка D405**: 4294967295 «равно» −1 — классическая ловушка C, ради которой D405 и писали |
| `cmp_width` | `i64 < i32` | `ok` | built → `true` | сравнение разных ширин — молча |
| `int_float` | `i64 + f64` | `ok` | built → `6.5` | **неявная промоция int → float**; D405 говорит только о целых, D54 — «нигде» |
| `neg_unsigned` | `-a` при `a u8 = 200` | `ok` | built → `56` | **унарный минус на unsigned без правила**: заворот по модулю 256; Rust — ошибка компиляции |
| `float_width` | `f32 + f64`, `f32 < f64` | `ok` | built → `4 true` | **смешение ширин float** — D405 говорит только о целых; правила для float в спеке нет вовсе |
| `float_lit_ok` | `f64 + 1` (int-литерал к float), `ro x f32 = 1.5` (float-литерал в f32) | `ok` | built → `3.5 1.5` | принимается, но D55 п. 4 перечисляет только целые цели — литеральное правило для float **не записано** |
| `float_lit_neg` | `ro n int = 1.5` — КОНТРОЛЬ | `E7301` | — | держит: float-литерал в int отвергается |

D405 перечисляет операторы `+ - * / % >> << & | ^` и говорит «оба операнда — целые одной
ширины и знаковости». Четыре двери вне списка: операторы сравнения, целое с float, разные ширины float,
унарный минус. На всех трёх чекер молчит, Си собирает, программа печатает неверное без
диагностики. Форма та же, что у №904/№906: правило записано там, где о нём вспомнили
(арифметика), а не там, где через него всё проходит (любой бинарный/унарный оператор над числами).
