# Хвостовой `if let` — пробы к волне 274.7 §П (2026-09-20)

Четыре файла, которыми найден и ограничен дефект. Суффикс `.nv.txt` — требование
стража: пробы-улики не должны попадать в корпус как исходники.

| файл | что спрашивает | вердикт на бинаре 2026-09-20 06:40 |
|---|---|---|
| `a.nv.txt` | обычный `if` в хвосте тела | **принят** |
| `b.nv.txt` | `if let` в хвосте тела | **отвергнут**: «fn declares a return type but its body ends without a value» |
| `c.nv.txt` | тот же `if` в инициализаторе | принят |
| `d.nv.txt` | `if let` в хвосте + `main`, который его зовёт | материал для замера эмиссии |

Запуск:

```sh
./novac/target/novac.exe check docs/plans/repro/tail-if-let/b.nv.txt
```

## Что доказывает `d.nv.txt`, и почему без него правка была бы просчётом

`a` и `b` показывают РАЗНИЦУ, но не показывают, что делать. Соблазн — дописать
`IfLet` в список разрешённых хвостов (`check/tail_rules.nv`), одна строка.

`d` отвечает на вопрос, который этот соблазн пропускает: **умеет ли эмиттер
донести значение**. Пустив форму временно и посмотрев эмиссию, получаем

```c
if (_novac_l1.tag == NOVA_TAG_Option_Some) {
nova_int v = _novac_l1.value;
(void)(v);
} else {
(void)(((nova_int)0LL));
}
return (nova_int)0LL;
```

— значения обеих ветвей выброшены, возвращается жёсткий ноль. `g(Some(7))`
напечатал бы `0`. Проверка прошла бы, программа собралась бы, и число
диагностик упало бы на двенадцать: все признаки сделанной работы при тихом
просчёте.

**Условие было названо в самой двери** — «хвост даёт значение тогда и только
тогда, когда эмиттер пишет для него `return`». Проба есть способ задать этот
вопрос эмиттеру вместо того, чтобы вспоминать ответ.
