# Из оракула для Карины — минимальные формы закрытых классов

**Зачем.** Закрытый в оракуле класс может быть заново написан в `novac`, и узнаем мы
об этом от пользователя: дифференциал Карины ходит по `novac/fixtures/**/pos_*.nv` и по
`examples/`, а `spec_tests`, где живут улики закрытых строк реестра 221.1, он не видит
вовсе (проверено чтением стража 2026-09-07, followup
`[M-oracle-classes-replayed-in-carina]`).

**Почему здесь, а не в `novac/fixtures/`.** Положить их сразу к фикстурам значит
заставить чужой гейт судить их сегодня же — и покраснеть на формах, которых подмножество
Карины пока не поддерживает. Перенос делает окно 274, по одной форме, когда подмножество
её принимает. Пока форма не перенесена — она НЕ судится, и это сказано вслух, чтобы
пропуск не читался как успех (класс №989).

**Что в каждом файле.** Минимальная форма класса, ожидаемый вывод в первой строке и
ссылка на строку реестра. Формы намеренно крошечные: их задача — воспроизводить КЛАСС,
а не покрывать язык.

| файл | класс | строка реестра |
|---|---|---|
| `const_array_elem_width.nv` | ширина элемента константного массива берётся из литералов, а не из объявления | №1003 (и №998) |
| `or_pattern_binding_sets.nv` | альтернативы дизъюнкции вводят разные наборы биндеров; биндеры читаются по разметке первой | №1009 |
| `user_type_name_collides_with_std.nv` | имя C-структуры без квалификатора модуля: пользовательский тип перекрывается одноимённым из std | №756 |
| `user_type_name_collides_with_std.nv` | пользовательский тип, совпавший именем со стандартным, мапится на ту же C-структуру | №756 |

**Порядок партий (согласован с владельцем 2026-09-07):** сначала «тихо неверные данные»
(эта партия), затем «принял то, что обязан отвергнуть» (№959, №926, №1008), диагностики
последними — у Карины они свои.

**Почему №676 в партии НЕТ.** Он был в первоначальном списке, но проверка строки
показала, что это дефект САМОЙ Карины (`novac/src/emit_c/emit_c.nv:308`,
`novac/src/sem/sem.nv:394`, найден окном 274 в волне M2), а не класс оракула.
Передавать окну его собственный дефект — шум; в партию вместо него взят №756,
тоже из группы «тихо неверные данные», но с последствием ещё грубее: программа
не собирается вовсе, и ошибку выдаёт СИ-компилятор на пользовательский код.
Урок для остальных партий: перед переносом смотреть, ЧЕЙ это дефект, — список
классов составлялся по памяти, и одна из четырёх строк оказалась чужой.
