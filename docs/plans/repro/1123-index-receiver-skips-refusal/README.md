# Улика к строке реестра №1123 — отказ чекера не срабатывает, когда ресивер индексный

Снято интегратором 2026-09-16 бинарём `nova-cli/target/release/nova` из корня дерева.
Команда записана в `cmd.sh` рядом, и пробы **запускают**, а не читают — потому суффикс
у файлов голый `.nv` (правило №695 п. 2а), а не `.nv.txt`.

| проба | что делает | вердикт сегодня |
|---|---|---|
| `a-literal-index-accepts-retired` | `xs[0].len()` | собралось, печатает `3` |
| `b-var-index-answers-container` | `xs[i].len()` | собралось, печатает **`1`** |
| `c-binding-refuses-as-it-must` | `ro s = xs[0]; s.len()` | **отказ** `[E_STR_NO_LEN]` |
| `d-var-index-refuses-the-replacement` | `xs[i].byte_len()` | **отказ** `[E_RECV_METHOD_MISMATCH]` |

## Зачем четыре, а не одна

**Смысл — в ПАРЕ `a`+`b` против `c`.** Вызов один и тот же — `str.len()`, метод, СНЯТЫЙ
решением D249 («у `str` три расходящиеся длины, длина берётся через линзу представления:
`byte_len()` либо `chars().count()`»). Через промежуточный биндинг он отвергается, как и
обязан. Через индексное выражение — проходит. Значит на индексном пути отказ чекера не
запускается вовсе, и это не «какой тип выбран», а «суждение не спрошено».

Одна проба этого не показывает: `b` в одиночку читается как уже заведённый №676 (ресивером
стал контейнер), `c` в одиночку — как нормальная работа снятия метода. Разделяет их только
сопоставление.

**`d` — четвёртая, потому что закрывает отход.** Первый ответ на `b` звучит так:
«ну и что, `len` у `str` всё равно нет — напиши замену, которую называет сама диагностика».
Замена через переменный индекс **тоже не зовётся**: `[E_RECV_METHOD_MISMATCH]`. То есть
законного способа вызвать метод элемента по переменному индексу сегодня нет ни одного.

## Почему `1`, а не мусор

Вектор держит ОДИН элемент, строка `"abc"` — три байта. `3` (пробы `a`, и `e` из матрицы
замера) — длина строки; `1` — длина контейнера. Число `1` правдоподобно и потому опасно:
в программе, где контейнер длиннее одного элемента, оно выглядит как ответ.

## Родня

Строка №676 (`| 676 |` в реестре) — тот же путь ресивера, но про ВЫБОР ТИПА; её граница
«с литеральным индексом — верно» оказалась верной лишь наполовину, и строка поправлена тем
же слиянием. Класс «обязательство и разрешение раздаются по ФОРМЕ ЗАПИСИ, а не по типу» —
№667, №672, №673.
