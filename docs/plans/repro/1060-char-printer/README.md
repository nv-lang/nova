# Проба к реестру №1060 — `println('z')` без принтера char

## Находка

Заведено 2026-09-09 (окно 274), фикстурой `novac/fixtures/println_literals/
pos_1.nv` — единственная фикстура, которую этот класс держал: `char` был
намеренно исключён из неё с явным комментарием, объясняющим почему.
`novac check` принимал `println('z')` (носитель проходит чекер), а
`novac emit`/сборка падали `E_NOVAC_ICE`: «printer_of reached a primitive
family without a printer (char and unit)». Оракул печатает `z` (замерено
автором строки 2026-09-09, сборкой и запуском).

## Метод

`novac/src/emit_c/emit_expr.nv`'s `@printer_of(t)` — таблица «примитив →
имя рантайм-принтера», по одной записи на семейство (`PfFloat`, `PfInt`
отвечены; `PfStr`/`PfBool` отвечены РАНЬШЕ, двумя `if` по id, до входа в
`match`; `PfChar`/`PfUnit` падали в пустой рукав `{}` и упирались в `ice()`
после `match`). Рантайм-принтер для char УЖЕ существовал —
`nova_print_char(nova_int cp)` (`compiler-codegen/nova_rt/nova_rt.h:561`,
UTF-8-кодирующий codepoint) — просто не был подключён в таблице `printer_of`.

## Фикс

Один рукав: `PfChar => { return "nova_print_char" }`, снятый из пустого
списка `PfStr | PfBool | PfChar | PfUnit`. `PfUnit` остаётся неотвеченным
(это ДРУГАЯ строка реестра, №1057 — не расследовалась и не чинилась этим
заходом: оракул собственной сборкой `println(())`-подобной формы дал
ошибку компиляции C уже НА СТОРОНЕ ОРАКУЛА при первой же пробе, то есть
поведение оракула для unit неочевидно и не «измерено этим окном» — граница
названа честно, не расширена вслепую).

## Замер ДО фикса

Перепроверено ЖИВЬЁМ (не по цитате находки): временный откат
`emit_expr.nv` (`git checkout --`), пересборка, `novac.exe emit` на
`fn main() -> () { println('z') }` — `E_NOVAC_ICE`, тот же текст, что в
комментарии фикстуры.

## Замер ПОСЛЕ фикса

`git apply` тем же патчем обратно, пересборка: `novac.exe emit` даёт
полный, синтаксически валидный C без ICE; вызов —
`nova_print_char(((nova_char)122U));` (122 = codepoint `'z'`, верное
значение). `nova check novac/src` — PASS 16/FAIL 0 (без изменений).

## Фикстура-свидетель

`novac/fixtures/println_literals/pos_1.nv` дополнена строкой
`println('z')` — она и есть носитель, на котором класс был впервые
заведён; комментарий про "absent on purpose" заменён на историю фикса.
Полная компиляция+запуск+сверка байт-в-байт с оракулом идёт через
`scripts/tools/novac-diff-corpus.sh` (корпусный прогон, длинный, запущен
отдельно фоном при подготовке этого фикса).

## Оговорка

Приёмка этой строки — ТОЛЬКО char; unit (`PfUnit`) — предмет №1057,
отдельная, не расследованная этим заходом граница.
