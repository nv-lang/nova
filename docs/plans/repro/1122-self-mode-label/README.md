# Проба к реестру №1122 — режим самосборки не назван в выводе

## Находка

Найдено интегратором 2026-09-15. `scripts/tools/novac-diff-corpus.sh`
меряет расстояние до самосборки ДВУМЯ РАЗНЫМИ методами под одним и тем же
текстом вывода: батчем (`NOVAC_SELF_PATH=novac/src novac check <все
файлы>`, кросс-файловые импорты резолвятся) и, при крахе батча (ICE),
пофайловым откатом (`novac check <один файл>` в цикле — каждый файл
судится САМ ПО СЕБЕ, импорты НЕ резолвятся). Строка вывода
`самосборка: отвергнуто N из M` не говорит, каким методом получено `N` —
а числа отвечают на РАЗНЫЕ вопросы («сколько файлов реально не
компилируется» против «сколько файлов не являются самостоятельными
программами», что верно почти всегда для многофайлового проекта).

## Метод

Столкнулась с этим классом ЖИВЬЁМ в тот же вечер, до чтения строки: сама
перепутала пофайловое число (85) с батчевым, потратила ход на разбор
несуществующей "регрессии" (82→85), пока не прочитала код скрипта и не
прогнала батч напрямую (84). Строка реестра №1122 описывает РОВНО этот
класс на исходном замере интегратора (92 из 93 пофайлово при 6 из 93
батчем).

## Фикс

Приёмка строки — формой вывода, не починкой ICE (оговорка строки прямая):
1. Печатаемая строка называет режим: `самосборка (БАТЧ): ...` либо
   `самосборка (ПОФАЙЛОВЫЙ ОТКАТ -- ICE убил пачку, числа НЕ сравнимы с
   батчевым режимом, реестр №1122): ...`.
2. При откате печатаются ОБА числа: надёжное пофайловое (вердикт) и
   недостоверный частичный счёт краха (только для видимости, помечен
   явно "недостоверен").
3. Машинная строка `baseline-numbers:` получила новое поле
   `self-mode=batch|perfile-fallback` — читающий скрипт при желании может
   отличить режимы программно, не только по прозе.

## Замер ДО фикса

Откат `novac-diff-corpus.sh`, прогон селфтеста
`test-check-novac-differential-corpus.sh` — базовое поведение (без
метки режима) подтверждено, тот же класс расхождений, что описан в
строке реестра.

## Замер ПОСЛЕ фикса

`git apply` патчем обратно, прогон селфтеста — без регрессии
(результат идентичен базовому набору `ok`/`FAIL`, ни один новый FAIL
не появился). Прямой прогон `novac-diff-corpus.sh` на текущем дереве
(батч не крахует, ICE нет) даёт `самосборка (БАТЧ): отвергнуто 84 из
101` — режим назван явно.

## Оговорка

Строка сама говорит: фикс НЕ чинит сам ICE, который вызывает откат —
откат останется законным механизмом и сработает на следующем крахе;
приёмка — чтобы он тогда НЕ врал молча под именем батчевого числа.
