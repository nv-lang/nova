# Достижимость: десять кодов `E_*` без фикстуры, проба формой из места печати

**Заказ:** интегратор, 2026-09-20 (строка реестра 1187). «Кодов без фикстуры
217» — ВЕРХНЯЯ оценка долга: среди них есть недостижимые, и пока доля неизвестна,
приёмку строки не написать. Проба делит объявленные на живые и недоступные.
Вердикт — интегратора.

**Способ:** форма берётся ИЗ МЕСТА ПЕЧАТИ кода, а не из его имени. Угадывание по
имени в предыдущей пробе дало 0 из 4; здесь — 5 из 10 с первой попытки.

| код | форма-репро | получен | что пришло вместо | файл-эмиттер |
|---|---|---|---|---|
| `E_CONST_NOT_CONSTEXPR` | `const K = f()` (вызов функции в const) | **ДА** | — | `codegen/emit_c.rs` |
| `E_UNSAFE_REQUIRED` | `ro p = raw &x` вне `unsafe` | **ДА** | — | `types/mod.rs` |
| `E_SERDE_BAD_ATTRIBUTE` | `#serde` без аргументов над типом | **ДА** | — | `parser/mod.rs` |
| `E_BOUND_UNKNOWN` | `fn f[T NoSuchProtocolHere](x T)` | **ДА** | — | `types/mod.rs` |
| `E_BAD_FORMAT_SPEC` | `println("${x:-5}")` | **ДА** | — | `ast/format_spec.rs` |
| `E_CONST_FN_EVAL_PANIC` | `const fn cf(a int)`, вызов `cf(1, 2)` | нет | отказ есть, но БЕЗ кода | `const_fn_eval.rs` |
| `E_UNUSED_PREFIX_TYPEVAR` | `fn f[T]() -> int => 1` | нет | ЧИСТО, rc=0 | `types/mod.rs` |
| `E_UNSAFE_T_READ_REQUIRES_WRAP` | чтение поля через сырой указатель | нет | `E_UNSAFE_CALL_REQUIRES_WRAP` | `types/mod.rs` |
| `E_POINTER_PREFIX_MODIFIER` | `fn f(p mut *u8)` | нет | `E_PARAM_TYPE_POS_MUT_RETRACTED` | `parser/mod.rs` |
| `E_PRIMITIVE_MUT_METHOD` | `mut n = 1; n.push(2)` | нет | `E_UNKNOWN_METHOD` | `field_cache.rs` |

## Что эти числа значат и чего НЕ значат

**Пять достигнутых — подтверждённый долг:** код живой, фикстуры нет, репро в
одну-две строки лежит в таблице.

**Пять недостигнутых — НЕ «мёртвые».** Проба показывает, что МОЯ форма их не
вызвала, и не больше. Три из пяти дали СОСЕДНИЙ код — то есть путь перехватывает
другая проверка, которая срабатывает раньше:

| вместо | пришло | у пришедшего фикстур |
|---|---|---|
| `E_UNSAFE_T_READ_REQUIRES_WRAP` | `E_UNSAFE_CALL_REQUIRES_WRAP` | 5 |
| `E_POINTER_PREFIX_MODIFIER` | `E_PARAM_TYPE_POS_MUT_RETRACTED` | 4 |
| `E_PRIMITIVE_MUT_METHOD` | `E_UNKNOWN_METHOD` | 4 |

**Это отдельный класс, и он интереснее пустого «недостижим»:** код объявлен и не
закреплён, а форма, которая должна была его вызвать, перехватывается соседней
проверкой — у которой фикстуры ЕСТЬ. Такой код может быть и живым (на другой
форме), и затенённым насовсем. Различить может только тот, кто писал проверку.

**Два оставшихся:** `E_CONST_FN_EVAL_PANIC` дал отказ БЕЗ кода вообще (сообщение
без `[E_…]` — значит либо другая ветка, либо код печатается не всегда), а
`E_UNUSED_PREFIX_TYPEVAR` не дал ничего: неиспользованный параметр типа прошёл
ЧИСТО. Второе стоит проверить отдельно — либо форма другая, либо проверка не
работает.
