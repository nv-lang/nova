# Улика к строке реестра №799 (К1)

**Что здесь.** Два файла одной формы, различающиеся ОДНИМ именем переменной.
Их пара — не «репро», а **изоляция**: она называет триггер, а не симптом.

| файл | что делает | замер 2026-08-31 |
|---|---|---|
| [collide.nv](collide.nv) | имя захваченной переменной СОВПАДАЕТ с именем параметра вызываемой функции | **CC-FAIL** `use of undeclared identifier 'policy'` |
| [control_no_collision.nv](control_no_collision.nv) | та же форма, имена РАЗНЫЕ (`pol` / `p`) | **собирается, печатает `ok 3`** |

Команды целиком, из корня репозитория:

```sh
nova-cli/target/release/nova.exe build docs/plans/repro/p799/control_no_collision.nv -o /tmp/p799_ctl.exe
/tmp/p799_ctl.exe                       # -> ok 3

nova-cli/target/release/nova.exe build docs/plans/repro/p799/collide.nv -o /tmp/p799_col.exe
# -> error: use of undeclared identifier 'policy'
#      NovaValue_Pol __nova_arg_src0 = policy;
```

**Зачем контроль, а не только падающий файл.** Без него строка читается как
«вызовы с параметрами-умолчаниями ломаются внутри `spawn`» — это НЕВЕРНО и
отправило бы следующее окно разбирать обработку умолчаний вообще. Контроль
показывает, что та же самая форма с умолчанием, тем же `supervised { spawn }`
и тем же каналом собирается и работает, стоит развести имена. Триггер —
**коллизия имени**, и больше ничего.

**Почему файлы лежат здесь, а не в `spec_tests/`.** Падающий файл — CC-FAIL,
то есть он не компилируется; фикстурой корпуса он сделал бы корпус красным.
Место улик заведено решением по строке №695 (`docs/plans/repro/`).

**История этого каталога.** Строка №799 с 2026-08-29 ссылалась на файл
`p799_default_in_spawn.nv`, которого в дереве НЕ БЫЛО — проба жила только в
прозе. Она пересобрана 2026-08-31 по описанию из самой строки; первая
реконструкция **не воспроизвела** дефект, потому что я развёл имена, и это
несовпадение и подсказало, что коллизия — суть, а не деталь.

**Что делать дальше — адрес найден СГЕНЕРИРОВАННЫМ C, правка НЕ сделана.**
Тело `spawn` выносится в отдельную функцию `_nova_spawn_0` с контекстом `_c`, и
в этой структуре поля `policy` НЕТ вовсе (а `tx` — есть, и захвачен верно).
То есть переписывать обращение было НЕ ВО ЧТО: захват не собрался.

Адрес: `compiler-codegen/src/codegen/emit_c.rs:13861 fn emit_spawn` — набор
захватов строится ПЛОСКОЙ разностью множеств (около 13920):
`for name in refs { if bound.contains(&name) { continue } }`. В `bound` лежит
`policy`, потому что callnorm породил `let policy` внутри того же тела.

**Правильный обходчик В ЭТОМ ЖЕ ФАЙЛЕ УЖЕ ЕСТЬ** —
`collect_free_idents_in_block` (около 54360), лексически упорядоченный:
«Value expression evaluated in scope BEFORE binding x». На нашем блоке он
собрал бы `policy` как свободное имя. Сейчас он применяется к замыканиям,
но не к `spawn`.

Значит правка — НЕ переименователь по 57 вариантам `ExprKind` в callnorm,
а перевод `emit_spawn` на уже написанный упорядоченный обход. Риск назван:
затрагивает КАЖДЫЙ `spawn`, поэтому сдаётся только с полным корпусом
и пробой обеих сторон на этой же паре файлов.

**ПОПРАВКА ТОГО ЖЕ ДНЯ — абзац выше занижал цену правки.**
Собрать захват НЕДОСТАТОЧНО. Переписыватель обращений ТОЖЕ плоский: стоит
`policy` стать захватом, как ВСЕ его вхождения станут `_c->policy`, включая
то, что стоит ПОСЛЕ `let policy = ...` и обязано читать локаль. Это было
бы не исправление, а замена громкого CC-FAIL на тихо неверное значение.

Адреса выше верны и остаются уликой; неверным был вывод о ЦЕНЕ.
**Путь остаётся прежний — переименование в callnorm**, и теперь видно почему:
он обходит ОБА плоских механизма сразу, убирая коллизию, на которой
оба ломаются.

## ЗАКРЫТО 2026-08-31

Правка сделана в `compiler-codegen/src/callnorm.rs`: локали фазы 2 получают имена
`__nova_bind_<параметр>`, когда фаза 1 вообще что-то положила. Эти два файла
остаются здесь НЕ как архив, а как инструмент: проба обеих сторон снята
на них ОДНИМ деревом и ДВУМЯ бинарями.

| бинарь | `collide.nv` | `control_no_collision.nv` |
|---|---|---|
| контрольный (до правки) | CC-FAIL `undeclared identifier 'policy'` | собирается, `ok 3` |
| с правкой | собирается, `ok 3` | собирается, `ok 3` |

То есть выключатель красит РОВНО то, что чинил, и не трогает соседа.
Класс удерживается фикстурой `spec_tests/conformance/standalone/m799_name_collision_in_spawn.nv`,
показанной красной на контрольном бинаре ДО правки.
