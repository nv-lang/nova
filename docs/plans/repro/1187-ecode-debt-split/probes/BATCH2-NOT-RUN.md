# Партия 2: пробы прогнаны — итог в `batch2-results.txt`

Этот файл заводился, когда пробы были только заготовлены (машина держалась
ярусом интегратора). Машина освободилась в 01:34, все шесть проб прогнаны в
той же сессии. **Полный итог, включая замену форм, которые не дошли с первой
попытки, — в `../batch2-results.txt`; здесь оставлена только адресная сводка.**

`E_ADDR_OF_REMOVED`), 1 недостижим доказательством из двух независимых
источников (`E_AUTO_DERIVE_UNKNOWN_PROTOCOL`), 2 честно оставлены
неразобранными в этой волне (`E_CONST_FN_CLOSURE_BODY`,
`E_CONST_FN_CLOSURE_ARITY` — условие входа найдено чтением, форма, проходящая
внешний гейт и падающая на внутреннем, не построена).
