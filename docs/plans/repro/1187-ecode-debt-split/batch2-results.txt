    Форма `#impl(Equal) external type RawHandle` поднимает `E_AUTO_DERIVE_UNSUPPORTED_KIND`.

    ОГОВОРКА ПРО НОСИТЕЛЯ, обязательная: та же форма поднимает ЕЩЁ ДВА кода --

    ещё принимает ради собственной диагностики (комментарий парсера:
    "let parse proceed; types/mod.rs emits E_EXTERNAL_TYPE_RETRACTED").
    ОТКРЫТЫЙ ВОПРОС, не закрытый в этой волне: существует ли ТЕКУЩИЙ

# 1187, партия 2, ПЯТАЯ ВОЛНА (02:23) -- два последних кода, оба НЕДОСТИЖИМЫ

E_CONST_FN_CLOSURE_EXTERNAL
  Условие живёт в `extract_closure_parts_from_expr` (`const_fn_closure.rs:626`):
  `ClosureFull` с телом `FnBody::External`. Чтение ЕДИНСТВЕННОГО места, где
  `ExprKind::ClosureFull` вообще строится (`parser/mod.rs:10303-10312`), нашло
  явную гарантию САМОГО ПАРСЕРА:

      FnBody::External => unreachable!(
          "closure-full cannot be `external` -- only named fns can; ..."
      ),

  То есть парсер физически не может произвести `ClosureFull` с телом
  `External` -- тело замыкания читается через `parse_fn_body`, и ветка
  `External` там зарезервирована только для ИМЕНОВАННЫХ функций верхнего
  уровня. Условие для `E_CONST_FN_CLOSURE_EXTERNAL` требует того, что
  конструктор AST сам объявляет невозможным -- `unreachable!()`, а не догадка.

E_BLOCKING_FN_DECL_MISSING
  Условие: `self.mono_fn_decls.get(fn_name).ok_or_else(...)` в
  `emit_blocking_fn_call` (`codegen/emit_c.rs:16223`). Решающая деталь --
  СИГНАТУРА функции: `Result<String, String>`, а не `Result<_, Diagnostic>`,
  которым размечен весь путь типизации. Это код ЭМИССИИ C, вызываемый ПОСЛЕ
  того, как чекер уже подтвердил существование и типы функции; `#blocking fn`
  без предварительной регистрации в `mono_fn_decls` означало бы, что
  типизация прошла для функции, которой эмиттер не знает, -- расхождение
  между двумя фазами компилятора, а не форма, которую пишет пользователь.
  Косвенное подтверждение: рабочая фикстура `#blocking fn` в корпусе
  (`spec_tests/conformance/d172_realtime_blocking_attrs.nv`) компилируется
  без этого кода -- обычный путь его не задевает.
