# Формы плеча `match`, на которых останавливается парсер — сколько ФАЙЛОВ открывает каждая

**Заказ:** окно Карины, 2026-09-20, чтобы идти по убыванию, а не по вкусу.
Вердикт «что брать первым» — её; здесь замер и его границы.

## ГРАНИЦА ПЕРВОЙ СТРОКОЙ — она важнее чисел

Замер снят бинарём, собранным из дерева на коммите **`5fb1ae723`**, а правка
квалифицированных плеч (`K.A => 1`) в тот момент лежала В РАБОЧЕЙ КОПИИ и не
была закоммичена. То есть **это состояние ДО фикса**, и две строки в разделе
«прочее» (`DiagKind.LangError =>`, `ElseShape.NoElse =>`) сегодня уже
принимаются. Без этой оговорки список читается как нынешнее состояние — и врёт.

Урок, купленный здесь: «собери свежий бинарь» — не команда, пока не назван
КОММИТ, на котором мерить. Свежесть меряется коммитом, а не временем сборки.

## Вторая оговорка: замер даёт МЕСТО, а не обязательно ФОРМУ

Классифицируется строка, НА КОТОРУЮ УКАЗЫВАЕТ смещение первого отказа. Три
строки в списке — комментарии (`///`, `//`), а диагностика не может указывать на
комментарий. Значит либо спан указывает на начало конструкции (и тогда искомая
форма НИЖЕ строки), либо привязка смещения к строке сдвинута. Пока это не
проверено глазом, «первый отказ файла» следует читать как АДРЕС, а не как форму.

## Способ, и почему не греп

Греп считает, сколько раз форма НАПИСАНА, а нужно — сколько файлов она
ОТКРЫВАЕТ: у файла один первый отказ, остальное каскад. Поэтому помодульный
прогон с `NOVAC_UNIT=1`, первый отказ вида «did not parse this» в каждом файле,
классификация строки по смещению. Основа — `../peers-one-unit/first_fallback.py`
(скрипт окна Карины), добавлены классификация и счётчик неразобранного.
