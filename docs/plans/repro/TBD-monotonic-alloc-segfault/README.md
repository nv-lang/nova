# Недетерминированный сегфолт: `Monotonic.now()` + тяжёлые аллокации

Пробы к строке реестра `№TBD` (221.1). Заведено окном `p200-23` 2026-09-15 по пути,
при замере цены лени для плана 200 §23 — **не искалось, попалось**.

## Что наблюдается

Программа, которая (а) зовёт `Monotonic.now()` и (б) в цикле строит много
короткоживущих объектов, падает с `Segmentation fault` (exit 139) **не каждый
прогон**. Тот же бинарь, тот же ввод, без аргументов: часть прогонов печатает
верный результат, часть падает.

## Замер (окно p200-23, 2026-09-15, clang, `--mode release`)

| проба | что внутри | 6 прогонов подряд |
|---|---|---|
| `mine_asciiws.nv` | `Monotonic` + 3 блока по 50 итераций, `split_ascii_whitespace` | **1 падение из 6** |
| `control_splititer.nv` | то же, но `split(" ")` — `SplitIter`, код НЕ трогался планом 200 §23 | **2 падения из 6** |
| `noclock_take2.nv` | 2000 итераций `.take(2).collect()`, **без часов** | 0 из 6 |
| `noclock_collect_all.nv` | 2000 итераций `.collect()` (≈4 млн строк), **без часов** | 0 из 6 |

Команды (из корня дерева, бинарь свой):

```sh
./nova-cli/target/release/nova build docs/plans/repro/TBD-monotonic-alloc-segfault/mine_asciiws.nv --mode release
for r in 1 2 3 4 5 6; do ./mine_asciiws.exe >/dev/null 2>&1; echo -n "run$r=$? "; done; echo
```

## Что этот замер доказывает, а что нет

**Доказывает две вещи.**

1. **Дефект НЕ принадлежит плану 200 §23.** Контроль на `SplitIter` — типе, который
   эта работа не трогала, — падает не реже нового `AsciiWhitespaceIter` (2 из 6
   против 1 из 6). Проба и контроль отличаются РОВНО одним: каким сплиттером режется
   строка.
2. **Ось — часы, а не нагрузка.** Двенадцать прогонов из двенадцати без
   `Monotonic.now()` чистые, при вчетверо большем числе итераций и в тысячу раз
   большем числе построенных строк, чем в падающих пробах. То есть «программа много
   аллоцирует» само по себе не воспроизводит.

**НЕ доказывает** — и это названо честно, потому что дальше копало бы чужое окно:
что именно в связке ломается. `Monotonic.now()` идёт через эффект `Time` и рантайм;
разделить «часы», «эффект `Time`» и «планировщик/GC под ними» тремя отдельными
пробами я не успел — это первый шаг того, кто возьмётся. Частота (1–2 из 6) означает,
что любой вердикт по ОДНОМУ прогону здесь ничего не стоит: и зелёный, и красный
воспроизводятся на одном бинаре.

## Почему пробы лежат в дереве

Отчёт без файла и команды не принимается: без проб строку реестра нельзя ни
воспроизвести, ни опровергнуть. Каталог назван `TBD-…` — номер выдаёт интегратор,
и каталог переименовывается вместе с присвоением номера.
