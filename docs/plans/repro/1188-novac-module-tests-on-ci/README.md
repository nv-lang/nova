# №1188 — приёмка замером: модульные тесты novac на CI

**Заказ:** интегратор, 2026-09-20. Строка требует не «починить отказы», а
ЗЕЛЁНЫЙ шаг конвенций на CI И видимый результат шага `novac module tests` с
НЕНУЛЕВЫМ числом тестов. Вторая половина не проверена никем и проверяема только
замером. Вердикт — интегратора; здесь три замера и их границы.

## 1. Сколько тестов существует — из дерева

```
find novac/src -name '*_test.nv'            → 26
ls novac/src/*/*_test.nv   (глоб шага CI)   → 26
ls novac/src/*_test.nv     (верхний уровень) → 0
find novac/src -mindepth 3 -name '*_test.nv' → 0
```

Сегодня глоб шага видит ВСЕ 26. **Но он фиксирован по глубине** (`*/`): тест,
положенный уровнем выше или ниже, в прогон не попадёт и никто об этом не узнает.
Сейчас таких нет — названо как скрытая мель, а не как дефект.

## 2. Что печатает шаг локально

Локальный страж `check-novac-module-tests.sh` (ОДИН пачечный вызов):

```
check-novac-module-tests ok: модульных тестов novac: файлов 26, PASS 26, SKIP 0, FAIL 0
```

Знаменатель виден: файлов 26 и PASS 26 — счёт сошёлся. Шаг CI устроен иначе: он
зовёт `nova test` ПО ОДНОМУ файлу в цикле и **числа файлов не печатает вовсе**.

## 3. СЕРДЦЕВИНА: «зелёный, прогнал 0» НЕОТЛИЧИМ от «зелёный, прогнал N»

Тело шага скопировано дословно из `.github/workflows/nova-gate.yml` и запущено
на дереве, где тестов нет (`ci-step-zero-tests.sh`):

```
ИТОГ шага при НУЛЕ тестов: rc=0
```

Вывод шага при этом ПУСТ: ни одной строки `== <файл>`, потому что цикл не
исполняется ни разу (`for t in …; do [ -e "$t" ] || continue`). То есть при нуле
тестов шаг зелен и молчалив, и по логу это неотличимо от успешного прогона.

**Следствие для приёмки 1188:** починка конвенций даст зелёный CI и ту же пустую
мишень, только теперь с видом доказательства. Приёмка обязана требовать
НЕНУЛЕВОЕ ЧИСЛО в выводе шага, а не его зелёный код возврата.

Для сравнения: локальный страж на нуле тестов ОТКАЗЫВАЕТ явно —
`FAIL — ни одного *_test.nv в novac/src`. То есть строже, чем CI.

## 4. Почему тесты не идут сегодня — измерено, а не предположено

`gh run view` по четырём последним прогонам `nova-gate`:

| прогон | шаг `novac conventions gate` | `Build novac` | `novac module tests` |
|---|---|---|---|
| 35484934414 (02:48) | **failure** | skipped | **skipped** |
| 35481737087 (01:34) | **failure** | skipped | skipped |
| 35429374900 (19-го) | **failure** | skipped | skipped |
| 35410639757 (19-го) | **failure** | skipped | skipped |

Шаг не сломан — он НЕ ДОСТИГАЕТСЯ: предыдущий шаг (`scripts/gate-novac.sh`)
падает, и всё, что за ним, пропускается. Строка права дословно: тесты не
запускались ни разу.

## Границы

* «ни разу» проверено по ЧЕТЫРЁМ последним прогонам, а не по всей истории;
* локальный прогон делался бинарём `novac/target/novac.exe` этого дерева;
  сборка на CI своя, и совпадение вердиктов не гарантировано;
* почему падает шаг конвенций — не выяснялось: это предмет соседней работы.

```sh
sh docs/plans/repro/1188-novac-module-tests-on-ci/ci-step-zero-tests.sh
sh scripts/guards/check-novac-module-tests.sh .
```

`nova-gate` — `35497981793`, начат 2026-09-20T07:51:14Z, и он судит коммит

ответ нельзя. Это ровно то предупреждение, которое интегратор сделал сам.

**Границы замера, названные явно:**

  строк `NOVAC-GATE FAIL:`; числа РАЗНЫЕ намеренно, один страж может дать
  несколько вердиктов, и складывать их нельзя.
