# План 175.2 — Эффекты «без магии»: typed ops + общий codegen + #default_handler + ретракция ambient

**Статус:** 🔨 В РАБОТЕ (2026-07-21, волна в полёте — sonnet, worktree `nova-typedfx`,
ветка `p175-typed-effects`). **Приоритет:** А-класс релиза v0.1 (блокер тегов) —
атом [221 A-B9](221-release-v0-1.md); триаж — [221.1 Ф.2б](221.1-bug-sweep.md).
**Родитель:** [175](175-time-system-rework.md) (заменяет SUPERSEDED Ф.2 «typed-effect-ops»
после 4 откатов — архитектура пересмотрена владельцем 2026-07-21).
**Корневой маркер:** `[M-effect-handler-body-record-literal]` (backlog-followups.md).

## Мотивация (решения владельца, 2026-07-21)

1. «Эффекты не должны быть калькой C-интерфейса — опы должны быть высокоуровневыми».
2. «Handler-тела и обычные функции должны идти ОДНИМ путём — как протоколы; спец-кодегена
   тел не существует в Rust» (замена особого эмиттера, НЕ дотягивание паритета).
3. «Time не должен иметь сверхъестественного положения»: (а) дефолт конструируется до main
   C-хардкодом без языкового механизма → нужен атрибут-конструктор, автоматически (при
   использовании) до main; (б) ambient-невидимость в сигнатурах — «дыра в строгости,
   давай без магии» → ретракция.
4. API эффектов зафиксировать ДО тегов v0.1 (breaking после релиза недопустим).

## Скоуп (одно окно, ветка `p175-typed-effects`)

| # | Часть | Суть |
|---|---|---|
| 1 | **Handler-тела → общий путь** | Снос особого эмиттера `emit_handler_lit`: тело каждого опа handler-литерала опускается в обычную fn (общий fn-путь, полный паритет выражений автоматически); vtable эффекта собирается из указателей — протокол-машинерия как образец. | 2 | **Перенос Time** | Декларация `type Time effect` из прелюдии → `std.time` (user-эффекты вне прелюдии уже работают); прелюдия реэкспортирует сахар; единый источник схемы (R1) сохраняется |

| 5 | **Ретракция ambient (D62)** | Time в сигнатурах как все эффекты; strict-effects энфорсит; миграция std/examples/фикстур механически по диагностикам |
| 6' | **СНОС рукописного `NovaVtable_Time` из C** (директива владельца 2026-07-22: «зачем так? хардкод, противоречие §3, убрать — только extern fn») | `NovaVtable_Time`-struct + default-handler в `nova_rt/effects.h`/`fibers.h` — рукописный C, инклюдится ДО генерируемых value-typedef → корень scalar-bridge-клина (Duration не объявить перед vtable). Тогда часть 3 (typedef перед vtable — идея владельца) тривиальна |
| 6 | **Дехардкод built-in vtable** | `BUILTIN_VTABLE_NAMES: &["Fail","Time","Mem","TimerMetrics"]` (emit_c.rs:6062) — хардкод-список C-встроенных vtable в Rust, противоречит §3 (max из .nv). Time уходит сам (часть 4). Остаток (Fail/Mem/TimerMetrics) — вывести «встроенность» из атрибута в prelude .nv (`#builtin_vtable`/`#default_handler`-семья), не имён-списка в Rust |

**Спека (та же ветка):** новый D-блок `#default_handler` + амендменты D62 (ретракция
ambient) и D316-семьи (типизированная схема, перенос, судьба `_ms`-имён);
`nv-coding-style` п.31 — провод-слой сужается до FFI-границы.

## Ф.2-v4 — эффект-API-полировка (находки владельца вычиткой кода 2026-07-22, ДО тегов)

Эффект-рефактор (v3) сделал систему без магии, но вычитка вскрыла ряд стилевых/
инкапсуляционных недоделок в эффект-поверхности. Все — язык-меняющие, ДО тегов
(v0.1 API не переигрывать потом).

**Готово (ветка `p-fx-polish`, не влита — гейт a_q3-флаки):**
1. ✅ extern `_nova_wall_unix_ms`→`time_wall_unix_ms` и т.д. (доменный префикс, конвенция
   `fs_*`; синхронно .nv + nova_rt C).
2. ✅ `sleep(d Duration)` — тип параметра в handler-опе.
3. ✅ вынос test-блоков из продакшн-модулей (`core.nv` 33→`core_test.nv`, +fmt_buf/property).

**Осталось (новая согласованная волна, всё до тегов):**
4. **handler-опы — полная декларация обязательна.** Сейчас `now() => ...` без `-> Timestamp`
   (неполная декларация — единственное место в языке; везде `fn`/`#impl` полные). Сделать
   неполную декларацию handler-опа ОШИБКОЙ компиляции (E_*); мигрировать ~78 handler-литералов
   на `now() -> Timestamp => ...`. D-амендмент.
5. **`priv nanos`** на `Monotonic`/`Timestamp`/`Duration` (сейчас `ro` = публично конструируемо
   `{nanos:}` извне → можно слепить невалидный Monotonic). Инкапсуляция (D220 per-field).
6. **Перенос `type Time effect` + default-handler → folder-модуль `time.duration`** (co-equal
   с `monotonic.nv`). Даёт handler'у module-private доступ к `priv nanos` (07-modules §393:
   module-private видно из всех файлов модуля; Vec-образец core/iter) → конструирует
   `Monotonic`/`Timestamp` внутренне БЕЗ публичного `from_ns`. Возможно т.к. ambient
   ретрактирован (v3) — prelude-размещение ради ambient-доступности больше не нужно.
7. **`#default_handler` без аргумента** — эффект выводится из `-> Effect[X]` (сейчас парсер
   требует `(EffectName)` — избыточно, DRY). Парсер-правка.
8. **Нейминг `time_default` → `real_time()`** — симметрия с `real_fs()`/`mock_fs()`/`mock_io()`
   (описательное имя handler-конструктора, не `_default`-суффикс).

**Список открыт** — владелец продолжает вычитку эффект-поверхности; финальный полный набор
запускается ОДНОЙ волной (дешевле, чем итерации с полным мега-CU-гейтом каждая).
