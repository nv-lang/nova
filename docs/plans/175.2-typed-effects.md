# План 175.2 — Эффекты «без магии»: typed ops + общий codegen + #default_handler + ретракция ambient

**Статус:** 🔨 В РАБОТЕ (2026-07-21, волна в полёте — sonnet, worktree `nova-typedfx`,
ветка `p175-typed-effects`). **Приоритет:** А-класс релиза v0.1 (блокер тегов) —
атом [221 A-B9](221-release-v0-1.md); триаж — [221.1 Ф.2б](221.1-bug-sweep.md).
**Родитель:** [175](175-time-system-rework.md) (заменяет SUPERSEDED Ф.2 «typed-effect-ops»
после 4 откатов — архитектура пересмотрена владельцем 2026-07-21).
**Корневой маркер:** `[M-effect-handler-body-record-literal]` (backlog-followups.md).

## Мотивация (решения владельца, 2026-07-21)

1. «Эффекты не должны быть калькой C-интерфейса — опы должны быть высокоуровневыми».
2. «Handler-тела и обычные функции должны идти ОДНИМ путём — как протоколы; спец-кодегена
   тел не существует в Rust» (замена особого эмиттера, НЕ дотягивание паритета).
3. «Time не должен иметь сверхъестественного положения»: (а) дефолт конструируется до main
   C-хардкодом без языкового механизма → нужен атрибут-конструктор, автоматически (при
   использовании) до main; (б) ambient-невидимость в сигнатурах — «дыра в строгости,
   давай без магии» → ретракция.
4. API эффектов зафиксировать ДО тегов v0.1 (breaking после релиза недопустим).

## Скоуп (одно окно, ветка `p175-typed-effects`)

| # | Часть | Суть |
|---|---|---|
| 1 | **Handler-тела → общий путь** | Снос особого эмиттера `emit_handler_lit`: тело каждого опа handler-литерала опускается в обычную fn (общий fn-путь, полный паритет выражений автоматически); vtable эффекта собирается из указателей — протокол-машинерия как образец. Закрывает `[M-effect-handler-body-record-literal]` |
| 2 | **Перенос Time** | Декларация `type Time effect` из прелюдии → `std.time` (user-эффекты вне прелюдии уже работают); прелюдия реэкспортирует сахар; единый источник схемы (R1) сохраняется |
| 3 | **Типизация опов** | `sleep(Duration)`, `now() -> Timestamp`, `now_monotonic() -> Monotonic` — голые имена, единица в ТИПЕ; int-провод `_ms`/`_ns` остаётся только на FFI-границе внутри реализаций; моки fixed/mut_clock — на типизированные сигнатуры |
| 4 | **`#default_handler`** | Атрибут на fn `-> X` рядом с эффектом; транзитивное использование X без `with` → авто-конструирование до main (лениво, DCE-дружелюбно); `with` переопределяет; топо-порядок, цикл = ошибка; C-хардкод Time-дефолта сносится (.nv-дефолт зовёт сырые FFI) |
| 5 | **Ретракция ambient (D62)** | Time в сигнатурах как все эффекты; strict-effects энфорсит; миграция std/examples/фикстур механически по диагностикам |
| 6' | **СНОС рукописного `NovaVtable_Time` из C** (директива владельца 2026-07-22: «зачем так? хардкод, противоречие §3, убрать — только extern fn») | `NovaVtable_Time`-struct + default-handler в `nova_rt/effects.h`/`fibers.h` — рукописный C, инклюдится ДО генерируемых value-typedef → корень scalar-bridge-клина (Duration не объявить перед vtable). Снести: Time-vtable ГЕНЕРИРУЕТСЯ как обычный эффект (часть 1 ✅ открыла дорогу), в C остаются ТОЛЬКО extern-примитивы (`_nova_wall_unix_ms`/`_nova_monotonic_ns`/context-sensitive sleep). Тогда часть 3 (typedef перед vtable — идея владельца) тривиальна |
| 6 | **Дехардкод built-in vtable** | `BUILTIN_VTABLE_NAMES: &["Fail","Time","Mem","TimerMetrics"]` (emit_c.rs:6062) — хардкод-список C-встроенных vtable в Rust, противоречит §3 (max из .nv). Time уходит сам (часть 4). Остаток (Fail/Mem/TimerMetrics) — вывести «встроенность» из атрибута в prelude .nv (`#builtin_vtable`/`#default_handler`-семья), не имён-списка в Rust |

**Спека (та же ветка):** новый D-блок `#default_handler` + амендменты D62 (ретракция
ambient) и D316-семьи (типизированная схема, перенос, судьба `_ms`-имён);
`nv-coding-style` п.31 — провод-слой сужается до FFI-границы.
