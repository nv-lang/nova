## 0. Суть (простыми словами)

Две независимые правки одной зоны (D78, resolver/manifest):

1. **Ключ реестра модулей = канонический путь, не декларация.** Сегодня
   роутинг импортов путевой, но найденные модули складываются в реестр по
   строке `module parent.target` — два модуля с совпавшей (принудительно
   продиктованной путём!) декларацией → второй **тихо глотается**
   («undefined identifier» с якорем на module-decl, без диагностики).
   Репро: research §2а. После фикса декларация остаётся чексуммой
   (`E_D78_MODULE_PATH_MISMATCH`) + битом членства (peer vs независимый),
   дубли деклараций из разных путей становятся легальными и безвредными.
2. **Корневой модуль пакета («root peers», аналог lib.rs).** `.nv`-файлы
   прямо в source root = co-equal peers ОДНОГО модуля с именем пакета
   (декларация `module <package>`). Убирает системный статтер `tls.tls`
   (`import tls.{TlsStream}` вместо `import tls.tls.{...}`); подпапки
   остаются под-модулями как сейчас.

### 0.1 Пример «до/после» для root peers (объяснение из сессии 2026-07-13)

**Сегодня — файлы прямо в `src/` положить нельзя** (в смысле «одним модулем»):
каждый файл там — сам себе модуль (`src/client.nv` → модуль `tls.client`,
`src/stream.nv` → `tls.stream`). Они не видят приватное друг друга — пакет
рассыпается на десяток мини-модулей с экспортами/импортами между собой.
Единственный способ сделать «один модуль из многих файлов» — папка →
отсюда и вынужденное `src/tls/` → `tls.tls`.

**После правки «root peers»:** файлы прямо в `src/` = равноправные части
одного модуля с именем пакета. nova-tls станет:

```
nova-tls/
  nova.toml        (name = "tls")
  src/
    client.nv      — все пишут `module tls`
    server.nv
    stream.nv
    config.nv
    ...
```

— и у потребителя `import tls.{TlsStream}`. Ровно как `lib.rs` у Rust.
Папки под `src/` остаются для под-модулей, когда они реально нужны
(`src/x509/` → `tls.x509`).

Это форма 2 статтер-фикса; форма 1 (схлопывание `src/tls/` → `tls`) при
ней почти не нужна — **берём только «root peers» как единственное
правило**, ещё проще.
