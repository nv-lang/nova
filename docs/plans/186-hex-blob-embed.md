# План 186 — hex-блоб литерал `x"…"` и интринсик `embed("path")` (D412)

**Статус: ОЧЕРЕДЬ** (после текущей очереди 172.12-A8 / 174.5).
**Спека: D412** (spec/decisions/03-syntax.md, принято владельцем 2026-07-07).
**Маркер: [M-hex-blob-embed-d412]** (docs/plans/backlog-followups.md).
**Волна: [sonnet]** по этой карте.

## Объём

1. **Лексер `x"…"`** — hex-цифры + разделители `_`/пробел/перенос строки; диагностики
   E_HEX_BLOB_ODD (нечётное число цифр), E_HEX_BLOB_CHAR (не-hex символ); пустой
   `x""` легален. Результат — компайл-тайм байтовый блоб, тип `[]u8`.
2. **Интринсик `embed("path")`** — аргумент только строковый литерал; путь
   относительно .nv-файла с вызовом; выход выше корня проекта — ошибка;
   E_EMBED_NOT_FOUND; встроенный файл участвует в fingerprint пересборки.
3. **Эмиссия**: `static const uint8_t nova_blob_<n>[] = {…}` (интернирование по
   содержимому, как interned_str_literals); материализация:
   - ro-биндинг → нулевая копия: `[]u8`-вид `data → статика, len == cap == N`;
   - mut-биндинг / consume в мутацию → копия в GC-кучу в точке биндинга.
4. **Тесты**: pos — ro-вид (чтение/срезы/итерация), mut-копия (push после),
   пустой `x""`, группировки разделителями, embed round-trip (байты == файлу),
   интернирование (один блоб на два одинаковых литерала); neg — нечёт, не-hex,
   отсутствующий файл, не-литеральный аргумент embed.

5. **Миграция-свип по готовности синтаксиса** (директива владельца 2026-07-08):
   заменить явные байтовые литералы-простыни на `x"…"` — греп по std на
   многострочные `[0, 0, …]`-заполнители и hex-массивы; известный сайт:
   sha256.nv (32-нулевой литерал, обход `[0; 32]`-парсер-гэпа
   [M-sha256-array-repeat-literal-parser]). Для чистых нулей допустим и канон
   `[]u8.new().resize(n, 0 as u8)` — выбирать по месту (стек-массив `[N]u8` ↔
   `x"…"`, динамика ↔ resize).
