# План 296 — Сводная спецификация языка (два слоя, два языка)

**Статус:** принят владельцем 2026-11-28 (решения: делать; два языка ru+en; страж синхронности;
тексты по конвенции технического письма). Исполнение — после hotfix-волны 0.1.9, отдельным окном.

## 1. Цель

Дайте читателю действующую норму языка одним текстом. Сегодня норма одной возможности
разбросана по цепочке D-блоков в `spec/decisions/` (73 348 строк, ~500 блоков): базовый блок,
поправки и редакции лежат в разных файлах и датах. Читатель собирает норму вручную и ошибается:
текст отказа Карины ссылался на D441 вместо D75 (реестр 221.1 №2043) — авторы кода не нашли
действующую редакцию.

## 2. Решение: два слоя

1. `spec/decisions/` остаётся журналом решений. Файлы только дополняются. Нумерация D
   неизменна: на неё ссылаются код, реестр и планы.
2. `spec/current/` — сводная норма. Главы организованы по областям языка: лексика, типы,
   выражения, операторы, эффекты, конкурентность, модули, семантика рантайма. Каждая глава
   излагает только действующую редакцию нормы. Каждое правило ссылается на свои D-блоки.

Не переносите и не переименовывайте существующие D-файлы. Сводный слой даёт читаемость
без разрыва ссылок.

## 3. Два языка

Каждая глава существует в двух файлах: `<область>.ru.md` и `<область>.en.md`. Оба текста
нормативны и равны. Русский текст пишите по конвенции
[technical-writing.md](https://github.com/unitcraft/engineering-conventions/blob/main/technical-writing.md)
(ASD-STE100 для русского): одно предложение — одна мысль, условие перед правилом, прямое
обращение, термины из глоссария. Английский текст пишите по тем же принципам. Термины языка
(`supervised`, `consume`, `spawn`) не переводите.

## 4. Стражи

1. **Синхронность языков** (`check-spec-current-sync`): правка главы на одном языке без правки
   той же главы на втором в том же коммите — отказ. Способ проверки: страж сравнивает набор
   изменённых глав обоих языков в диапазоне коммита.
2. **Провенанс** (`check-spec-current-provenance`): каждая ссылка на D-блок указывает на
   существующий блок; блок не помечен superseded без записи в главе. Формат ссылки фиксируйте
   в шапке главы.
3. **Свежесть** (по образцу `check-novac-plan-liveline`): глава старше последнего D-блока своей
   области более чем на N дней — отказ. N задаётся при внедрении (предложение: 14).
4. **Индекс по фичам** (`spec/decisions/INDEX-by-feature.md`): генерируется из полей
   `feature:` и `revised-by:` заголовков D-блоков. Страж проверяет, что индекс пересобран
   и ссылки двусторонни.

## 5. Дисциплина изменений

Изменение нормы — один коммит, который содержит: новый или изменённый D-блок, правку главы
`spec/current/` на обоих языках, пересобранный индекс. Требование вносится в AGENTS.md тем же
слиянием, что и первый страж.

## 6. Пилот

Первая глава — конкурентность (`spec/current/concurrency.ru.md` + `.en.md`). Основание:
домен дал носитель путаницы (D75 REVISED + D408 + D415 + D442), он компактнее types и syntax.
Пилот даёт замер трудоёмкости на домен (оценка: 2–4 сессии) до раскатки на остальные области.

## 7. Порядок работ

1. Инфраструктура: формат заголовков D-блоков, генератор индекса, четыре стража, самотесты.
2. Пилот: глава конкурентности на двух языках, ревью владельцем.
3. Раскатка по областям в порядке боли: эффекты, типы, синтаксис, модули, рантайм.
4. После покрытия всех областей: обзоры верхнего уровня (`spec/syntax.md`, `effects.md`)
   заменяются ссылками на `spec/current/` — отдельным решением владельца.

## 8. Критерии приёмки пилота

- [ ] Глава конкурентности излагает действующую норму без противоречий с D-блоками (проверка:
      страж провенанса зелёный, выборочная сверка владельцем).
- [ ] Оба языковых текста синхронны (страж синхронности зелёный, выборочная сверка смысла).
- [ ] Текст отказа Карины про `cancel:` после правки ссылается на главу сводной нормы (носитель
      №2043 закрыт по существу, не только по тексту).
- [ ] Замер трудоёмкости записан в план; решение о раскатке принято владельцем.

## 9. Чего план не делает

- Не переносит и не дробит файлы `spec/decisions/`.
- Не меняет процесс присвоения номеров D (номера выдаёт интегратор).
- Не переводит исторические обзоры и `history/rejected.md`.
