## 1. Скоуп

- Английская сторона (`docs/guide/X.md`) каждого файла из таблицы пишется
  по-английски целиком: проза, заголовки, подписи таблиц, текст врезок.
- Русская сторона (`X.ru.md`) остаётся русской; если при работе выясняется, что
  ru-файл был зеркалом (то есть по-русски уже всё) — правки не требует.
- Код-блоки: байт-в-байт идентичны между сторонами (правило #translation-drift).
  Комментарии внутри примеров — по-английски (оригинал английский); менять их
  можно ТОЛЬКО одновременно в обеих сторонах.
- Терминология — `spec/GLOSSARY.en.md` (журнал решений владельца в конце файла).

## 2. Не-скоуп

- Содержательная переработка гайдов (структура, новые разделы) — только если
  текст описывает несуществующее; такие места — находкой в отчёт, не переписывать.
- `spec/*.en.md` — уже настоящие переводы, в этот план не входят.
- Словарь калек (машинная проверка англицизмов) — отдельная тема, warning-уровень.

## 3. Порядок

Батчами по 3-5 файлов, от «русских документов» к «вкраплениям», коммит после
каждого файла. После каждого батча — прогон стража; по мере погашения долга
опускать `mixed_language_files` в базе с летописью (число снимать грепом, не на глаз).

## 4. Приёмка

- `mixed_language_files` в базе стража опущен до значения, объяснимого летописью
  (в идеале — только `spec/GLOSSARY.en.md`-класс исключений и строки-переключатели).
- Код-блоки всех тронутых пар байт-в-байт (машинный дифф).
- Выборочная вычитка английского владельцем/интегратором.
- Отчёт по-русски: модель, хеши, файлы, число строк до/после, находки.
