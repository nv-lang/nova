# План 200.1 — скорость `nova test std` (подплан плана 200)

**Статус:** 📋 СОГЛАСОВАН 2026-07-13 (владелец: «оформи отдельным подпланом»).
**Приоритет:** после 196/198 (не блокирует ничего; выигрыш — время каждого полного прогона).

## Мотивация и диагноз (замеры 2026-07-13)

Полный `nova test std` занимает ~60–90 минут. Виноват не фронтенд (Nova→C — доли секунды на файл),
а **обвязка на каждый тест-файл**: отдельный компайл-юнит → отдельный запуск cl.exe → статическая
линковка (GC + libuv) → свежий exe (антивирус-скан) → запуск. Плюс стенно-часовые тесты
(sleep/тайминги/сеть/ретраи), которые ждут реальное время при любой скорости компилятора.

Доказательства:
- `spec_tests/conformance`: ~950 тест-блоков **одним** компайл-юнитом = ~3–4 мин целиком
  → цена тест-блока внутри юнита копеечная; час на std = ~130 файлов × накладные-на-юнит.
- `std/src/data` (6 файлов): 2м05с под конкурентной нагрузкой; повторный прогон с тёплым
  кешем сборки — почти мгновенно.

## Пункты

### П1 — папочные компайл-юниты для std-тестов (главный выигрыш)
Раннер собирает `*_test.nv` одного домена (папки) в один CU по образцу conformance merged-CU.
Ожидание: срез накладных ×N → полный std в разы быстрее.
Риски/вопросы: изоляция module-scope между тестами одного CU; известный гуляющий
рантайм-рейс проявляется чаще на больших CU (см. 196.6-runtime-flake-diag-notes) — П1 не начинать
до закрытия рейса или закладывать per-file fallback при RUN-FAIL мерж-юнита.

### П2 — кеш сборки на тестовом цикле
`build_cache` существует (hash-based); замерить hit-rate на типовом цикле «правка одного
модуля → nova test std», найти классы промахов (env-переменные? пути? таймстемпы), починить.

### П3 — профиль «медленные тесты»
Стенно-часовые тесты (sleep/timing, сетевые хендшейки, ретраи) — в отдельный профиль/маркер;
дефолт-прогон без них, полный профиль — по флагу и в ночном прогоне. Частично уже конвенция
(«большие тесты в репо, но не в дефолт-прогоне») — формализовать маркером раннера.

### П4 — базовые цифры и бенч
Скрипт-замер: полный std, по доменам, с разбивкой «фронтенд / cl.exe / линк / ран».
Публикация базовой таблицы в этом файле; повторный замер после П1–П3.

## Критерий приёмки
Полный `nova test std` (без медленного профиля) ≤ 15–20 мин на тихой машине, без потери
покрытия (полный профиль остаётся доступным одним флагом). Conformance-гейт не трогается.
