# План 241 — сайт: подвал контент-страниц (Edit/Source, Open an issue, дата источника)

**Статус:** 🆕 PLANNED (записан 2026-08-02 по слову владельца; идея — по образцу opencode.ai/docs).
**Приоритет:** P3 (сайт; не блокирует релизные хвосты nova).
**Репа исполнения:** `www` (ветка `p-docs-footer` от `origin/main`, свой worktree); мерж в main сайта — за интегратором.
**Зависимость:** docs-split ✅ (2026-08-02: `docs/guide/` = единственный источник doc-контента сайта; `p-docs-split-paths` влита в www).
**Конвенции:** [docs/dev/site-conventions.md](../dev/site-conventions.md) — нормативны для этой волны (в частности [#honest-dates](../dev/site-conventions.md#honest-dates), [#edit-vs-source](../dev/site-conventions.md#edit-vs-source), [#acceptance](../dev/site-conventions.md#acceptance)).

## 0. Мотив

У сгенерированных страниц сайта (`/doc/`, `/spec/`, `/decisions/`) нет обратной связи
и указания источника: читатель не может ни поправить устаревание, ни сообщить о нём,
ни понять, насколько страница свежая. Сегодняшняя волна сняла три содержательных
устаревания руками интегратора — канал «читатель → issue/PR» удешевит это в будущем.
Образец UX — opencode.ai/docs (Edit this page / Found a bug? Open an issue / дата
обновления / переключатель языка). Переключатель RU/EN у нас уже есть.

## 0.1 Исполнитель и дисциплина

- **Исполнитель:** opencode (механика по готовой карте — конвенция «дешёвые модели
  где оправдано»); при запуске указать модель в отчёте/журнале. Fallback при двух
  тупиках — Claude sonnet.
- Суб-агентов НЕ спавнить. Чекпоинт-коммиты после каждого пункта скоупа +
  PROGRESS.md в worktree (устойчивость к rate-limit/обрыву; продолжение с чекпоинта).
- `git add` только по именам; `git config` не трогать; греп конфликт-маркеров ОДНОЙ
  командой с коммитом; ветку пушить только свою `p-docs-footer`.
- Гейты `npm run build/check/check:highlight` агент гоняет сам (лёгкие);
  авторитетную приёмку повторяет интегратор перед мержем.

## 0.2 Карта файлов (всё в репе www, `site/`)

- `scripts/sync-decisions.mjs` — генерация content-файлов; сюда: source-путь + дата
  коммита источника в frontmatter (п.1 скоупа).
- `src/layouts/BaseLayout.astro` — единственный лейаут; подвал-компонент подключать
  здесь (или новым `src/components/PageMeta.astro`) с пропсами от страниц.
- Динамические страницы контента: `src/pages/doc/[...slug].astro`,
  `src/pages/spec/[...slug].astro`, `src/pages/spec/decisions/*` (+ `ru/`-зеркала) —
  читают frontmatter и передают в подвал тип (guide|spec|decisions) и source-путь.
- Рукописные страницы (`index.astro` + партиалы) — пропсы задаются статически
  (ссылка на партиал в www).

## 1. Скоуп

1. **`site/scripts/sync-decisions.mjs`**: пробрасывать в frontmatter каждой
   сгенерированной страницы путь источника в репе nova (`docs/guide/<f>.md`,
   `spec/decisions/<f>.md`, …) и **дату последнего коммита источника** (GitHub API,
   с оглядкой на rate-limit; батчить запросы). Дата сборки как fallback ЗАПРЕЩЕНА —
   ложный сигнал свежести хуже отсутствия даты: нет даты коммита → блок даты не
   рендерить.
2. **Компонент подвала** контент-страниц (en+ru тексты):
   - guide-страницы → «Edit this page» (ссылка на файл `docs/guide/` в nova, ветка main);
   - spec/decisions → «Source on GitHub» БЕЗ приглашения редактировать (спека
     нормативна, изменения — через D-блоки решением владельца; «Edit» соберёт шумные PR);
   - везде → «Open an issue» с предзаполненным заголовком (путь страницы);
   - дата: «Last updated <дата коммита источника>».
3. **Рукописные страницы** (главная, /install/, …): ссылка на партиал в репе www
   (+ «Open an issue»); дата — по коммиту партиала, если дёшево, иначе без даты.
4. **Discord НЕ добавлять** (решение владельца 2026-08-02: до v0.1 сообщество =
   GitHub Discussions, уже в футере).

## 2. Не-скоуп

- Переезд на docs-first движок (Starlight и т.п.) — не нужен, всё добавляется в
  текущие Astro-лейауты точечно.
- Комментарии/реакции на страницах, аналитика.

## 3. Приёмка

- `npm run build` + `npm run check` + `npm run check:highlight` — зелёные;
  check-links чист.
- en/ru синхронны; релиз-нейтральность; «синк не тянет docs/dev/» (стоячая проверка).
- «Edit»/«Source»-ссылки кликнуты на 2-3 реальных страницах каждого типа — файл
  существует в nova main (не 404).
- Даты выборочно сверены с `git log -1` источника.
- Отчёт по-русски: модель, хеши, вердикты гейтов дословно, список страниц/лейаутов.
