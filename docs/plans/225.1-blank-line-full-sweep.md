## 1. Классы стыков (машинные правила)

(a) конец декларации (`}` или `=> expr`) → следующая декларация (`export fn|fn|type|const|test`)
    БЕЗ пустой между — вставить одну; допуск: голые аксессоры одного поля вплотную;
(b) `module …` → непустая строка — вставить пустую;
(c) конец import-блока → первый не-import — вставить пустую;
(d) `test "…" {` без пустой перед — вставить;
(e) 2+ пустых подряд → схлопнуть до одной.

## 2. Объём и порядок

## 3. Гейт (как 225 §3 — байт-идентичность)

Каждый пакет: C-снимок до → правка → пересборка → diff C = ПУСТО (любое расхождение = стоп,
правило задело не-пробел); `nova check`/`test` затронутых пакетов δ0. Внешние репы — их гейты.
