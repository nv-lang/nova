## 2. Остаток (очередь волн)

1. **CI-доводка**: gate.sh + arch-ratchet в GitHub Actions на каждый пуш (CI = бессонный
   интегратор; project-ci-monitoring-protocol остаётся в силе).
2. **Quality-ratchet**: счётчики долгов (беззубые нормы из 231.1, E/W-коды без neg-фикстур,
   warnings по репам) с baseline — красный при росте.
3. **Линт-паритет-таблица**: nv-coding-style правило → линт есть? (аналог 231.1 для
   конвенций кода); мета-норма «код-конвенция вливается вместе с линтом».
4. **Бриф-шаблон файлом**: docs/promts/agent-brief-template.md — стоячие правила агентов
   копируются, не вспоминаются.
5. **Физическая граница канала** (дом — 196): канал отдельным модулем, инференс-хелперы
   приватизируются от emit_c — мимо канала не компилируется.
6. **Дифф-прогон контекстов** (231-Б.2, дом test_runner): standalone vs folder-CU.
