# План 222.0 — карта модулей Polaris/http: слой · статус · основа · под-план

**Статус:** 📋 КАРТА (навигация по под-планам зонтика [222](222-http-framework.md)), 2026-07-23.
**Назначение:** единая точка «какой модуль на каком слое, откуда берём основу, где его под-план».
Правило слоёв (222 §0а): **слой N НИКОГДА не импортирует слой >N**.

## Счёт

**Сейчас 6 модулей** (важно: `body/header/status/…` — это НЕ отдельные модули, а 12 co-equal
root-peer файлов ОДНОГО модуля `http`, см. `nova.toml`). **Целевых ~19** (13 новых).

## Именование до/после раскола пакетов

До раскола (сейчас): модули живут как `http.server.*` / `http.middleware.*` внутри пакета
`nova-http`. После раскола (по завершении ядра 222, см. 222 §0а): слои 0-1 остаются пакетом
`http`, слои 2-3 переезжают в пакет `polaris` с переименованием путей `http.*` → `polaris.*`.
Переименование — механическое (греп импортов), делается ОДНОЙ волной, не по частям.
