## Ф.8 — разведка/замер (зафиксировано в плане §Ф.8.1/8.2, не повторяю)

- Локальный clang 22.1.5 (`C:\Program Files\LLVM\bin\clang.exe`) — `#embed` РАБОТАЕТ с `-std=c23`.
- CI (`ubuntu-latest` ≈ `ubuntu:24.04`, проверено `docker run`) — `apt-get install clang`
  даёт clang **18.1.3** — `#embed` НЕ поддержан (`invalid preprocessing directive`,
  что `-std=c23`, что `-std=c2x`). **Вывод: рантайм feature-probe обязателен,
  версия-парсинг/предположения недостаточны — сам факт CI≠локально это доказывает.**
- Замер 1 МБ синтетики: `.c` 6.4 МБ → 157 байт (~40900×); `clang -c` время
  ~3.2-3.7с → ~0.11-0.12с (~28-30×); итоговый `.o` байт-в-байт идентичен.
  Порог задания (×2) разгромно превышен по обоим измерениям.

## Ф.8.3 — план реализации (что делаю прямо сейчас)

Инвазивность: `emit_c.rs`'s `render_interned_blob_literals` — ЧИСТЫЙ
string-builder (0 файлового I/O сегодня, проверено). Сделать sidecar-запись
затрагивает: (а) новое поле `CEmitter.blob_sidecar_dir: Option<PathBuf>` +
setter; (б) cached feature-probe (`OnceLock<bool>`, компилирует крошечный
`#embed`-пробник через `-fsyntax-only`, без объектного файла); (в) ОДНА
call-сайт-точка wiring — `nova-cli/src/main.rs`'s `build`-команда (~строка
4983), **опционально** через `NOVA_C23_EMBED=1` (env var, БЕЗ этого флага —
0 изменений в горячем пути `nova build`, нулевой риск для существующего
конвейера). `test_runner.rs`'s `nova test`-путь НЕ wired этой волной (карта
есть, симметрично несложно добавить — не сделано из-за бюджета времени после
обрыва связи).

**Почему env-var, не CLI-флаг:** `nova build`/`nova-codegen` — разные
бинари/call-сайты (nova-cli/main.rs, compiler-codegen/main.rs, test_runner.rs)
— проброс через `clap`-флаг потребовал бы трогать сигнатуры в нескольких
местах; env var — ортогонально, задаётся один раз оператором/CI, нулевые
изменения в сигнатурах.

**Почему опционально, а не default-on:** локальная машина сейчас ЕДИНСТВЕННОЕ
известное окружение с поддержкой (CI — нет); включать по умолчанию значило бы
"работает только у автора" — типичная ловушка non-portable. Задание Ф.8
явно предполагает fallback-режим ("реализуй... с fallback").
