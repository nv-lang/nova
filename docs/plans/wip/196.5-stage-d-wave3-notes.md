## Пункт 1 — снос B11ah (коммит `2c2697e1b`)

Единственный честно-мёртвый по census. Контрольный точечный ре-замер post-wave-2
(debug `NOVA_TRACE_ICR`, conformance + collections + data): 0 hit. Структурное
доказательство (не только «0 сегодня»): арм повторно читал ту же пару
`(resolved_types, expr.id)`, что диспетчер `infer_expr_c_type` уже прочитал ПЕРЕД входом
в `infer_call_ret_c` (тот же `&self`, без записи между чтениями; `resolved_type_to_c` —
чистая функция). Либо верхнее чтение провалилось → повтор проваливается идентично
(никогда не хитует), либо верхнее чтение успешно-но-generic-stub
(`debt_is_generic_stub_c`, намеренный fallthrough к subst-aware инференсу) → арм вернул
бы тот же stub, которого fallthrough избегал (неверный ответ). Разбор
closure_channel_miss-гейта (волна-1 §3.3): гейт относится к closure-выражениям
(ClosureLight/ClosureFull kind), Call-выражения он не задерживает — на маршрут Call →
`infer_call_ret_c` не влияет.

## Пункт 2 — две P67-паники (пре-существующие user-visible баги; zero-tolerance вход)

### 2а. `deserialize` — терминал B12q, серде-корпус (коммит `16c312ca8`)

Первопричина: `T.deserialize(d)` в generic-теле `[T Deserialize]`
(std/src/encoding/serde/{serde,json}.nv) парсится в `ExprKind::Path(["T","deserialize"])`
— парсер превращает любой PascalCase-ident перед `.lowercase` в Path; `T` не в
`self.types`/`method_overloads` → ни один static-return путь чекера вызов не видел →
co-miss обоих каналов → легаси-терминал B12q = паника, валившая раннер на серде-корпусе.

Фикс в чекере (f1_expr Call-арм, новый Path-бранч, types/mod.rs ~7927): gate
`parts[1]=="deserialize" && gs.contains(parts[0])`; возврат читается из ДЕКЛАРАЦИИ
протокола `Deserialize` (`TypeDeclKind::Protocol` → `methods["deserialize"].return_type`
= `Result[Self, DeError]`), `Self`→`T` через `subst_type_ref_pub`, гейт на residual
method-generics; `T` канализируется явным `TypeParam` — `resolved_type_to_c` подставит
из `current_type_subst` при эмиссии каждого mono-инстанса. Не хардкод: user-CU со СВОИМ
Deserialize-протоколом получит СВОЙ декларированный возврат; без протокола в CU —
честный fall-through в легаси (как раньше). Тест на класс = серде-корпус
(std/src/encoding 17/0+7skip; до фикса раннер погибал).

### 2б. `str.until` — терминал B11al, orm_decorators (коммит `9ad863091`)

`rest.until(" WHERE ")`/`rest.after(" WHERE ")` (examples/real_world/orm_decorators.nv:65)
не существовали нигде. Тест авторитетен → методы добавлены в std
(runtime/string/search.nv): `@until(sep) -> str` (до первого вхождения; вся строка при
промахе) + `@after(sep) -> str` (после; `""` при промахе) — тотальная пара к
`@split_once`, byte-offset, zero-copy на `@find`. Язык-меняющее → D251-амендмент
2026-07-13 в spec/decisions/03-syntax.md тем же слиянием. Conformance-тест
(d251_str_surface.nv, 6 кейсов: найден/не найден/первое вхождение/multibyte/пустой sep).
