## Ф.3 (№281) — ЗАКРЫТ

### Диагноз (подтверждён чтением кода, не только REPORT-p240.md)

`compiler-codegen/src/codegen/emit_c.rs::emit_expr`, `ExprKind::While`:
```rust
let cond_val = self.emit_expr(cond)?;           // побочные stmt'ы ОДИН раз
let tmp = self.fresh_tmp_named("while");
self.line(&format!("nova_unit {};", tmp));
self.line(&format!("while ({}) {{", cond_val)); // C-цикл перепроверяет
...                                              // ТОЛЬКО это выражение
```
`emit_expr(cond)` может эмитить side-effecting `self.line(...)`-стейтменты
(addressable temp для value-record промежуточного результата цепочки
вызовов, напр. `_nv_tmp_N = Nova_T_method_m1(&recv);` перед
`&_nv_tmp_N`, передаваемым в `.m2()`). Вызов один раз ДО `while(...)`
означает: этот temp вычисляется РОВНО один раз, а C `while (cond_val)`
дальше перепроверяет только финальное булево выражение — которое
ссылается на замороженный `_nv_tmp_N`. Для условия без цепочки (голый
ident/литерал) `emit_expr` не эмитит побочных стейтментов — баг невидим.
Для условия-цепочки — тихий бесконечный цикл на корректном коде.

Соседний `ExprKind::WhileLet` (тот же файл, ~80 строк ниже) УЖЕ решает
эту же задачу правильно: `while (1) { <scrutinee/cond ВНУТРИ>; if (!(cond))
break; body }` — cond пересчитывается каждую итерацию.

### Фикс

Mirror `WhileLet`: `ExprKind::While` теперь тоже `while (1) { <cond
внутри>; if (!(cond_val)) break; body }`. `continue` внутри тела прыгает
на верх `while(1)`, т.е. на пересчёт условия — то же поведение, что уже
доказанно корректно работает для `WhileLet`/`Loop`. Диф — 1 файл,
локальный к одному match-арму.

### Ratchet

emit_c.rs вырос на **+1 строку** (`if (!(cond_val)) break;` — семантически
неизбежная строка, C `while` не может встроить pre-check statement).
Ужато с исходных +10 (подробный doc-comment) до +1 (однострочный
комментарий-маркер). Baseline `scripts/guards/arch-ratchet.baseline`
обновлён `64395→64396` с обоснованием (см. файл, датированная запись
2026-08-02). `infer` не тронут (control-flow эмиссия, не новая точка
инференса) — остаётся 348.
