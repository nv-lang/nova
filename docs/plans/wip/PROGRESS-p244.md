## Ф.0 — базовый замер ТЕКУЩЕЙ (сишной) реализации

Машина: эта, сборка компилятора: `cargo build --release` в этом worktree,
коммит `e3f8135b3` + rust toolchain из `nova-cli/Cargo.toml` (без изменений).
Бинарь: `nova-cli/target/release/nova.exe`. Бенчи — `docs/plans/wip/bench-p244/*.nv`

### Сценарий 1 — пропускная способность (bench1_throughput.nv)

Один отправитель (`spawn`), один получатель (`spawn`) в одном `supervised`,
N=200_000 элементов `int`, буфер ёмкости 1 / 16 / 1024.

| cap | elems/sec |
|---|---|
| 1 | 195 241 |
| 16 | 1 063 924 |
| 1024 | 12 695 994 |

### Сценарий 2 — задержка на пустом канале (bench2_latency.nv)

Получатель паркуется первым (`rx.recv()` на пустом канале), отправитель
приходит после `2ms` сна (гарантия, что получатель успел припарковаться),
засекается `send_ns`/`recv_ns` через `Monotonic.now().nanos()` в разных
файберах. 200 раундов, cap=1.

- среднее: **26 695 нс**
- минимум: **12 600 нс**

### Сценарий 3 — select с несколькими ветвями (bench3_select.nv)

N каналов (2/4/8), РОВНО один готов постоянно (арм, который сработал,
тут же кладёт значение обратно в свой канал). 100 000 раундов на каждое N.

| ветвей | iters/sec |
|---|---|
| 2 | 8 074 023 |
| 4 | 4 943 251 |
| 8 | 2 859 357 |

Видна деградация ~линейно от числа ветвей (полный скан списка ожидателей
на каждый вызов) — ожидаемо для текущей C-реализации, эталон для Ф.3/Ф.5.

### Находка Ф.0 (побочная, №TBD)

При написании `bench1_throughput.nv` вскрылся ложноположительный
D131-отказ: `mut i = 0; while i < n { ro v = i; i += 1; tx.send(v) }` —
компилятор помечает **саму переменную цикла `i`** как «использование,
возможно, потреблённой», хотя потребляется отдельная привязка `v`, а не
`i`. Диагностика указывает on точку входа `while` (loop back-edge), похоже
на консервативное слияние потоков управления в D131-анализе внутри
`while`, ошибочно связывающее судьбу `i` с судьбой `v`. Обход в бенче —
`for i int in 0..n { tx.send(i) }` (свежая привязка на итерацию, для-цикл
не страдает тем же багом). Не чинилось — не входит в объём Ф.0/Ф.1,
докладывается интегратору как находка.
