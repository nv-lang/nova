## Доделка по приёмке (sonnet) — сняты все 3 TODO

Владелец дал решение, чем заменить три заблокированных места. Все три
TODO-маркера сняты, шапка «Частично актуализировано» убрана целиком
(п.5 задания — TODO не осталось).

1. **`Printable` → `Display`** (раздел «Полиморфизм через protocol»).
   Вместо вымышленного протокола — реальный built-in `Display`
   (`std/prelude/protocols.nv`, [D422](decisions/02-types.md#d422)),
   процитирован дословно: `export type Display protocol { @display(mut f
   Fmt) -> () }`. Пример «Printable для int» заменён: вместо `impl
   Printable for int` (запрещённый extension-метод на примитиве, D35
   «Receiver») — `Account` и новый тип-запись `Point` реализуют
   `@display(mut f Fmt) -> ()` структурно, каждый свой.
2. **Коллекция протокольных значений.** Гетерогенный `ro items
   []Printable = [acc, 42, "hello"]` заменён на две легальные формы
   (раздел «Динамический диспатч»): (а) обобщённая функция `fn
   log_all[T Display](xs []T) -> ()` с bound'ом `[T Display]` (D72,
   вызывается отдельно для `[]Account` и `[]int` — гетерогенного
   массива в одной мономорфизации не бывает, это честно проговорено);
   (б) отдельно — подлинный existential-пример `fn describe(x Display)
   -> str` (D72: `fn f(x Hash)`, protocol-тип в обычной позиции
   параметра = vtable-диспатч), вызванный на `Account`/`int`/`str`.
3. **Строка «Абстрактный класс»** в таблице ООП заменена на «нет
   аналога: протоколы не несут реализаций по умолчанию ([D15]
   (decisions/02-types.md#d15))» — оформлено тем же коротким anchor-
   стилем ссылок, что и в шапке файла (был).
4. **D46 → D35.** Обе ошибочные ссылки на D46 (оператор-перегрузка,
   03-syntax.md#d46 — не имеет отношения к теме) были внутри снятых
