**Это АДАПТЕР, а не вторая копия.** Источник правды — `.claude/commands/id.md`.
Прочитай его целиком и следуй ему, заменяя:

- `CLAUDE_CODE_SESSION_ID` / `CLAUDE_CONFIG_DIR` / поиск файла истории → в Kimi
  Code ID сессии и путь к её wire-файлу смотри командой `/status` (идентификатор
  сессии и каталог сессии там же). Точный путь к `wire.jsonl` — в подкаталоге
  `agents/` каталога сессии.
- `ListAgents` → в Kimi Code нет прямого аналога. Соседние сессии не видны
  напрямую; своё имя/идентификатор — только из `/status`. Сообщения соседям
  идут через пользователя этой сессии, а не через `SendMessage`.
- Отправка сообщений (`SendMessage`) → недоступна; форму сообщений из `/peers`
  используй для сообщений, которые пользователь перенесёт.
- Время в докладе — `date "+%H:%M"` непосредственно перед докладом.

Форма ответа на чужий вопрос «кто ты / дай id» — четыре факта: id сессии (из
`/status`), дерево, ветка (`git rev-parse --abbrev-ref HEAD`), и роль (если
известна).
