**Это АДАПТЕР, а не вторая копия.** Источник правды роли — файл
`.claude/commands/integrator.md` в корне репозитория: он один хранит правила,
замеры и порядок входа (в этом репозитории две копии одного текста расходятся
молча — прецеденты названы в `AGENTS.md`). Прочитай исходник ЦЕЛИКОМ
инструментом Read и следуй ему, заменяя механики Claude Code на механики
Kimi Code CLI по таблице ниже. Если адаптер и исходник разойдутся — верен
исходник, а адаптер правится.

Первой строкой хода — **местное время** командой `date "+%H:%M"` (правило
`AGENTS.md`, раздел «Время»), и ПЕРЕД КАЖДЫМ докладом — заново.

## Таблица подстановок (Claude Code → Kimi Code CLI)

| В исходнике | В этой сессии |
|---|---|
| slash-команда `/integrator` | этот скилл, вызов `/integrator` |
| `/peers`, инструменты `ListAgents`/`SendMessage`, `session-card.sh`, отзыв на контрольный вопрос «кто тут интегратор Карины?» | **недоступны** — обход живых соседних сессий и визитки из Kimi Code не исполняются. Если соседние окна работают в Claude Code, они не увидят эту сессию: скажи пользователю, кто ты (роль, дерево, ветка), чтобы он передал это соседям |
| агент `spec-reader` (`.claude/agents/spec-reader.md`) | инструмент **Agent** с `subagent_type="spec-reader"` — порт заведён в `.kimi-code/agents/spec-reader.md` (только чтение, та же форма выдачи). Если тип в этой сессии не зарегистрирован — fallback: `subagent_type="explore"` с брифом и формой из `.claude/skills/read-spec/SKILL.md`, вложенными в prompt текстом |
| команды `/save`, `/stop` | запись в `docs/dev/prompts/integrator-handoff.md` инструментом Edit (раздел СВЕРХУ); при остановке — также `docs/.sessions/handoff-<id>.md` (id сессии — из `/status`) |
| команды `/flow`, `/delegate`, `/explain`, `/carina`, `/commit-push` | читай одноимённый файл `.claude/commands/<имя>.md` как текст инструкций и следуй ему вручную |
| хук `show-local-time.py` (строка «ВРЕМЯ СЕЙЧАС …») | не приезжает — время в докладе берётся ТОЛЬКО из `date "+%H:%M"`, запущенного непосредственно перед докладом |
| полный гейт откреплённо через `scripts/tools/gate-bg.sh` (интегратору фон законен и обязателен) | разрешён и здесь: `run_in_background=true` у Bash для гейта законен РОВНО для этой роли — уведомление приходит в эту же сессию. Всё остальное фоном не запускать |
| `allowed-tools` во frontmatter исходника | не действует; разрешения — permission-режим сессии (`/permission`) |
| строка «Модели агентов: …» в докладе (`/delegate`) | в Kimi Code субагенты идут на модели из `/secondary-model`; строку в докладе сохраняй — пиши, какие типы субагентов запускались |

## Рабочее дерево

Интегратор работает в **главном дереве** на `main`. Проверь `pwd` и
`git rev-parse --abbrev-ref HEAD`: если сессия запущена не в главном дереве
(например, cwd — чужой worktree), не тяни `main` в чужую копию — работай через
`git -C <главное дерево> …` либо попроси пользователя перезапустить сессию
в главном дереве.
