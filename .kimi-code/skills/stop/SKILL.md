**Это АДАПТЕР, а не вторая копия.** Источник правды — `.claude/commands/stop.md`.
Прочитай его целиком и следуй ему, заменяя:

- `/save` → запись в ролевую записку инструментами Edit/Write (см. `/save` и
  таблицу адресатов в исходнике).
- Фоновые задачи → остановить через `TaskStop` (по id из `TaskList`); если
  стартовали через `Agent run_in_background` — тоже `TaskStop`.
- `docs/.sessions/handoff-<id>.md` как доказательство остановки → id сессии бери
  из `/status`; запись в `docs/.sessions/handoff-<id>.md` дополнительно к ролевой
  записке (см. актуальное правило в `/carina`: два дома — содержание и
  доказательство).
- Хук `show-local-time.py` → не приезжает; время в докладе только из
  `date "+%H:%M"`, запущенного прямо сейчас.
- Визитка `session-card.sh` для помощника → недоступна; помощник пишет в
  `docs/dev/prompts/assistant-handoff.md` по роли, а не по визитке.

Правило скорости сохраняется: ничего дольше 30 секунд, не начинать нового,
остановить фон, зафиксировать или перечислить `git status`, записать передачу и
id сессии.
