**Это АДАПТЕР, а не вторая копия.** Источник правды — `.claude/commands/peers.md`.
Прочитай его целиком и следуй ему, но учти:

- `ListAgents` и `SendMessage` — **недоступны в Kimi Code CLI**. Живых соседних
  сессий нельзя обойти инструментально. Всё, что исходник требует передать/
  запросить, формулируй в докладе пользователю этой сессии — он перенесёт
  сообщения в соседние окна (если они есть).
- Контрольный вопрос-ответ (`кто тут интегратор Карины?` и т.д.) из этой сессии
  работает только если сосед спрашивает тебя напрямую через пользователя.
  Отвечай дословно фразой из таблицы исходника, приложив дерево и ветку.
- Визитка `session-card.sh` — недоступна; роль опознаётся по вашему обмену и
  доказуемым фактам (дерево/ветка), а не файлом.
- Имени сессии вида `nova-XX` в Kimi Code нет; соседние Kimi-сессии различаются
  по id из `/status`.
- Частота обхода (раз в 10 минут) и правило «пустой ответ — не шлём»
  сохраняются: раз в 10 минут сверяй, есть ли что передать/спросить, и говори
  пользователю.
