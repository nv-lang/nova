`.claude/commands/carina.md` в корне репозитория: он один хранит правила,

молча — прецеденты названы в `AGENTS.md` и `docs/dev/read-project.md`).
Прочитай исходник ЦЕЛИКОМ инструментом Read и следуй ему, заменяя механики
Claude Code на механики Kimi Code CLI по таблице ниже. Если адаптер и
исходник разойдутся — верен исходник, а адаптер правится.

Первой строкой хода — **местное время** командой `date "+%H:%M"` (правило
`AGENTS.md`, раздел «Время»), и ПЕРЕД КАЖДЫМ докладом человеку — заново.

## Рабочее дерево

Исходник называет дерево по ИМЕНИ каталога, не по абсолютному пути (реестр
221.1 №698: раскладка машины не пишется литералом, а выводится) — worktree
ветки `p274-novac` лежит рядом с главной копией под именем `nova-p274`.
Если текущий cwd сессии — не оно (проверь `pwd` и
`git rev-parse --abbrev-ref HEAD`), не переключай ветки в чужой копии:
работай через абсолютный путь этого worktree, взятый `git worktree list`
(колонка пути для ветки `p274-novac`), либо попроси пользователя
перезапустить сессию в том дереве.
