## Минимум класса и границы

Нормативные **текстовые backtick-литералы без живых слотов `${...}`**, с тегом и без: lossless чтение, D467 escape/переносы/нормализация, D48 вызов обычной tag-функции с одним элементом parts и пустым типизированным args. Экранированное `\${...}` является текстом, обязательно поддерживается. Именно этот класс покрывает все backtick-позиции неизменного реального входа. Живые слоты не должны молча становиться текстом: неподдержанный контекст обязан получить явный subset-отказ. Существующая интерполяция в двойных кавычках сохраняется.

Не входит: typed Fail, lambda/callback, map-literal, изменение исходного примера/спеки, поставляемого сида или пинов. Если типизация/эмиссия текстового tag требует самостоятельного нового класса — остановка с точной дверью, не обход через перепись исходника.
