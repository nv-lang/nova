## Критерии приёмки задания

- **RED/GREEN на потере исходников** — см. САБОТАЖ; GREEN доказан не только
  сменой диагностики, но сквозной позитивной фикстурой (деп исполняется).
- **Позитивная и отрицательная регрессии разрешения внешних импортов** —
  позитивная: `dep_build_min` + транзитивный граф polaris (http/tls/compress
  из pinned git-cache, 45-55 файлов на вход, побайтовая сверка:
  `verify-stage-polaris.txt`); отрицательная: неизвестный импорт (не деп/не
  свой/не std) ничего не стейджит, отказ сида по имени как сегодня
  (юнит-тест + саботаж-форма); одноимённые последние сегменты у разных депов
  (`a.types`/`b.types`) — ЖИВАЯ проба через драйвер и pinned B1 с разными
  результатами: пакеты-депы `a` и `b`, оба с модулем `types`; без приманки —
  build rc=0, запуск печатает дословно `a=111 b=222 only_a=1 only_b=2`, то
  есть все четыре значения взяты из правильных единиц, смешения деклараций
  одноимённых модулей НЕТ (`evidence/probe-ab-types.txt`); с приманкой
  (неимпортируемый `give_a() => 999` в `b.types`) — громкий отказ
  `E_NOVAC_SUBSET` D84-неоднозначности на вызове `give_a()` в entry
  (`evidence/probe-ab-types-decoy.txt`): сид резолвит свободные функции
  глобально по имени по всем переданным единицам, список имён импорта
  кандидатов не фильтрует — ложная неоднозначность на законной по D29
  программе; отказ честный (по имени, без тихого неверного ответа), заведено
  второй строкой №1931 в реестре, починка — в новой сборке сида, не в
  драйвере. Путаницы сида (тихой подмены) не обнаружено — измеренная граница
  названа, а не скрыта.
