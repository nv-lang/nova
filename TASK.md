# Задача: триаж 76 кодов ошибок, отсутствующих в компиляторе

Файл `MISSING_CODES.txt` в этом каталоге — список кодов `E_*`/`W_*`, которые
ВСТРЕЧАЮТСЯ В СПЕКЕ (`spec/**/*.md`), но НЕ встречаются ни в одном `.rs`-файле
компилятора (`compiler-codegen/src`, `nova-cli/src`). Проверено грепом 2026-08-07.

Для КАЖДОГО кода из списка определи ОДНУ из четырёх категорий и запиши строку
таблицы в `TRIAGE.md`:

- **A — реально беззубая норма**: в спеке норма описана как действующая, в
  компиляторе нет ни кода, ни эквивалентной проверки под другим именем.
  Это настоящая дыра.
- **B — самоописанная отложенность/ретракция**: рядом с кодом в спеке стоит
  пометка «отложено», «ретрактировано», «Plan NNN», «future» и т.п.
  Дыры нет, норма честно помечена как невведённая.
- **C — реализовано ПОД ДРУГИМ ИМЕНЕМ**: проверка есть, но код называется иначе.
  Обязательно указать, какой код найден вместо него (грепом по тексту сообщения
  или по соседним строкам спеки).
- **D — код-заглушка/пример**: `E_CODE`, `E_AUTO_DERIVE_FIELD_LACKS_`,
  `E_COALESCE_RETURN_` и подобные обрубки — это не настоящие коды, а фрагменты
  из шаблонов/примеров в тексте спеки. Отбросить.

## Как искать (механика, отклоняться не нужно)
1. `grep -rn "<КОД>" spec/` — найти место в спеке, прочитать 5 строк вокруг:
   есть ли пометка отложенности (категория B) или ссылка на план.
2. Взять из спеки ТЕКСТ СООБЩЕНИЯ рядом с кодом (обычно в кавычках или после
   двоеточия) и поискать характерный фрагмент этого текста по `compiler-codegen/src`:
   `grep -rn "<фрагмент>" --include=*.rs compiler-codegen/src` — если найдётся
   диагностика с другим кодом, это категория C.
3. Если ни того ни другого — категория A.

## Формат TRIAGE.md
| Код | Категория | Обоснование (1 строка) | Если C — под каким именем |

В конце файла — итог: сколько A, B, C, D.

## Правила
- В начале КАЖДОЙ команды с grep: `export LC_ALL=C`.
- НЕ править ни спеку, ни компилятор — только создать `TRIAGE.md`.
- Не додумывать: если данных не хватает, ставь категорию A и пиши «требует
  ручной проверки» — честное «не знаю» ценнее уверенного домысла.
- Коммить после каждых 15 разобранных кодов:
  `git add TRIAGE.md && grep -rn '<<<<<<<\|>>>>>>>' TRIAGE.md; git commit -s -m "..."`
