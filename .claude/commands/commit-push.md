Закоммить и запушь сделанное в этом окне: $ARGUMENTS

Правила — из `AGENTS.md` (Git) и `docs/dev/rules-for-agents.md`; здесь только порядок,
в котором их применяют, и команды целиком. Ветка — своя (`main` принадлежит интегратору).

1. **Что едет.** `git status --short` и `git diff --stat`. Раздели изменения по
   ЛОГИЧЕСКИМ задачам — один коммит на задачу, несколько задач — несколько коммитов.
   Файлы, о которых владелец не говорил (чужие правки, черновики «по слову»), в коммит не
   входят — назови их в докладе как оставленные.
2. **Новые файлы — `git add <имя>` по одному** (никогда `-A`, `.`, `-u`). Файл, который
   игнорирует `.gitignore`, `git add` отклонит — это не повод для `-f`: реши, где ему
   место, или добавь исключение в `.gitignore` с причиной.
3. **Проверь индекс перед коммитом:** `git diff --cached --stat` — в нём только твои
   файлы этой задачи; чужое в индексе общего дерева — не твоё, `--only` его не возьмёт,
   но увидеть надо.
4. **Сообщение — по-английски, файлом по длинному пути** (не через `B7E3~1`):
   `target/msg-<тема>.txt`. Заголовок ≤ 72 знака в форме `тип(область): что изменилось`;
   тело — почему и чем доказано (строка вердикта, тест, замер). Для правок `novac` —
   строка `Donor:` (законный донор или «none — потому что…»; оракул донором не бывает,
   страж `check-novac-commit-donor` откажет).
5. **Коммит с областью и грепом маркеров конфликта В ОДНОЙ КОМАНДЕ:**
   `grep -rn -E '^(<<<<<<<|=======|>>>>>>>)' -- <файлы> && echo "conflict markers" && exit 1;
   git commit -s -F target/msg-<тема>.txt --only -- <файл1> <файл2>`
   Флаги — до `--`, пути — после (хук `guard-git.py` откажет иначе). Проверь, что
   коммит создался: `git log -1 --format='%h %s'` — «Everything up-to-date» при пуше
   означает, что коммита не было.
6. **Гейт и пуш — одной командой:** `bash scripts/tools/push-after-gate.sh`. Она сама
   откажет на грязном дереве и на `main`, проверит автора непушенных коммитов, выберет
   ярус по путям (`novac/` → `NOVAC_TIER=push` и основной `loop`; иначе только основной
   `loop`), запушит с повтором и напечатает `unpushed: N`. Красный гейт — чинить причину,
   не базу; пуш без гейта — только `GATE=none GATE_SKIP_REASON="…"`, и причина идёт в
   доклад.
7. **Доклад:** хеши и заголовки коммитов, вердикт каждого яруса с временем, `unpushed: 0`,
   что осталось незакоммиченным и почему.

Чего команда не делает: не сливает в `main`, не пушит `--force`, не трогает
`git config user.*`, не добавляет `Co-Authored-By`, не пушит слияние, меняющее язык, без
спек-амендмента в том же слиянии.
