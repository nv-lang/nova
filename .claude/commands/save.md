**КОМУ ЭТА КОМАНДА: главному интегратору.** Окно со своей задачей пишет свою
передачу по `/stop`, а не сюда.

Первой строкой хода — **местное время** командой `date "+%H:%M"`.

## Зачем она есть — замер, а не пожелание

2026-09-16 владелец спросил, где и как часто сохраняется контекст. Ответ был
плохим: записка не обновлялась **семнадцать часов работы**. Правило существовало,
механизма не было — а правило без механизма есть симптом, не фикс.

## Что делает

Дописывает в [docs/dev/prompts/integrator-handoff.md](../../docs/dev/prompts/integrator-handoff.md)
раздел `## 0-ДДММ. Состояние на <дата>, <часть суток>` — **сверху, сразу под
шапкой**, потому что свежее читают первым.

**Содержимое берётся ИЗ ДЕРЕВА, а не из памяти хода:**

```sh
date "+%Y-%m-%d %H:%M"
git -C . log --oneline origin/main..HEAD
git -C . log --oneline -15
git -C . status --porcelain
```

Раздел несёт ровно пять частей, каждая обязательна:

1. **Что сделано за смену** — таблицей «что · коммит · чем доказано». Без «чем
   доказано» строка бесполезна: следующее окно не отличит сделанное от
   заявленного.
2. **Что открыто и чьё слово нужно** — списком, с адресатом у каждого.
3. **Чего НЕ делать** — границы, названные владельцем, дословно. Без них
   следующее окно доделывает «очевидное», которого никто не заказывал.
4. **Уроки смены** — только те, что переживут работу; не пересказ хода.
5. **Время и коммит**, на которых снят раздел.

## Правила, которые нарушит первое же окно

- **Метка раздела берётся из `date`, а не выбирается.** Дважды за смену метки
  сталкивались, и оба раза — потому что имя выбиралось до записи. Проверь
  уникальность **ДО** правки: `grep -c "## 0-ДДММ" <файл>` обязан дать 0.
- **Второй вызов в тот же день НЕ создаёт дубля**: если раздел с этой меткой уже
  есть — дописывай в него, а не рядом. Это проверяется тем же грепом.
- **Состояние планов сюда не копируется.** Его дом — строки `**Статус:**`;
  копия разойдётся на первой правке.

## Как часто

Раз в час, автоматически — это настроено механизмом, а не памятью окна (см.
`scripts/tools/session-save-reminder.py` и запись в плане 290 пункт 3). Вызов
руками законен в любой момент: перед долгим гейтом, перед риском обрыва, после
слияния.
