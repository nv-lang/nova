Владелец включил ultracode и workflows на эту сессию. Разворачивай: $ARGUMENTS

**Что это меняет и чего НЕ меняет.** Разрешение стоит на весь ход сессии, а не на
один вызов: многоагентные workflow и параллельные веера агентов можно запускать
без отдельного вопроса. НЕ меняется всё остальное — выбор модели по `/delegate`
(его правила здесь не повторяются, они приезжают импортом в каждое окно), запреты
агентам (суб-агентов не спавнить, мега-CU не гонять), дисциплина фона (чекпоинт,
взгляд каждые пять минут, между взглядами — работа).

**Когда workflow, а когда просто веер агентов** — по форме работы, не по моде:

- **Workflow** — когда есть конвейер с фазами и сбором результатов: N разведок →
  проверка каждой находки → свод. Скрипт делает порядок детерминированным, а
  упавший шаг перезапускается с кэшем (`resumeFromRunId`), не переплачивая за
  сделанное.
- **Параллельные агенты без workflow** — когда задачи независимы и свода не
  требуют: три охоты по трём клеткам, сверка документа, дока по образцу. Каждому —
  бриф по `/delegate`: команды целиком, точный путь, запреты, ОБРАЗЕЦ строки
  результата, свой чекпоинт-файл.

**Жёсткое, что ломается первым при веере:**

- **дерево под идущим гейтом не правит НИКТО** — ни ты, ни агент; агентам давать
  только чтение main-репы либо запись строго в свои каталоги скратчпада;
- **два агента не пишут в один файл**; выдача агента — сырьё, факты о дереве
  сверяет вызывающий до использования;
- **вееру нужен потолок**: не больше числа окон из конвенции (сейчас 4 тяжёлых
  разом — память о добитых watchdog'ом окнах); дешёвые читатели — свободнее;
- в докладе — строка «Модели агентов:» с моделью КАЖДОГО и словом, что делал.

**Цена.** Ultracode не отменяет «ЛИМИТЫ — РЕСУРС»: он разрешает тратить их
параллельно, а не тратить больше. Веер из haiku дешевле одного opus; opus в
веере — только там, где дешевле не выходит (правило `/delegate`).
