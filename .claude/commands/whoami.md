Скажи, от какой учётки работает это окно Claude Code и где лежат её файлы. Значения из
`.credentials.json` НЕ читать и НЕ печатать — ни командой, ни в примере: секрет,
попавший в вывод сессии, остаётся в её истории. О файле кредов сообщаются только путь,
размер и время изменения.

1. **Какой каталог конфига активен.** `echo $CLAUDE_CONFIG_DIR`:
   - переменная задана → мульти-аккаунтная раскладка владельца: каталог учётки вида
     `D:\Sources\.claude-accounts\<имя>`; соседние каталоги в `D:\Sources\.claude-accounts\`
     — другие учётки (покажи `ls` одним уровнем);
   - не задана → раскладка по умолчанию: каталог `%USERPROFILE%\.claude`, а файл
     конфига — `%USERPROFILE%\.claude.json` (файл РЯДОМ с каталогом, не внутри).
2. **Кто залогинен.** Из файла конфига (`$CLAUDE_CONFIG_DIR\.claude.json` либо
   `%USERPROFILE%\.claude.json`) прочитай ТОЛЬКО два поля — питоном через `json`, не
   грепом по всему файлу: `oauthAccount.emailAddress` и `oauthAccount.organizationName`.
3. **Где креды.** `$CLAUDE_CONFIG_DIR\.credentials.json` (или
   `%USERPROFILE%\.claude\.credentials.json` без переменной) — путь, размер, mtime,
   содержимое не открывать. На macOS токены живут в Keychain, файла может не быть.
4. **Доклад, четыре строки:** учётка (почта, организация); каталог конфига и задан ли он
   переменной; путь файла кредов с размером и временем; список соседних учёток, если
   раскладка мульти-аккаунтная. Плюс напоминание: сменить учётку — `/login` и `/logout`
   в самом Claude Code; смена `CLAUDE_CONFIG_DIR` действует на новые сессии.

Проверено 2026-08-27 на этой машине: `CLAUDE_CONFIG_DIR=D:\Sources\.claude-accounts\nv-lang`,
почта и организация читаются из `oauthAccount`, креды лежат рядом с конфигом.
