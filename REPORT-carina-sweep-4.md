### Голый `None` — четыре формы
1. **Хвостовой `if` и `if let` блока** функции `-> Option[T]`: typing.nv ставит объявленный
   возврат ожиданием вокруг `@type_if_value` / `@type_if_let` — как уже было у `if` тела-выражения
   и у хвостового `match`.
2. **Хвост блока рукава** (`Leaf(t) => { ..; None }`): `@type_arm_block_value` отдаёт ожидание
   рукава только ХВОСТУ блока; инструкции до него ожидания не получают (`ro x = None` внутри — не
   значение рукава).
3. **Рукав ПОСЛЕ блочного рукава** (`Branch { .. } => None`): тело рукава могло сбросить ожидание,
   и следующий рукав наследовал пустое; `@type_match` восстанавливает его перед каждым рукавом.
4. **Поле конструктора** (`default_expr: None`): binds.nv типизирует значение поля с объявленным
   типом поля как ожиданием (`@ctor_field_expect`, только конкретные типы).
